# Particle Bird Hero

独立技术样机，不替换现有液态飞鸟、纸质版或正式首页。

验证范围：

- 65,536 个表面均匀采样点组成真实飞鸟轮廓；
- 滚动控制散落粒子逐步汇聚，向上滚动可倒放；
- 鼠标靠近时产生柔和排斥，离开后回位；
- 移动端将绘制数量降到 24,576，并支持 `prefers-reduced-motion`。

本地查看：从仓库根目录启动静态服务器，然后打开
`/prototypes/particle-bird-hero/`。

模型来源：用户在腾讯混元 3D V3.1 中生成的飞鸟 GLB。网页不分发原始 89MB GLB，只分发从其表面离线采样的坐标数据；正式商用前仍需留存生成记录并核对当时适用的服务条款。
