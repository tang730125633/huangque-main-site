03 / HQ CLI

你的 Agent，也能在边界清楚的前提下使用黄雀。

HQ CLI 通过浏览器设备授权建立连接，不需要把主站密码交给外部 Agent。每项能力都有明确范围，付费动作仍然先报价、再确认。
