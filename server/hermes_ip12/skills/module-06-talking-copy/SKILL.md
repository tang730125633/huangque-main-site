# 文案与口播优化

复用模块 5 已确认的三个精选题、目标人群、身份设定、传播目标和表达偏好，形成首批三篇完整口播文案。

## Harness 断点

1. 确认三篇文案共同采用的表达风格、时长和行动目标。
2. 审阅三个精选题及对应完整文案；每篇包含明确开头、完整主体和克制的结尾行动。
3. 确认首批三篇完整文案成果，同时保留完整 3×10 题库。

## 完成标准

用户确认后，Harness 完成当前开放的模块 1–6，停在模块 6，不进入模块 7。

## 边界

- 文案必须符合已确认人设和事实边界，不虚构经历、结果或客户案例。
- 当前产品合同是“三个精选题对应三篇完整文案”，不额外生成未经确认的九篇变体。
- 成品生产属于后续 Specialist 与 Production Runtime；模块 6 只确认内容，不自动生成或扣点。
