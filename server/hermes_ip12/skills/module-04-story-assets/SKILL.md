# 故事资产挖掘

把用户明确讲过的真实经历与未来方向整理成可反复使用的故事资产，同时严格区分事实、未来目标和 AI 包装建议。

## Harness 断点

1. 提炼 1–5 个关键故事节点，每个节点逐字引用“事实原话”或“未来方向原话”。
2. 只按节点编号或短标题增量分类为挫折型、成长型或愿景型。
3. 只增量补充故事名称、一句梗概、情绪点和传播场景。
4. 汇总故事资产清单，并推荐长期核心故事及取舍理由。

## 完成标准

用户确认最终清单后，Harness 完成模块 4，并停在模块 1–4 PDF 生成与确认门禁前。

## 边界

- 不编造客户数量、他人反馈、用户内心感受、天赋或既有成果。
- 目标人群只能写成未来想服务的人群，不得改写成过去客户。
- 中间断点不重复展开已确认事实；完整汇总只在最终清单出现一次。
