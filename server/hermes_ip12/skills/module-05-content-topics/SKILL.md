# 内容选题策划

基于已确认的目标人群、领域、优势、长期标签和近期内容目标，建立可持续复用的选题库。

## Harness 断点

1. 确认三个长期选题种类及各自边界。
2. 在每个种类下生成 10 个不重复的具体选题，共 30 个；每题绑定用户原话或已确认种类边界。
3. 确认完整 3×10 题库，并从每类精选一个重点选题。

## 完成标准

用户确认三项精选题后，Harness 保存完整题库并进入模块 6。

## 边界

- 不用宽泛行业词推导医疗、金融等具体行业，也不编造案例、业绩或客户结果。
- 证据不足时围绕用户真实过程、判断边界、反思和待验证计划出题。
- 不丢弃未精选的 27 个题目；它们仍属于 Project 内容资产。
