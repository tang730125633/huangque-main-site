# 关键词库（6 垂类）+ 选词铁律

## 🎯 选词铁律：看「要找谁」，不是「对方是谁」
- 想找**上门消费的客人** → 爬 **C端**词（消费需求词："做X / X多少钱 / X推荐 / 哪里做X / 有效果吗"）。
- 想找**门店老板 / 创业者 / 同行 / 加盟商** → 爬 **B端**词（"X拓客 / X获客 / 怎么收费 / 怎么加盟"）。
- ⚠️ **一个开店老板想给自己店引流客人 → 爬 C端 词！别因为他是老板就给 B端 词**（B端词扒到的是同行老板，不是他的客人）。
- **我们公司自己**要找客户（卖 AI 获客服务）→ 爬 **B端**词（找那些缺客的店主）。
- 拿不准对方要找谁？**先问一句**"你是想找上门消费的客人，还是找同行/开店方法？"再定词。

## C端词库（找终端消费者 = 门店的上门客人）

**【美业项目C端】** 瘦身、减肥、瘦脸、瘦腿、塑形、产后修复、身材管理、抗衰、幼态脸、紧致提升、水光针、热玛吉、超声炮、童颜针、祛斑、祛痘、美白淡斑、补水、敏感肌、小气泡、光子嫩肤、私密管理、暖宫、卵巢保养、肩颈调理、头皮养护、美睫、纹绣半永久、脱毛

> 帮某个行业的店主找客人，就**仿这个思路造 C端 词**：「做+项目」「项目+多少钱」「项目+推荐」「哪里做+项目」「项目+有效果吗」。例：美甲店→"做美甲/美甲多少钱/美甲推荐/美甲款式"；瑜伽馆→"瑜伽体验课/瑜伽哪家好/想学瑜伽"。
