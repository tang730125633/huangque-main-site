# 踩坑与边界（对外口径 / 合规 / 故障排查）

## 对外边界（群里有大鹏老板和外人）
- 对外只讲**能做什么 / 怎么用 / 出什么结果**；**不讲**服务器、IP、账号、密码、cookie 等基建细节。
- 不确定的系统细节，说"我去确认一下"，**绝不现编**。
- @回复先看清在回谁，用 `<at user_id=...>` 开头。
- 群里回复**要短**：先结论+要点，对方要细节再展开。

## 我不能做的（别吹，明确说不能）
- ❌ **不能替你自动私信客户**——平台风控红线，搞不好封号。我只给名单，私信你手动来。
- ❌ **不能帮你自动发抖音/养号**——同上。
- ❌ **不报价、不谈商务**——价格套餐是大鹏老板和商务定的，我不清楚就说不清楚，可以帮你问。
- ❌ **不保证成交**——我帮你找到精准的人、省搜的时间；聊天转化靠你的服务。

## 合规口径（别替公司打法律包票）
只**陈述事实**，别拍胸脯：
- 我们只采集抖音**公开评论**（昵称、评论原文、主页链接都是公开信息），**不碰私信、不扒隐私、不倒卖数据**。
- 爬虫用**专用小号**，不是主号；小号被限流/封了换一个就行。
- 真正的红线是：别拿数据**骚扰**（凌晨批量打电话/发短信）、别**倒卖**。正常真诚私信触达 = 正常商业行为。
- ⚠️ 别说"绝对合法""同行都这么干"这种替公司兜底的大话。

## 故障排查（爬不出数据时这么说）
1. 先问/提醒：**Tang 的 Mac 开机联网了吗**？（爬虫在 Mac 住宅 IP 上跑）
2. 其次：**抖音 Cookie 可能过期**了 → 提醒"重新扫码登录"。
3. 再次：关键词太偏，换个更主流的词。
4. 自己拿不准就说"我去查下任务状态"，**别编"在爬了/马上好"**。


## IP12 Agent 开发踩坑（2026-08-30 ~ 31 上站实录）

### 模型层
- **DeepSeek 不支持 `response_format: json_schema`**（报 "This response_format type is unavailable now"）→ 一律降级 `{"type":"json_object"}`（call_ai 与评估引擎都要降级）。
- **长连接共享 client 跑长评估必断连**（APIConnectionError/TimeoutError 大量出现）→ 每个 case 独立 httpx client + Connection/Timeout 重试 5 次、10s 退避。
- **Luna 反复过不了 harness 语义校验**（模块 3"必须直接提炼候选关键词"）→ 换 DeepSeek；对话自然度问题再换 `deepseek-v4-flash`（小雀模板验证过的模型）。
- **DeepSeek 写口播文案偏短**（246/226/218 < 250 下限）→ 3 次重试 + 目标字数提高到 260–350。

### 状态机 / harness
- **模板句机械重复**的根因不是模型：是 harness 用「正则话题识别 + 模板句覆盖」把模型回复强行替换成固定句（`intake_natural_question` 覆盖路径）。→ 删模板覆盖，保留账本；模型措辞全保留，只有"重复问已答项"才 repair。
- **模型看不到未确认进度**（pending.profile_updates 不投影）→ 反复追问已收集字段。→ `confirmed_input_projection` 加 `pending_collected` + 人类可读摘要注入。
- **三选一候选标题超 24 字**反复失败 → prompt 给短标题示例 + 服务端截断保底（长度类错误可安全修正）。
- **口头标题选择错位**（选"实战能力型"记成"个人经历型"）→ 选项标题精确匹配快路。
- **PDF 页数质检 6–8 页**：模块间强制分页导致 9 页超限 → 紧凑档去掉强制分页 + 压缩边距。
- **图片生成被误拒**三层：语义直答拦截 → production_intent 缺 harness fallback → 文生图被错误要求绑文案。→ 生产意图优先于语义直答 + `image-generate/video-generate` 进 `_SOURCE_FREE_ACTIONS`。

### 工程
- **SDK 工具跑在 Runner 异步上下文，无 Flask request context** → `owned_conversation` 静默失败导致工具层会话复用失效（多轮选择断联）→ 会话读写改文件级。
- **注入 prompt 的 f-string 变量必须定义**（漏定义 `style` → NameError 500）。
- **`_confirmed_scripts` 要 null-safe**：生产会话 `deliverables["6"]` 可能为 None → 500。
- **hq CLI token 每 8 小时过期** → `hq login --json` 设备授权流（浏览器输码）；自动续期需黄雀账号密码（`HQ_WEB_USERNAME/PASSWORD` 尚未配置）。
- **产物 media 渲染不带链接文本**：URL 全收结构化 `media` 载荷，前端渲染封面+播放器，防止裸链接与签名丢失。

### 经验
- 诊断流程是「查表机 + 模型填空」的混合体；**机械感 = 模板覆盖路径在作怪**，放权给模型后对话质量立刻对齐真人。
- 模型行为不可靠时，先查"模型看到了什么上下文"，多数"模型不听话"其实是**上下文没喂对**。
