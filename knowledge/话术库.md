# 话术库（私信破冰 / 锁客 / 升单）

> 这些是**参考模板**，用的时候按对方的行业、项目、城市改。别原样复制，要像真人。

## 转化三步法
1. **筛选**——从名单里挑语气真诚、有具体需求的（不是"dd""加v"这种敷衍的），优先指名道姓提到痛点的。
2. **私信破冰**——提对方的原话痛点 + 自报家门 + 给个低门槛钩子（免费体验/参考），别一上来硬推销。
3. **锁客 → 升单**——先用低价引流项目把人拉到店，到店再升高利润项目。

## 私信破冰模板
**通用**：
> 姐妹，看你之前在问【对方原话痛点】～我是XX路开【店类型】的，最近有【免费体验/活动】，发你几个参考？不消费也没关系～

**美甲店**（找客人，C端）：
> 看你在找美甲推荐呀～我在XX路开美甲店，这周有新款上新，9.9 体验款要不要试试？发你款式图参考～

**瑜伽馆**（找学员，C端）：
> 看你想学瑜伽呀～我这边瑜伽馆在XX路，有**免费体验课**，不限基础，练完觉得合适再说～

**美容院/瘦脸瘦身**（C端）：
> 看你在问瘦脸有没有效果～我们店做面部提拉项目，先体验看效果再决定，姐妹你在XX区方便到店吗？

## 锁客 + 升单
- **引流款**：首次 9.9 / 19.9 基础项目（基础美甲 / 体验课 / 基础护理）——目的是**把人拉进门**。
- **升单**：到店后服务好 + 推高利润项目（延长甲·款式设计 / 私教课·长期卡 / 抗衰·套餐）。
- 核心：**进门是第一步，到店的服务和环境才是转化根本。**

## 运营/IP/传播（群里也常被问，给方向不瞎承诺）
- **门店拓客**：评论区获客 + 美团9.9引流 + 老客转介绍（带朋友双人送）。
- **老板IP**：每天发同城抖音，选题如"XX元能做哪些项目""门店老板的一天""教你分辨A和B"，带同城定位+话题标签。
- **朋友圈**：别天天发广告，发经营日常/顾客反馈/限时福利，看起来像"真实的人"。
