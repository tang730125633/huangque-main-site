# 获客系统（我的核心产品，必须门儿清）

## 两种模式
1. **关键词获客**：行业关键词 → 搜抖音视频 → 扒评论区 → **过滤出精准客户名单**（昵称 / 抖音号 / 属地 / 需求原话 / 主页链接）。
2. **账号深扒**：账号主页链接 → 拉**画像 + 全部作品 + 评论** → 导出 xlsx。

## 我怎么调用（工具用法详见 TOOLS.md）
群友说"爬一下 XX 的客户" → 我跑 `leadgen.py "关键词" --count N` → 等爬完 → 把名单整理成飞书消息发回。

## 操作规格（真实数据，别编）
- **爬 10 个视频约 1-3 分钟**，能出 **20-40 个客户**。
- 一次别贪多；要更多就多爬几个相关词。
- **爬不出数据 = 三个原因**（按概率）：
  1. **Tang 的 Mac 没开机/关机了**——实际爬虫跑在 Mac 住宅 IP 上，Mac 不在线就爬不了。
  2. **抖音 Cookie 过期**——需要 Tang 重新扫码登录（提醒他"重新扫码"）。
  3. **关键词太偏**——搜不到足够多的视频。

## 真实过滤逻辑（我们就是这么干的，别编别的）
- **剔除**（同行 / 中介引流话术）："需要我推荐""推荐给你""先帮店做出业绩""做出业绩再合作""不需要店家出成本""0成本启动""免费送模式""感兴趣的老板""一起交流交流""下店来打版"。
- **保留**（真实需求信号）：
  - **B端意图**："怎么拓客 / 怎么收费 / 多少钱 / 求带 / 想学 / 求推荐 / 没开单 / 求助"
  - **C端意图**："有效果吗 / 会反弹 / 能瘦吗 / 痛吗 / 维持多久 / 怎么预约 / 想做 / 多少钱一次 / 在哪做"
- ⚠️ **不是**靠"新号 / 乱码名 / 高频评论"判断 —— 我们**没做**这些，别瞎说。

## 架构（对外只讲到这层，别报 IP/账号/密码）
- 混合架构：**云端**（服务器）跑队列+网页+我；**爬取**跑在 Tang 的 Mac（住宅 IP）。
- 为什么要住宅 IP：抖音**搜索接口封机房 IP**，必须住宅 IP 才扒得到。
- 配套**网页**伙伴可自助用（口令内部给）。
