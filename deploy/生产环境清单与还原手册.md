### Hermes IP12 完整服务

服务器的 `/home/ubuntu/.secrets/hermes-openai.env` 必须明确配置
`HERMES_DEPLOY_USER=ubuntu` 和 `HERMES_DEPLOY_GROUP=ubuntu`。发布脚本会用该账号、
用户组及 `0700` 权限创建私有备份目录。若回滚任一步骤失败，脚本以 `125`
退出并输出 `manual recovery required`、备份路径和失败步骤；此时不得继续发布，
须按输出的备份路径人工恢复并重新执行健康检查。

```bash
# 只从待发布的确切 Git commit 导出，避免把本机 ignored 运行数据带上服务器。
HERMES_SHA=$(git rev-parse HEAD)
HERMES_STAGE=$(mktemp -d)
HERMES_REMOTE_STAGE="/tmp/hermes-ip12-release-${HERMES_SHA}-$(date +%Y%m%d%H%M%S)-$$"
git archive "$HERMES_SHA" -- \
  server/hermes_ip12 \
  scripts/migrate_hermes_artifacts.py \
  deploy/hermes-ip12-release.sh \
  deploy/systemd/hermes-ip12-preview.service \
  deploy/nginx-hermes-ip12-direct.conf \
  deploy/nginx-huangquechuanmei.conf | tar -x -C "$HERMES_STAGE"
test -f "$HERMES_STAGE/scripts/migrate_hermes_artifacts.py"
test -f "$HERMES_STAGE/deploy/hermes-ip12-release.sh"
python3 -m py_compile "$HERMES_STAGE/scripts/migrate_hermes_artifacts.py"
chmod 0755 "$HERMES_STAGE/deploy/hermes-ip12-release.sh"
ssh dapeng-server "mkdir -p '$HERMES_REMOTE_STAGE'"
rsync -a "$HERMES_STAGE/" "dapeng-server:$HERMES_REMOTE_STAGE/"

# 覆盖前备份代码、systemd/nginx 配置和服务状态。发布脚本从停机开始
# 安装统一 EXIT trap；迁移、rsync、依赖、配置或任一健康检查失败都会
# 自动恢复旧代码/配置、daemon-reload，并恢复发布前的服务状态。
ssh dapeng-server \
  "HERMES_SHA='$HERMES_SHA' HERMES_RELEASE_DIR='$HERMES_REMOTE_STAGE' \
  bash '$HERMES_REMOTE_STAGE/deploy/hermes-ip12-release.sh'"
```

## 四-B、漂移哨兵与部署保护

- 哨兵脚本：`scripts/drift_sentinel.py` → `/home/ubuntu/hq-drift/drift_sentinel.py`。
- 巡检基准：直接比较线上运行文件与服务器 checkout 的 `origin/main`，不再依赖上次 `--bless` 的线上快照。
- 合法部署：`./ship` 在 rsync 后会执行 `drift_sentinel.py --verify-deploy <本次文件>`，确认本次部署文件线上内容等于 git。
- 部署记录：`./ship` 只用 `--bless-deploy <本次文件>` 记录本次文件清单，不会把整站当前线上状态吞进基线。
- 服务器 checkout：`./ship` 会给 `/home/ubuntu/huangque-main-site` 安装 pre-commit 拦截钩子，禁止在服务器 checkout 直接提交热改。

手动巡检：

```bash
python3 /home/ubuntu/hq-drift/drift_sentinel.py --print
```

## 五-B、DNSPod WebBlock 单次只读检测

`scripts/domain_access_check.py` 每次只执行一次 HTTP 首跳和 HTTPS 最终状态检测，输出 JSON；它不会修改 DNS/Nginx、自动修复或持续监控。

```bash
python3 scripts/domain_access_check.py --domain huangquechuanmei.com --timeout 10
```

- 退出码 `0` 表示本次检测通过；`1` 表示命中 WebBlock、异常跳转、HTTPS 异常或网络错误。
- 应从无 hosts 覆盖、实际受影响的网络运行；单次 `OK` 不能证明间歇问题已消失。
- 命中 `DNSPOD_WEBBLOCK` 时，保存检测时间、网络地区和 JSON 结果，再到腾讯云核对备案及当前接入关系。服务器或解析地址以实时清单为准，不在此处写死。
