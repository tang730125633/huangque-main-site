## 队列 1 · 文案 bot2-10 批量收口（最快最划算）⏳ 进行中

**对象**：`.openclaw-second` 实例（main=文案策划 + bot1-10），全是纯 LLM 写稿、**不需任何工具**。
**机制**：`tools.profile=minimal`（砍 exec/read/fs/runtime）+ `deny` 黑名单兜底。回飞书靠 automatic 自动投递，**不需 alsoAllow**（和爬取/图片号不同——它们要装回能力按钮，文案号什么都不装）。
**做法**：设 `agents.defaults.tools`（一刀覆盖 main + bot2-10；bot1 已有自己的配置，效果相同）→ 重启 openclaw-second 一次。
**验收**：抽样 bot2/bot5/bot10 红队随机串扒不出 + 能正常写文案。

```bash
# 在 .openclaw-second 上：
OPENCLAW_CONFIG_PATH=~/.openclaw-second/openclaw.json openclaw config set agents.defaults.tools.profile minimal
OPENCLAW_CONFIG_PATH=~/.openclaw-second/openclaw.json openclaw config set agents.defaults.tools.deny '["fs","runtime","read","exec","write","edit","process","apply_patch","code_execution","cron","gateway","nodes","browser","subagents","sessions_spawn","sessions_send"]' --strict-json
openclaw config validate ; systemctl --user restart openclaw-second.service
```

## 队列 2 · 图片 v1-10 队列化 + 收口（硬骨头，照小冬套）

**难点**：v-bot 靠 `exec` 跑 `gen_and_send.py`（出图 + 发图，需图片 API 密钥）。
**方案**：写一个"出图按钮" MCP，把 exec 换成 `generate_image(prompt)`：
- 子步骤：
  1. 摸清 `gen_and_send.py` 的调用（API/参数/`chat_id` 从哪来——发图要知道发哪个群）。
  2. 写 `scripts/mcp_douyin_image.py`（MCP server，内部跑出图+发图，密钥服务端持有；异步：`generate_image` 提交 + `image_result` 查/确认已发）。
  3. `openclaw mcp add` 注册到 `.openclaw-visual`。
  4. v-bot 收口：`profile=minimal` + `alsoAllow=[image__generate_image, image__image_result, message]` + `deny=[exec,read,...]`。
  5. 红队随机串验扒不出 + 功能验证真出图真发群。
- ⚠️ 比文案复杂（涉及发文件 + chat_id 路由），按小冬模板小心做、逐个验。
