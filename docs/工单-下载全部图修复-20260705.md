# 工单 · 修「下载全部图」（图文笔记批量下载走下载代理）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》领取流程。
> **冲突组：E-collect（`site/workbench/collect.html`）** —— 抢 `lock/E-collect`。**纯前端。**

## 问题
内容爬取模块抓图文笔记后，点「下载全部图」**不下载、只在新标签页打开一堆图片**（还常被弹窗拦截只弹开第一张）。

## 根因
`collect.html` 里 `galDownloadBtn.onclick`（约 531-540 行）用的是：
```js
imgs.forEach(function(u,i){
  var a=document.createElement('a');
  a.href=u; a.download='img_'+(i+1)+'.jpg'; a.target='_blank';
  a.click();
});
```
`imgs` 是**抖音/小红书图片 CDN 的跨域 URL**。HTML5 `download` 属性**只对同源生效**，跨域时被浏览器忽略 → 直接导航打开图片而非下载。对比「下载无水印视频」（约 517 行）走的是 `/api/gen/dl` 代理，所以视频能下、图片不能下。

## 改动（只改 `site/workbench/collect.html`）
把批量下载改成**每张图走同源下载代理** `/api/gen/dl`（强制 attachment + 代理绕防盗链）：
```js
a.href = '/api/gen/dl?url=' + encodeURIComponent(u) + '&name=' + encodeURIComponent('img_' + (i+1));
// 去掉 a.download 依赖跨域（改由 dl 代理的 Content-Disposition 强制下载）；target/rel 可保留
```
- 建议**逐张间隔一点点**触发（如每张间隔 200~300ms，用 setTimeout 顺序触发），避免浏览器把连续多个下载当弹窗拦截。
- 文件名 `name` 传 `img_N`，后端 dl 会拼后缀/走 Content-Disposition。

## 无需改后端
图片 CDN 域名（`.byteimg.com` / `.douyinpic.com` / `.douyinstatic.com` / `.xhscdn.com` / `.rednotecdn.com` 等）**已在 `/api/gen/dl` 的 ALLOW 白名单里**（#116/#120）。若实测某图片域名被拒 400，再按 #120 的方式补白名单（那会变成跨组，另议）。

## 验收标准
1. 抓一条**抖音图集**或**小红书图文笔记** → 点「下载全部图」→ **每张图都真下载到本地**（不是打开标签页），文件名 `img_1.jpg`…。
2. 张数多时不被弹窗拦截（间隔触发生效）。
3. 单张点击预览（点缩略图）仍能在新标签打开原图（保留原 gallery 预览行为）。
4. 视频「下载无水印视频」不受影响。
