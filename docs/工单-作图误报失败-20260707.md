# 工单 · 作图误报「生成失败」实际成功（Issue #317）

> 冲突组：**E-banana（`site/workbench/banana.html`）**，可能涉 A（后端状态/轮询）。抢 `lock/E-banana`。先读 §0+看板+DESIGN.md。

## 现象
作图页生成，前端提示「生成失败」，但刷新资产库发现图**其实已成功入库**。误判失败误导用户。

## 根因方向（需排查）
- 前端轮询**超时时间不够**：后端还在处理，前端超时就显示"失败"（应显示"生成中/请稍后到资产库查看"）。
- 或状态同步拿到中间态(processing)误判 failed。
- 作图慢（今天泽龙中转 image 中位耗时长、45%失败里含超时），前端超时阈值可能偏短。

## 待做（banana.html 轮询逻辑）
1. **轮询超时不要显示"失败"**，改显示「生成中，请稍后到资产库查看」（区分"真失败 error/failed"与"还在处理/超时"）。
2. 只在 job 状态**确实是 error/failed** 时才提示失败；pending/running/超时 → 提示处理中。
3. 适当**调长轮询超时**（对齐后端 image 实际耗时，今天中位数偏长）。
4. 可选：轮询结束后主动查一次资产库/job 终态，避免"已成功却提示失败"。

## 验收
1. 生成成功→前端显示成功、结果区出图，不再误报失败。
2. 真失败才提示失败；超时显示"生成中，请查资产库"。
3. 慢生成（超前端超时）不再误判失败。
