# 工单 · COS 客户素材私有化 + 产物接口鉴权（#185 P0·隐私红线）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》+ `DESIGN.md`。
> **冲突组：A（`server/content_domains/{cos,core,image}.py`）+ 多前端页（tryon/结果展示相关）** —— 跨组大工程，抢齐所占组锁。
> ⚠️ 涉及生产 COS 与前端展示链路，**分阶段、别一次性改崩现有直链**。踩 PIPL/个保法红线，优先级 P0。

## 现状核实（2026-07-06，别照抄 issue 原文）
- ✅ **匿名 List 已禁**：`GET bucket?list-type=2` 返回 403 —— **不能枚举遍历**全部对象（issue 说的"可枚举"实际做不到，风险比原描述低）。
- ❌ 剩余风险：
  1. 对象键**可猜测**（`img_<毫秒>_<i>.png`、`collect/<platform>/<id>.mp4` 时间戳/ID 型），猜中即匿名可下。
  2. 换装换背景(含**真人人脸**)、克隆语音样音、上传参考图 落在 **public-read** 桶、可直链下载。
  3. 源站 `/api/gen/file/<rel>`、`/api/gen/dl` **无 token、无归属校验**。

## 目标（kongli 定的分级策略：敏感私有、普通公开，不破坏分享体验）
### 1. 敏感真人素材走私有 + 预签名短链
- **换装换背景(tryon)输出/输入、克隆语音样音**等含真人隐私的产物：上传时对象设**私有 ACL**（或走独立私有前缀/子桶），产出 URL 用 **COS 预签名短链**（`COS_PUBLIC=0` 代码已支持，限时有效）。
- 普通作图/采集图 **保持公开直链**（分享/发飞书体验不变）。
- 需要一套"哪些 kind/字段算敏感"的判定，集中在 `cos.py`/产出封装处。

### 2. 对象键加不可猜随机段
- 新产出对象键插入 **uuid/随机段**（如 `img_<uuid>.png`、`tryon/<uuid>.mp4`），杜绝时间戳猜测。老对象不动（迁移成本高，靠下面接口鉴权兜底）。

### 3. 产物接口加鉴权 + 归属校验
- `/api/gen/file/<rel>`、`/api/gen/dl`：加 **token 校验**（复用现有 verify）+ **归属校验**（该资源属于该用户 / 或公开白名单前缀才放行）。
- 敏感素材必须经此鉴权或预签名，不能裸直链。

### 4. 留存/授权策略
- 补真人素材的留存期限与用户授权说明（产品/合规侧，至少留 TODO 与文档）。

## 边界与注意
- **分阶段**：先做接口鉴权 + 新键随机段（不破坏现有直链），再逐步把敏感素材切私有+预签名（需前端配合改展示）。
- COS ACL/policy 改动**先在测试对象验证**，别一把改桶级导致存量直链全挂。
- 前端展示敏感素材处改走鉴权接口/预签名 URL；注意缓存戳、DESIGN.md。

## 验收标准
1. 未登录/非归属用户**无法**通过猜测 URL 或接口拿到他人**真人**素材（换装人脸/克隆语音）。
2. 敏感素材走鉴权或预签名短链；普通作图/采集图分享体验不受影响。
3. 新产出对象键不可猜；`/api/gen/file`、`/api/gen/dl` 有 token+归属校验，非法访问被拒。
4. 存量直链不被改崩（或有平滑迁移）；各服务 health 正常。

## 部署与验证
- 后端 `cos.py`/`core.py`/`image.py`→content-api；前端相关页→webroot。分阶段部署、每阶段验证。
- 实测：伪造/枚举 URL 拿不到真人素材；正常用户功能与分享不受影响。
