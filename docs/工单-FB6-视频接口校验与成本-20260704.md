# 工单 · FB6 视频生成接口校验 + 成本（Issue #60 qilin 审计）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 + 《任务看板》。
> **冲突组：A（`server/content_domains/**`）** —— 抢 `lock/A`。

## 问题
`POST /api/gen/video`：部分坏参数**没在提交阶段拦截**，仍返回 200 + job_id、进后台流程（随后失败），污染任务记录；且**视频成本显示为 0**。

## 要修（`content_domains/core.py` 提交入口 + `video.py`）
### 1. 提交前校验，坏参数直接 400、不创建 job
在写入任务（INSERT job）**之前**统一校验视频请求体，任一失败返回 400、不产生 job_id、不进后台：
- 空体 → `400 image_data 不能为空`
- 非法 JSON → `400 请求体不是合法 JSON`
- 错误 `mode` → `400 mode 仅支持 text/audio/motion`
- 无效图片 dataURL → `400 image_data 不是有效的人物形象图片`（基础校验 dataURL 头/base64 可解）
- `mode=text` 缺 `voice` → `400 mode=text 时 voice 必填`
- `mode=audio` 缺 `audio_data` → `400 audio_data 不能为空`
- 不支持的 `ratio/resolution/motion` → `400` 并说明允许值
> 注：现有 `gen_video` 里有 mode 校验，但发生在 **run_job（建 job 之后）**。要把校验**前移到提交端点**，坏参数不建 job。

### 2. 视频成本不再是 0
- `COST` 里 `video` 从 0 改为可配置正值（**建议 20，上线前和 kongli 确认**）；口播/动作模仿走此成本；失败退点（现有机制）。
- 注：换装换背景(tryon)成本 F8 已定 40/25，不动它。

### 3. 失败时同步资产状态
- 后台任务失败时更新 video_assets 状态，避免前端一直显示"生成中"。

## 边界
- 只改校验前移 + 成本 + 失败态同步；不改生成核心（HeyGen/whisper）。基于 T8 后结构。

## 验收标准
1. 各类坏参数在提交阶段返回 400、**不产生 job_id**、不进后台。
2. 正常视频任务按成本（默认 20）扣点，失败退点。
3. 任务失败时资产状态更新为失败（前端不再卡"生成中"）。
4. 口播/动作模仿/换装换背景正常；`py_compile` 通过、health 200。
