# 工单 · 果肉视频画面比例（用 size 正确重做，替代被拒的 aspect_ratio）

> 冲突组：**A（`server/content_domains/video.py`）+ B（`site/workbench/video.html`）**。抢 `lock/A`+`lock/B`。先读 §0+看板。

## 背景
果肉视频（Grok）加画面比例的第一版（VID-GROK-RATIO #361）用了 `aspect_ratio` 参数，但 **Grok/Seedance 视频模型不支持该参数**，每次生成 HTTP 422，导致 #367 生产故障，已热修撤掉（#368）。

**本工单用 API 真正支持的 `size` 参数正确重做。**

## 实测依据（已验证，勿再假设）
对 `Grok Image Video` 模型逐参数实测（`/api/v1/generations`）：
- ❌ `aspect_ratio`/`quality`/`n` → 模型级拒绝「当前模型类型不支持参数」
- ❌ cfg_scale/duration/fps/height/motion/negative_prompt/response_format/seed/style/width → `extra_forbidden`（schema 无此字段）
- ✅ **`size` → 接受**，实测三个值全部 200 起片：
  - 9:16 竖版 → `size:"720x1280"` ✅
  - 16:9 横版 → `size:"1280x720"` ✅
  - 1:1 方形 → `size:"1024x1024"` ✅
- ✅ `duration_seconds`/`mode`/`reference_images` 支持（现有代码已用）
- ⚠️ `resolution` 认识但值受限（1080p 被渠道拒），本工单不用它
