# 工单 · 影视级模仿预设片段缩略图裁切（Issue #372）

> 冲突组：**B（`site/workbench/video.html`）**。抢 `lock/B`。⚠️ B 组近期被 #374(同事WIP)/#375 频繁改动，领之前先确认 B 空闲、基于最新 main。先读 §0+看板。

## 现象
视频页「影视级模仿(motion)」tab 的预设片段网格（`#motionPresetGrid` / `.motion-preset-card`），缩略图被**横版卡片裁切**，竖版预览不直观。

## 根因
预设缩略图**方向不一**（竖版/横版混）：
- `gesture-01` 576x1024（竖）、`gesture-02` 720x406（横）、`gesture-03` 720x1280（竖）
- 但卡片 CSS 写死横版裁切：`.motion-preset-card img{width:100%;height:94px;object-fit:cover;}`
- 固定 94px 高 + cover → 竖版缩略图上下被裁掉大半，看不出内容。

## 待做（P2 视觉，前端 CSS 为主）
作者给了三个方案，按性价比推荐 **方案 A**（纯 CSS，最省）：
- **方案 A（推荐）**：卡片随缩略图真实比例展示——
  ```css
  .motion-preset-grid{ grid-template-columns:repeat(auto-fit,minmax(128px,1fr)); }
  .motion-preset-card{ min-height:auto; }
  .motion-preset-card img{ aspect-ratio:9/16; height:auto; object-fit:cover; }
  ```
  竖版为主统一按 9:16 展示，横版个别用 contain 或接受轻微留白。
- 方案 B（更稳但要数据）：`assets/motions/index.json` 每条加 `ratio`/`orientation`，前端按方向加 `.is-portrait`/`.is-landscape` 决定 aspect-ratio。
- 方案 C：cover+blur 背景 或 contain 留白。

先做 A；若横竖混排 A 效果不佳，再上 B（数据驱动）。

## 验收
1. 竖版预设缩略图不再被裁切/能看清内容；横版不崩。
2. 不影响预设选择/上传/生成逻辑，不回退 video.html 近期功能（#333/#349/#375/#276/#302）。
