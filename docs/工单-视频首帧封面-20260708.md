# 工单 · 视频统一首帧封面 + 历史数据修补（Issue #365）

> 冲突组：**A（`server/content_domains/video.py`）+ 运维(装 ffmpeg)+ 一次性修补脚本(F)**。抢 `lock/A`。先读 §0+看板。

## 现象
资产库视频卡片，部分视频（尤其 motion/tryon）**无封面缩略图**，显示黑色占位/播放图标。

## 现状（已修的 + 没修的）
- **已修**：bg_only 换背景视频无封面 → 封面用背景图（VID-TRYON-COVER #338/#346）。
- **仍不理想**：
  1. bg_only 用的是**背景图**而非视频首帧，不够直观（用户看不出视频内容）。
  2. **历史数据**：#338 修复前入库的视频，`image_file` 字段仍为空 → 老视频还是无封面。
  3. 各模式封面来源不统一（口播用人物图/tryon 用衣服或背景图）。

## 待做
1. **视频生成完成后自动提取首帧作封面**（ffmpeg）：
   - `ffmpeg -i <video> -vframes 1 -q:v 3 <cover>.jpg`（截第一帧，或第 1 秒 `-ss 1` 避免纯黑开头）。
   - 落盘 + `public_url` 走 COS，写入 video 资产的 `image_file`/`image_url`。
   - 统一所有视频模式（口播/motion/tryon/果肉），封面 = 视频首帧，最直观。
   - ⚠️ 先确认服务器装了 ffmpeg（`which ffmpeg`），没有则运维装（这步也为 VID-PLAY-SLOW P2 转码铺路）。
2. **历史数据修补脚本**（一次性，F 组）：扫 content_jobs 里 `image_file` 为空的已完成视频，对每条用 ffmpeg 补生成首帧封面 + 回填字段。注意限速、只补公开产出、幂等可重跑。

## 验收
1. 新生成的各模式视频，资产库封面 = 视频首帧（非黑屏、非无关图）。
2. 跑修补脚本后，历史无封面视频也有了首帧封面。
3. 不影响播放/下载/#354 弹窗加载优化。

## 部署
- 装 ffmpeg（运维）→ 改 video.py → ship（重启 content）→ 各模式实测封面。修补脚本单独跑。完成关 #365。
