# 工单 · 轮询只判 error 漏 failed → 失败任务卡"进行中"（Issue #391）

> 冲突组：**B（video.html）+ E-audio + E-canvas + E-leads + E-script**（5 个前端页同病）。多组，按页分批领或一起锁。先读 §0+看板。

## 现象/根因（已核实）
视频任务失败后前端一直显示「生成中」直到 30 分钟超时。根因：`pollJob()` 只判 `status==='error'`，**没判 `status==='failed'`**。而**后端确实会产生 `failed`**：
- core.py:787 任务异常 → `status="failed"`
- core.py:978 队列满 → `status="failed"`
- video.py:696/1537 也用 `{failed,error}`

失败任务返回 `failed` 时前端不识别 → 继续轮询最多 600 次(30分钟)才停 → 卡"生成中"。

## 同病页面（都只判 error,需一起修）
- `video.html:1316` `if(d.status==='error')`
- `audio.html:243`、`canvas.html:1864`、`leads.html:301`、`script.html:257`

## 待做
每处失败判断加 `||d.status==='failed'`（防御性,兼容两种失败态）：
```js
if(d.status==='error'||d.status==='failed') throw new Error(d.error||'生成失败');
```
逐页核对具体写法（有的是 `throw`、有的 `clearInterval+rej`），改法一致即可。

## 验收
1. 后端返回 failed 的任务,前端及时显示「失败」+退点提示,不再卡 30 分钟。
2. 5 个页面都覆盖。
3. 不影响正常 done/进行中流程。
