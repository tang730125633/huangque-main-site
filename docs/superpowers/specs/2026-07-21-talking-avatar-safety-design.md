# 数字人口播素材准入与授权设计

## 范围

修复 BUG-0026～BUG-0029，覆盖单人口播、批量口播、形象创建和已有形象复用。

## 设计

- 浏览器在预览前校验 MIME、文件头和 8MB 上限。
- 服务端重新校验 Data URL、真实文件签名和大小，并用视觉模型执行“单个清晰真人正脸”审核。
- 审核发生在扣点和建任务前；审核服务异常时拒绝受理且不扣点。
- 新形象只有审核及 HeyGen 创建均成功后才进入 ready；旧形象首次使用时复审，失败标记 invalid 并从形象列表隐藏。
- 口播和形象创建均强制用户确认肖像/声音授权，任务 payload 保存确认版本与时间。
- 网络失败转成中文提示，保留输入并展示重试按钮；重试复用 Idempotency-Key。

## 非目标

- 不自动删除历史形象文件。
- 不修改点数价格，不部署生产环境。
