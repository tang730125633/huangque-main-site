# 文案编导完整链路修复设计

## 范围

修复 BUG-0017～BUG-0021：上游 404、行业选择、分镜编辑保存、换一版与版本追溯、未生成时误展示演示结果。

## 设计

- OpenAI 兼容地址统一规范化，兼容 base 已包含 `/v1` 的部署配置。
- 行业作为生成参数和历史元数据持久化。
- 成功的 copy 任务继续作为脚本版本正本；换一版创建新付费任务，并记录归属校验后的 `parent_job_id` 与服务端计算版本号。
- `PUT /api/gen/copy/{job_id}` 仅允许本人修改已完成的分镜脚本，并同步统一资产历史。
- 页面启动时展示空状态，真实结果产生前禁用复制、导出、保存和下游转换。
- 高风险违法/绕过安全措施的明确意图在扣点和建任务前拒绝。

## 非目标

- 不新增数据库表，不迁移既有任务。
- 不修改点数规则，不部署或重启生产服务。
