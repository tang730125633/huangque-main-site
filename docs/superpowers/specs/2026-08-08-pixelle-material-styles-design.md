# Pixelle 素材风格选择设计

## 目标

在“文案成片”工作台中增加素材视觉风格选择。用户手动选择一种风格后，整条视频的所有图片或视频素材统一使用该风格。风格控制与视频模板、画幅和输入方式相互独立。

本次仅增加受控预设，不支持用户输入任意提示词，不支持逐分镜选择风格，也不为每种风格维护独立生成工作流。

## 用户体验

“视频模板”区域下方增加“素材风格”下拉菜单，不展示缩略图。菜单提供以下 10 个预设：

| 风格键 | 展示名称 |
| --- | --- |
| `realistic_commercial` | 写实商业 |
| `cinematic` | 电影质感 |
| `future_tech` | 科技未来 |
| `healing_fresh` | 治愈清新 |
| `chinese_illustration` | 国风插画 |
| `cartoon_3d` | 3D 卡通 |
| `retro_film` | 复古胶片 |
| `minimal_line` | 极简线稿 |
| `medical_beauty` | 医美高级感 |
| `ecommerce_product` | 电商产品广告 |

默认选择“写实商业”。切换模板、横竖屏或输入方式时保留当前风格；重新打开页面时恢复默认值，不增加本地持久化。

生成请求必须包含风格键。该键也参与现有幂等请求体计算，用户更换风格后生成的是新任务，不复用旧任务。

## 风格定义

主站后端维护风格白名单及英文 `prompt_prefix`。前端只获得风格键和中文名称，不接收完整提示词，避免客户端篡改生成约束。

每个前缀同时描述画面媒介、光线、色彩、构图和质感，并附加通用限制：不生成水印、品牌标识、乱码文字和畸形主体。首批预设的方向如下：

- 写实商业：真实人物或产品、现代商业环境、自然专业光线、可信广告摄影。
- 电影质感：电影布光、叙事构图、浅景深、克制调色和真实纹理。
- 科技未来：现代 AI 场景、蓝青色科技光、干净界面元素和高级未来空间。
- 治愈清新：明亮自然光、柔和低饱和色、生活化场景和轻盈氛围。
- 国风插画：现代东方插画、水墨与工笔质感、留白和雅致配色。
- 3D 卡通：精致三维角色或物体、圆润造型、柔和材质和明快灯光。
- 复古胶片：模拟胶片颗粒、柔和高光、怀旧色彩和纪实构图。
- 极简线稿：干净线条、有限色彩、大面积留白和信息图式构图。
- 医美高级感：高端医美空间、洁净柔光、自然皮肤质感、克制奢华和可信专业感。
- 电商产品广告：产品主体明确、棚拍布光、材质细节、干净背景和高转化商业构图。

风格提示词不包含具体人物身份、品牌名称、产品功效或文案内容；这些信息仍由分镜提示词提供。

## 数据与接口

### 风格目录

`server/content_domains/pixelle_video.py` 增加单一风格目录，保存 `key`、`name` 和 `prompt_prefix`，并提供只返回 `key`、`name` 的公开读模型。

新增已认证接口：

```text
GET /api/gen/text-video/styles
```

响应包含：

```json
{
  "styles": [
    {"key": "realistic_commercial", "name": "写实商业"}
  ],
  "default_style": "realistic_commercial"
}
```

接口不得返回 `prompt_prefix`。

### 生成请求

前端向现有 `/api/gen/script_to_video` 请求增加：

```json
{"style": "realistic_commercial"}
```

`prepare_payload()` 在任务创建和扣点前完成白名单校验；缺省时使用 `realistic_commercial`，非法值返回“请选择有效的素材风格”。准备后的任务负载保留风格键。

`_submit()` 根据风格键从服务端目录读取 `prompt_prefix`，传给 Pixelle `/api/video/generate/async`。现有图片与视频工作流选择逻辑保持不变。Pixelle 已在同步和异步视频请求中支持 `prompt_prefix`，无需修改生成服务器协议。

任务结果和资产元数据记录风格键，便于问题定位和后续复用，但不记录或回传完整前缀。

## 前端结构

风格控件使用标准下拉菜单，适合 10 个互斥选项。控件包含可访问名称“素材风格”，选项文本仅显示中文名称。

页面加载时并行读取模板目录与风格目录。模板目录失败时保持现有阻断行为；风格目录失败时禁止生成并显示“素材风格暂不可用”，不能静默提交未校验的前端默认值。

提交期间锁定生成按钮，风格下拉菜单可保持当前值；提交载荷使用点击生成时读取到的风格键。

## 错误处理与安全边界

- 风格白名单由后端单点维护，前端不能提交自定义 `prompt_prefix`。
- 非法或删除后的风格键在扣点前拒绝。
- 风格目录加载失败时不允许创建生成任务。
- 服务端只向 Pixelle 发送目录中预定义的前缀。
- 图片和视频模板均使用同一风格键，但继续使用各自正确的媒体工作流。
- 不在日志、任务结果或前端接口中暴露完整风格提示词。

## 验证

- 后端单元测试校验 10 个唯一风格、默认风格、公开目录不泄露提示词。
- 准备层测试校验缺省值、合法风格和非法风格在扣点前拒绝。
- 提交层测试分别使用图片模板和视频模板，断言两者收到相同的选定 `prompt_prefix`，同时仍使用各自正确的媒体工作流。
- 页面测试校验下拉菜单从已认证接口加载、选中值进入生成及幂等请求体、风格目录失败时禁止生成。
- 浏览器验证桌面和移动视口的控件布局、10 个选项、选择保持，以及实际请求体中的风格键。

## 非目标

- 不支持逐分镜风格。
- 不支持用户自定义风格提示词。
- 不展示风格缩略图。
- 不新增或切换 RunningHub 工作流。
- 不修改计费、配音、字幕、素材上传或模板预览功能。
