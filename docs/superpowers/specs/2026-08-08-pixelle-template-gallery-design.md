# Pixelle 模板图片库设计

## 目标

把文案成片页当前的文字模板列表改成图片模板库，并补齐 Pixelle 已提供的插画竖屏、插画横屏和视频模板。

## 模板范围

- 插画竖屏：`1080x1920/image_*.html`，共 20 个。
- 插画横屏：`1920x1080/image_*.html`，共 5 个。
- 视频模板：`1080x1920/video_*.html`，共 2 个。
- 不开放 `asset_*.html`、`static_*.html` 和方形实验模板。

## 后端接口

`GET /api/gen/text-video/templates` 继续返回统一模板数组。每个模板增加：

- `kind`: `illustration` 或 `video`
- `orientation`: `portrait` 或 `landscape`
- `preview_url`: 网站静态预览图地址

模板 key 仍是 Pixelle 的相对 HTML 路径，并继续由后端 allowlist 校验，避免客户端提交任意模板路径。

## 前端交互

- 一级标签为“插画模板”和“视频模板”。
- 插画模板显示“竖屏”和“横屏”二级标签；视频模板当前只有竖屏，不显示无意义的横屏标签。
- 模板以固定比例缩略图卡片展示，卡片包含预览图和模板名称。
- 点击整张卡片完成选择；选中项显示金色描边、勾选标记和可访问状态。
- 切换分类时自动选择该分类中第一项，避免隐藏模板仍被提交。
- 选择横屏模板时，右侧结果预览容器切换为 `16:9`；竖屏模板保持 `9:16`。
- 桌面端按可用宽度显示 4 至 5 列，移动端显示 2 列；模板区独立滚动。

## 静态资源

复用 Pixelle 仓库 `docs/images` 中与开放模板同名的中文 JPG/PNG 预览图，复制到网站静态目录。浏览模板不调用 Pixelle、Playwright 或视频渲染接口，不增加生成服务器运行负载。

## 异常与兼容

- 预览图加载失败时显示模板名称占位，不影响选择和生成。
- 接口返回旧字段时页面仍能显示名称；新增分类依赖新字段。
- 默认模板保持 `1080x1920/image_default.html`，避免改变已有生成行为。

## 验证

- 后端单元测试校验 27 个模板、三种分类组合、尺寸、预览地址和 allowlist。
- 页面静态测试校验分类标签、图片卡片、选中状态和横竖屏容器切换逻辑。
- 浏览器在桌面与移动视口检查缩略图加载、滚动、切换、选中和布局无重叠。
