# Hide Compact Sidebar Logout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hide the avatar logout overlay only when the desktop sidebar is compact, while preserving logout in expanded and narrow drawer modes.

**Architecture:** Keep the existing shared shell structure and remove only the compact-mode CSS override that re-displays `button.hq-user-logout`. Protect the behavior with the existing source-level Node regression suite, then regenerate the shared asset cache stamp across every workbench HTML page.

**Tech Stack:** Vanilla JavaScript, inline CSS generated by `cloud-shell.js`, Node.js test runner, static HTML cache stamps.

## Global Constraints

- Expanded Inspiration sidebar logout remains unchanged.
- Narrow viewport drawer logout remains unchanged.
- Navigation labels, icons, tooltips, and compact sizing remain unchanged.
- Every workbench HTML page must reference the exact content hash of `cloud-shell.js`.
