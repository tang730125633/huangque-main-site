# 工单 · 工作台全局性能：背景动画 + 导航（Issue #389）

> 冲突组：**cloud.js 是 `site/assets/cloud.js` 共享资源（全站页面都加载）**。改动风险低（单文件），但影响全站渲染,ship 后各页抽查。导航 SPA 化属大改归 GROW-FRONTEND(#203)。先读 §0+看板。

## 现象
工作台整体切换/交互迟钝（非单模块）,低配电脑/标签页开久/有视频图片预览时更明显。

## 根因（已核实 cloud.js）
每页都有动态背景 canvas（`.hq-bg > canvas`,公共 `site/assets/cloud.js`）：
- `requestAnimationFrame(frame)` 持续刷新,**无 `visibilitychange` 暂停**（标签页隐藏/切走也在跑,白占主线程+GPU）。
- 每帧双重循环连粒子,复杂度 ~O(n²)（n≤76）。
- `mousemove` 监听无节流,鼠标动就参与计算。

## 待做（P0 轻,cloud.js 自包含优化）
1. **标签页隐藏时暂停动画**：`document.addEventListener('visibilitychange', ...)`,`document.hidden` 时停 rAF,可见时恢复。**最大收益**。
2. **mousemove 节流**（如 rAF 内取样 / 时间节流 ≥50ms),别每次移动都触发计算。
3. （可选）降粒子上限 / 限 FPS（如帧间隔 ≥33ms ~30fps),或空闲时降频。
4. （可选）复用单个全局 canvas 而非每页新建。

## P1（大改,归 GROW-FRONTEND #203,本工单不做）
导航是多 HTML 页跳转（`href="collect.html"` 等）,每次切换全量重载 HTML+脚本+背景+Shell。SPA/局部切换是 #203 前端工程化的活,别在本工单顺手做。

## 验收
1. 标签页切走/隐藏时 CPU 占用明显下降（背景动画停）。
2. 页面切换/滚动手感改善；不破坏背景视觉。
3. 尊重 `prefers-reduced-motion`（现有 `reduced` 逻辑保留）。
