# 工单 · 微衣视频更名「豆姐视频」

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》+ `DESIGN.md`。
> **冲突组：A（`server/content_domains/**`）+ B（`site/workbench/video.html`）** —— 锁 `lock/A` + `lock/B`。

## 背景
kongli 决定微衣视频（Seedance 2.0）正式上线，同时把用户可见的产品名从「微衣视频」改成「豆姐视频」（此前多轮并发压测已验证：无人为可控的下载404问题、内容审核偶发误杀跟提示词内容无关属供应商侧不稳定、429并发限速需要重试~2-3分钟，这些是已知特性非本次改动范围）。

## 改动
纯文案更名，不改内部标识符/接口/计费逻辑：
- `site/workbench/video.html`：所有用户可见文案「微衣视频」→「豆姐视频」（tab按钮/面板标题/生成按钮/modeSummary/modeName/label变量/注释）。内部 `channel==='micro'`、`#microPanel`、`#microPrompt` 等 DOM id/JS 标识符**保持不变**。
- `server/content_domains/video.py`：`XIAOLE_CHANNEL_MODELS` 注释、`_gen_xiaole_media`/完成消息里 `label = {"grok":"果肉视频","micro":"豆姐视频"}`（影响任务完成后展示的状态文案）、相关注释。
- `server/content_domains/points.py`、`image.py`、`core.py`：仅注释里的产品名同步更新，无逻辑改动。

## 已验证
- `python3 -m py_compile` 四个改动的 .py 文件通过。
- `python3 -m unittest discover -s tests` 38/38 通过。
- 全仓库 grep 确认 `site/`、`server/content_domains/` 下无残留「微衣」字样（历史工单文档保留原名，不追溯改）。

## 验收标准
1. 视频页「豆姐视频生成」tab 可正常切换/提交/生成完成，功能与更名前一致。
2. 任务完成后的状态文案显示「豆姐视频生成完成」而非「微衣视频生成完成」。
3. 计费/扣点逻辑不受影响（纯文案改动）。

## 部署与验证
- 改 `server/content_domains/video.py`/`points.py`/`image.py`/`core.py`(A) + `site/workbench/video.html`(B) → ship。部署后公网 vs git 全文对比 + 实测一次豆姐视频生成确认文案+功能正常。完成后本工单可关。
