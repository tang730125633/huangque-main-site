同机已跑 **Dify 全家桶（11 容器）** + **Hermes 小夏 web（:3000）**，部署时均未动。

## A. 深采层：小探（Douyin_TikTok_Download_API）→ 服务器 `:8501`

1. **方式**：弃官方 DockerHub 镜像（国内拉取卡 + 省内存），改 **host venv + systemd**。
2. **步骤**：
   - rsync 本地 `~/code/douyin-scraper` → 服务器 `/home/ubuntu/douyin-scraper`（排除 `.venv/.git/data/logs/Screenshots`）。
   - **cookie 随 `crawlers/douyin/web/config.yaml` 一并搬**（这是采集能跑通的关键，3844 字符）。
   - `python3 -m venv .venv`，`pip install -r requirements.txt`（阿里云源）。
   - systemd 服务 `xiaotan.service`（生产直接启动 Uvicorn、禁用 reload、`Restart=on-failure`、`enable`），端口 8501。
3. **验证**（本机 curl，均 code 200 真实数据）：`/docs`、账号信息、作品列表、评论。
4. **内存兜底**：原机**无 Swap** → 加 2G `/swapfile`（写入 `/etc/fstab`），防 Dify+小探 OOM。

## B. 发现层：MediaCrawler → 服务器无头化（进行中）

> 关键难点：MediaCrawler 要浏览器 + 登录态，服务器无头不能扫码。

破法 = **登录态移植**：
1. 本地 Mac 先正常扫码登录一次，会话存在 `browser_data/dy_user_data_dir`（~99MB）。
2. rsync 把整个项目 + `browser_data/dy_user_data_dir` 搬到服务器 `/home/ubuntu/MediaCrawler`。
3. 服务器配置改 **`HEADLESS = True`**、`ENABLE_CDP_MODE = False`、`SAVE_LOGIN_STATE = True`。
4. 无头复用移植来的登录态 → **服务器不用再扫码**。（抖音 cookie 会过期，过段时间需本地重登一次再同步。）
5. 依赖：服务器 Python 3.10 venv + `pip install -r requirements.txt` + `playwright install chromium`（用 nohup 跑，避免 SSH 断开打断）。

## C. 踩过的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| **CDP 模式连真实 Chrome** | `ws://localhost:9222/devtools/browser 404` | Chrome 149 + Playwright 兼容 bug → 改 `ENABLE_CDP_MODE=False` 标准模式 |
| **Playwright 浏览器缺失** | `Executable doesn't exist ... Chromium` | `playwright install chromium`（标准模式必装） |
| **SSH 长连接装依赖中途断** | 远程 pip 进程被杀、装一半 | 服务器侧 `nohup bash install.sh > log 2>&1 &`，轮询 log |
| **DockerHub 国内拉镜像慢** | 小探官方镜像拉不动 | 改 host venv 本地装，pip 用阿里云源 |

## D. 资源评估

- **磁盘**：剩 ~35G，充足。
- **内存**：Dify 已占大半，剩 ~1.4G + 2G swap。无头 chromium 一次约 300-500M → **单任务串行可跑，禁止并发**，否则挤爆 Dify。规模化建议升 8G。
