## 问题（Issue #138）
数字人口播的 **4 个公共音色**（`audio_voices` 表 `scope='public'`：S_d21F8OR62 温柔女声 / S_l8wE8OR62 活力女声 / S_pa0E8OR62 沉稳男声 / S_xaUB8OR62 亲和女声）`preview_url` **全为空** → 前端只在有 `preview_url` 时才渲染 ▶ 试听按钮 → 用户无法试听。**不是前端 bug，是公共音色缺样音数据。**

## 现有可复用
- `gen_audio` 里对 `S_` 开头的音色调用 **`generate_doubao_preview(voice, text, ...)`**（豆包/火山 TTS）合成、返回 `{file, url}`——按需生成直接复用它。
- COS 已就绪：产出走 `public_url(fn, "audio/mpeg")` 得直链（和其它产出一致）。

## 改动（`server/content_domains/audio.py`，按需生成 + 缓存回填）
在**列音色的地方**（`list_audio_voices` 或 `/api/gen/audio/voices` 组装返回处）：对**公共音色且 `preview_url` 为空**的，**懒生成一次并缓存**：
1. 用固定短样本文本合成：`SAMPLE_TEXT = "大家好，这是我的声音示范，很高兴为你服务。"`，调 `generate_doubao_preview(provider_voice, SAMPLE_TEXT)`。
2. 拿到 file → 走 `public_url(file, "audio/mpeg")` 得 COS 直链。
3. **回填 DB**：`UPDATE audio_voices SET preview_url=?, preview_file=?, updated_at=? WHERE id=?`，这样**只生成一次**、之后走缓存。
4. 返回该音色时带上新 `preview_url`。

## 关键约束
- **幂等/缓存**：只在 `preview_url` 为空时生成；生成后写回 DB，后续调用直接读缓存、不重复合成。
- **非致命**：合成失败**不能让整个音色列表接口报错**——包 try/except，失败就该音色暂时无 preview_url（音色仍可正常用于生成，只是这次没 ▶），下次再试。
- **首次慢可接受**：首次列表可能同步合成几段（tang 也认可"首次慢、之后有缓存"）。若担心阻塞，可只对"被请求到的公共音色"逐个生成、或加简单标记避免并发重复合成（可选优化）。
- 只改后端；前端有了 preview_url，▶ 按钮和播放会自动出现、生效。

## 验收标准
1. 数字人口播的 4 个公共音色都出现 ▶ 试听按钮，点击能播放**该音色**的示范音频。
2. `audio_voices` 里 4 个公共音色 `preview_url` 有值（COS 直链）、文件可访问。
3. 二次加载走缓存、不重复合成（观察不再有新的 TTS 调用/新文件）。
4. 合成失败时音色列表接口仍正常返回（非致命）。
5. `py_compile` 通过、health 200。
