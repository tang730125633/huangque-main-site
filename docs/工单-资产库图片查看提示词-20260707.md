## 现象（#298）
资产库图片资产（文生图）**看不到当时的生成提示词**。点击查看详情只显示图片本身，没有提示词字段/复制入口。用户想回溯和复用优质 prompt。

## 已排查（关键：数据都在，只差 UI，2026-07-07）
- **后端已存 prompt**：`image.py:57` `gen_image` 返回 `"prompt": prompt`；`core.py:1065` 记录资产时带 `"prompt": res.get("prompt")`；列表接口把 prompt 返回给前端。
- **前端已拿到 prompt**：`assets.html` 的图片 `card(x)`（约 line 371）里 `x.prompt` 已可用，但**只截了前 22 字当卡片底部标签**（`p=(x.prompt||'').slice(0,22)`，`white-space:nowrap;overflow:hidden`），无法看全、不能复制。
- **重生成已用 prompt**：line 309 `regenerate` 已用 `x.prompt`（相当于"用此提示词重新生成"已存在）。
- 结论：**只需在图片卡片/详情加"看全 prompt + 一键复制"的 UI**，无需动后端。

## 待做（纯前端，改 `site/workbench/assets.html` 的图片 `card(x)`）
1. **完整查看**：给底部 prompt 文本 `pt` 加 `title=x.prompt`（悬浮看全），或点击 prompt/加「详情」按钮弹出小面板显示完整 prompt（多行、可滚动）。按 `DESIGN.md` 金调，别撑破卡片布局。
2. **一键复制**：加「复制提示词」按钮 → `navigator.clipboard.writeText(x.prompt)` + `toast('已复制提示词',true)`；`navigator.clipboard` 不可用时回退 `document.execCommand('copy')` 或选中文本兜底。
3. **空态**：`x.prompt` 为空（如图生图/局部修改无 prompt）时不显示复制按钮或显示「无提示词」，别报错。
4. **复用**：`重生成` 已是"用此提示词重生成"，工单建议里的第三点已满足，无需另做（如要更显眼可加提示文案）。
5. **XSS**：prompt 是用户/模型文本，进 DOM 必须转义——用 `textContent` 赋值（现有 `pt.textContent=p` 已安全），别用 innerHTML 拼 prompt。

## 验收标准
1. 文生图图片资产能看到**完整**生成提示词（悬浮或详情面板，不只是 22 字截断）。
2. 有「复制提示词」按钮，点击成功复制到剪贴板 + toast 提示。
3. 无 prompt 的图片资产不报错、不显示空复制入口。
4. prompt 文本转义安全（`textContent`，不执行注入脚本）。
5. 不影响资产页其它功能（收藏/标签/重生成/删除/下载/视频/音频卡片）。
