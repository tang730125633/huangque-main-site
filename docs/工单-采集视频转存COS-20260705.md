# 工单 · 采集视频全量转存 COS（永久直链）

> 来自 kongli：采集下载的抖音视频全量转存到腾讯云 COS，返回 COS 永久直链。
> **冲突组：A（`server/content_domains/**`）+ `server/tikhub.py`（共享）+ `server/leadgen_api.py`** —— 抢 `lock/A`（tikhub/leadgen 同属采集链路，一并改）。依赖 COS 已配置（PR #99/#104 已上线）。

## 背景与动机
- 现在 `collect` 采集**只返回抖音/TikHub 的 CDN 直链**（`play_url`），视频不落我们服务器、不走 COS。
- **`play_url` 带时效（详情 1h 内安全，之后过期）**——用户过一会儿就下载不了/播不了。
- 抖音 `play_url` 本身已是**无水印 mp4**（tikhub 用 `play_addr`）；视频号 `_ch_play_url` 优先 `nonWatermarkUrl`。
- **转存 COS → 拿永久直链**，解决过期 + 更快更稳。

> ⚠️ kongli 已知并接受：全量转存 = 每条采集视频都下载+上传 COS，**存储/流量成本随采集量线性上涨**；转存的是抖音第三方内容（合规风险自负）。**用开关 `COS_COLLECT` 控制，默认开，可随时降级为按需/关闭。**

## 目标
采集（含贴链接采集 + 关键词搜索结果）返回的每条视频，**下载并转存 COS**，`play_url`（下载/播放链接）替换为 **COS 永久直链**；转存失败或 COS 未配置时**回退原 CDN 链接**，功能不受影响。

## 改动
### 1. 新增"远程 URL 转存 COS"助手（`cos.py` 或 `core.py`）
`public_url_from_remote(remote_url, rel_key, content_type=None)`：
- 若 `cos.enabled()` 且 `remote_url` 非空 → 用现有 http 拉字节（带 UA/超时）→ `cos.upload`（或直接 put_object）→ 返回 COS 直链。
- 未配置 / 拉取失败 / 上传失败 → **返回原 `remote_url`**（回退，绝不报错中断采集）。
- 对象键建议：`collect/<platform>/<aweme_id_or_hash>.mp4`（用现有 `COS_PREFIX` 前缀）。同一视频重复采集可先 `head` 判存在、存在就直接拼 URL 不重传（省流量，可选优化）。

### 2. 采集结果替换 `play_url` → COS（`content_domains/leads.py` + `leadgen_api.py` 两条采集链路）
- 在 det 组装返回处（leads.py:34 附近 `play_url` / `url`），对**视频类**（非图集、`play_url` 非空）调用 `public_url_from_remote(play_url, key, "video/mp4")`，把结果作为对外 `play_url`（或新增 `cos_url` 字段，前端下载优先用它）。
- **图集/无 play_url/视频号加密流（play_url=None）跳过**，保持原样。
- 关键词搜索结果是**列表**——**每条视频**都转存（全量）。

### 3. 开关
- `COS_COLLECT`（env，默认 `1`=开）。为 0 时**完全走原逻辑**（返回 CDN 链接不转存），方便按需/关闭。

## 边界
- 只在**采集产出返回处**转存一次，不改抖音搜索/详情/评论主逻辑、不改 whisper/ASR（ASR 仍可用原 play_url 拉流）。
- 在采集后台任务（`kind=collect` 走 run_job）里做，**不阻塞** HTTP 提交。
- 转存**只加/回退，绝不因转存失败让采集失败**。

## 验收标准
1. `COS_COLLECT=1`：新采集的视频 `play_url`（或 `cos_url`）是 `https://huangque-media-...cos...myqcloud.com/huangque/collect/...`，**公网可播/可下**，且**不过期**（隔 >1h 仍可访问）。
2. COS 未配置 / 转存失败 / `COS_COLLECT=0` → 回退原 CDN 链接，采集功能不受影响。
3. 图集、视频号加密流等无 play_url 的不受影响。
4. `py_compile` / 现有 unittest / ci_validate 全过；不影响 whisper/ASR、关键词搜索、评论采集。

## 部署与验证
- `./ship "采集视频转存COS" server/content_domains/core.py server/content_domains/leads.py server/tikhub.py server/leadgen_api.py`（按实际改动文件）
- 服务器 `content.env` 加 `COS_COLLECT=1`（审核方部署时配）。
- 实测：采集一条抖音视频 → 返回 COS 链接 → 隔久再点仍可下载（验证永久性）；关一次开关验回退。
