# 工单 · 果肉视频(Grok)生成面板加画面比例选项（需求）

> 冲突组：**A（`server/content_domains/video.py`）+ B（`site/workbench/video.html`）**。抢 `lock/A`+`lock/B`。先读 §0+看板。

## 需求
在**果肉视频**生成面板（video.html 的 `grok` 模式 tab「果肉视频生成」）增加独立画面比例分段控件：**9:16 / 16:9 / 1:1 / 4:5 / 5:4**，默认 9:16。参照 #349（motion 加比例）的做法，用独立变量避免和其它模式串值。

## 现状（已核实）
- **前端**：`submitXiaole('grok')`（video.html:1447）提交体只有 `{channel, prompt, reference_images?}`，**不传 ratio**；grok 面板**无比例控件**；草稿 `currentVideoDraft.ratio='—'`（写死横杠）。
- **后端**：`generate_xiaole_video(model, prompt, reference_images, job_id, prefix)`（video.py:1395）的 `input_d` 只含 `prompt`/`mode`/`reference_images`/`duration_seconds`，**不含 aspect_ratio**。
- 参考：果肉**生图** `_gen_image_xiaole`（#350）走同一套 `/api/v1/generations` 接口时**有**传 `aspect_ratio`，所以视频侧大概率也支持同字段。

## 待做（A+B，纯前端不够！）
1. **后端 A**（video.py）：
   - `generate_xiaole_video` 增加 `ratio` 参数，在 `input_d` 加 `"aspect_ratio": ratio`。
   - `/api/gen/xiaole_video` 路由处理里从 payload 取 `ratio`（默认 9:16）透传给 `generate_xiaole_video`。
2. **前端 B**（video.html）：
   - grok 面板加比例分段控件（复用现有 `.seg`+`data-*ratio` 样式：9:16/16:9/1:1/4:5/5:4）。用独立变量如 `selectedGrokRatio`（默认9:16），别和 `selectedRatio`/`selectedMotionRatio` 串。
   - `submitXiaole('grok')` 的 `xlPayload` 加 `ratio:selectedGrokRatio`；`currentVideoDraft.ratio` 从 `'—'` 改为选值。

## ⚠️ 必须先验证（同 #345 教训）
**Grok(果肉) 视频 API 是否真受 aspect_ratio 控制**——视频模型的比例支持可能受限或被忽略。做之前用不同比例各跑一条 grok 实测：
- 生效 → 按上面加控件。
- 被忽略/受限（只支持部分比例）→ 只放开真支持的比例，或显示说明，**不做假控件**（FAKE-UI 原则）。

## 说明
微衣视频(micro/Seedance) 与 grok 共用 `submitXiaole`/`generate_xiaole_video`。本工单按需求只做**果肉(grok)**；若微衣也要，可同套扩展（属同一改动，可一起做或后续跟进）。

## 验收
1. （若生效）果肉视频选不同比例，输出比例正确；默认 9:16。
2. 不影响数字人/motion/换装的比例（各自独立变量，不串值）。
3. 不回退 video.html 近期改动（#294/#302/#276/#333/#349）。
