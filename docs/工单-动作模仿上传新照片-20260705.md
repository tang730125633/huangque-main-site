## 问题（Issue #143，yuelei-dev 报）
视频页「动作模仿」→ 点「＋ 上传新照片」→ **文件选择框弹不出、点了没反应**，无法选本地照片。

## 根因
`video.html` 里「＋ 上传新照片」卡片的 onclick（约 688 行）是 `selectMotionAvatar(null)`——它**只切换到"用新图"模式 + 显示上传拖拽区 `motionImageDrop`，并不直接打开文件选择框**。用户需要**再点一次拖拽区**才弹框；点"上传新照片"当次无文件框 → 体感"没反应/坏了"。

## 改动（只改 `site/workbench/video.html`）
让点「上传新照片」**直接弹文件选择框**（在用户点击手势内触发隐藏 file input 的 click）：
```js
add.onclick=function(){
  selectMotionAvatar(null);           // 切到"用新图"模式、显示上传区(原逻辑保留)
  var inp=document.getElementById('motionImageFile');
  if(inp) inp.click();                // 直接弹文件选择框
};
```
- 触发在按钮 onclick 内（用户手势），浏览器允许 `input.click()`。
- 若已在"用新图"模式再点也应能再弹框（上面写法天然满足）。
- 顺带确认：上传区 `motionImageDrop`（`<label>` 包 `<input id="motionImageFile" hidden>`）本身点击也能弹框（label 原生行为）；选完图后 `box.innerHTML` 重建的新 input 也要仍可点开（约 1015 行，保持 label 包裹即可）。

## 边界
- 只改「上传新照片」的点击行为，不动动作模仿的生成逻辑、不动换装/口播。
- 保持 `DESIGN.md` 视觉不变。

## 验收标准
1. 动作模仿 → 点「＋ 上传新照片」→ **立即弹出文件选择框**，能选本地图片、预览、用于生成。
2. 选图后再点上传区能换图；已保存形象的选择不受影响。
3. 口播、换装换背景的上传都不受影响。
4. 无控制台报错。
