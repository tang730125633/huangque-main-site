## 一、删除「参考图」部分（作图变纯文生图）
删掉 `site/workbench/banana.html` 里参考图相关的**全部** UI + JS。删除后作图只做**文生图（text2img）**，不再有图生图/局部修改。

要删的：
1. **HTML**：约 71-78 行「参考图」标题 + `upHint` + 上传框 `upBox`(`upFile`/`upIcon`/`upText`) + 那 4 张风格参考示例图(duanwu/cyberpunk/comic/guofeng_search)。
2. **JS**：参考图上传/预览逻辑（约 202-219：`refImg`/`refW`/`refH`、`upFile.onchange`、`upText` 清除图、`showInp`）；**局部修改(inpaint)整块**（约 294 起：`inpBtn` 按钮 + canvas 画蒙版逻辑，gpt 专属）。
3. **生成逻辑**：`gen.onclick` 里 `if(refImg) bp.image=refImg;`（约 284）以及 mask/局部修改分支——删掉，只保留文生图提交；`submit` 的文案里去掉"图生图/在参考图上改"，统一"生成中/文生图中"。
4. **关联清理**：切引擎时 `showInp(engine==='gpt')`（约 171）、"上传后变图生图"提示、`rs`(参考图区常显)等参考图相关行一并清；确保删后**无 `refImg`/`upBox`/`inpBtn` 等悬空引用、无控制台报错**。

> 保留：作图主流程（提示词、引擎、清晰度、比例、数量、生成、结果、历史）；「灵感案例·做同款」区块（约 82-97）**不在本单范围**，别动。
> 后端不用改：`gen_image` 仍接受 image/mask，前端不传即走文生图。

## 二、生成数量：按钮选择 → 输入框 + 左右加减
把现在的 `#countRow`（1/2/4 三个按钮 + `selectCount`）换成 **[− ] [输入框] [ +]** 增减器：
- **默认值 1**；输入框只接受正整数。
- **左右按钮**：`−` 减 1、`+` 加 1。
- **上限按引擎**：沿用现有 `ENGINE_MAXN`（nb2:2 / pro:2 / gpt:4 / zelong:2）——数量**钳制在 `[1, ENGINE_MAXN[engine]]`**；到上/下限时对应按钮禁用/置灰。
- **切引擎时**：若当前数量 > 新引擎上限，自动钳到上限（替换现有 `adaptCount` 逻辑）。
- **手输**：失焦/输入时校验，非法或超范围钳回合法值。
- 每次变更调 `updateCost()`（成本=基价×数量，现有逻辑）。
- 样式沿用 DESIGN 令牌（金 `#e7b24c` 等），加减按钮 + 输入框排成一行、和其它选择区风格一致。

## 验收标准
1. 作图页**没有参考图区、没有局部修改按钮**；文生图正常出图（4 个引擎都能出）。
2. 删除后**无控制台报错**、无悬空引用；提示文案不再出现"图生图/参考图"。
3. 数量是 **[−][输入框][+]** 形式，默认 1；加减和手输都能改，**不能超过当前引擎上限、不能小于 1**；切引擎超限自动钳回；成本随数量实时更新。
4. 清晰度/比例/引擎/生成/结果/历史/灵感案例 都不受影响。
