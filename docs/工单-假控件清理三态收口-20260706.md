# 工单 · 全站假控件清理 · 三态收口（#190 P1 剩余）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》+ `DESIGN.md`。
> **冲突组：多前端页（按页 `lock/E-<页>` / admin）** —— 逐页做、抢对应页锁。
> 灵感搜索 bug 已单独修(INSP-SEARCH #215)，本单是剩余「假控件」清理。

## 原则：每个入口三态收口
**① 真能用**（保留）｜ **② 明确"即将上线"**（置灰/加 badge/说明，外观区别于可用）｜ **③ 下线**（从导航移除）。**不造假数据、失败态显式空/错误态。**

## 清单（页面 → 现象 → 处理）
- **canvas.html（海报画布）— 整页样机**：无内联 script；工具栏/撤销重做/缩放/图层/属性面板(全 disabled)/假滑块/"导出·入库"无绑事件；连 `<input type=file>` 都没有。→ 要么补最小可用(上传+导出)，要么整页标"即将上线"并从主流程弱化入口。**按 kongli 定方向**。
- **dashboard.html / cost.html（后台）— 100% 静态假数据**：0 fetch，KPI/涨跌/图表/团队表全硬编码、日期写死 `2026-06-26`。→ 接真实后端(admin_api 已有 call-logs/stats)或明确标"示例数据/即将接入"，别拿假数当真。
- **video.html — 影子 UI + 死代码**：`.vid-side>:not(.output-card){display:none}` 藏掉整套结果区(重生成/继续改/转飞书/下载四按钮未绑事件)；`renderOutputVideo()` 定义无人调用；参数写死(720p/9:16/10s、换装6s)无控件。→ 清影子 UI 与死代码；结果区按钮要么绑真事件要么移除；参数写死若是产品定死则加说明。
- **其它**：假在线 Bot 数(34, cloud-shell.js)、recharge 假交易流水、assets 失败回退 3 张假音色卡、script 硬编码演示分镜冒充结果、通知铃铛/业务切换器无 handler、"发飞书/入库"占位。→ 逐个：失败态改真空态、占位控件置灰或下线。

## 边界
- 不改后端能力，只清前端假象/死代码 + 补必要空态。
- 每页独立小 PR、按页抢锁，别一个 PR 跨多页(撞车)。
- 改 UI 读 `DESIGN.md`。

## 验收标准
1. 导航每个入口：真能用 / 明确即将上线 / 已下线，三者之一，**外观可区分**。
2. 无写死假数据冒充真数据；失败态是显式空/错误态。
3. 影子 UI、`if(false)`、无人调用的函数等死代码清除。

## 部署与验证
- 各页→webroot。逐页实测：能用的真能用、占位的有明确标识、无假数据。

> 本工单只做规划，未改动任何文件。逐页拆小 PR 做。canvas/后台假数据方向需 kongli 拍板。
