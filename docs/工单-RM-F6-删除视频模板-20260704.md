# 工单 · 删除视频模板功能（F6 回退）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 + 《任务看板》领取流程。
> **冲突组：B（`site/workbench/video.html`）** —— 抢 `lock/B`。**纯前端。**

## 目标
产品决定**不要视频模板功能**（F6 视频模板库）。把它从视频页移除干净。

## 要删的（F6 加的模板部分）
1. 前端 `site/workbench/video.html`：
   - 模板选择器 UI（`.template-panel`/`.template-grid`/`.template-card`/`.template-name`/`.template-desc`/`.template-meta` 等 CSS + 对应 HTML 区块 + 模板入口/tab）。
   - 模板 JS：`loadVideoTemplates`、`applyVideoTemplate`、`renderVideoTemplates`、`videoTemplates`、`selectedVideoTemplate` 及其初始化调用（如 `loadVideoTemplates()`）。
2. 素材文件：删除 `site/workbench/assets/video-templates.json`。

## ⚠️ 必须保留（别误删！）
F6 当初加了两个 helper，**后来被 F7 的"资产页视频重生成预填"复用了**：
- `clickDataButton(name, value)`
- `applyTemplateVoice(key)`

这两个函数**必须保留**（视频重生成预填 `applyAssetPrefill` / `_applyPrefillVoice` 依赖它们）。删模板时只删 `applyVideoTemplate` 里对它们的**调用**和模板本身，**不要删这两个函数定义**。

## 边界与注意
- **只改前端**（video.html + 删 json）；不碰后端。
- 删完确认：口播、动作模仿、字幕、**资产页视频重生成预填**（跳到视频页会预填参数）都仍正常——预填正是靠上面两个 helper。
- 先读 `DESIGN.md` 保持视频页其它区块布局不乱。

## 验收标准
1. 视频页不再有"模板/模板库"任何入口和 UI。
2. `video-templates.json` 已删除；页面不再 fetch 它、无 404 报错。
3. 口播 / 动作模仿 / 字幕 正常。
4. **资产页视频「重生成」跳到视频页仍能预填**（clickDataButton/applyTemplateVoice 还在起作用）。
5. 无控制台报错。
