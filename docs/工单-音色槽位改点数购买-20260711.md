# 工单 · 音色槽位购买改点数（VOICE-SLOT-POINTS）

## 背景
声音复刻已全量切 CosyVoice（#564），上游坑位**免费、上限 1000**。原来的「兑换码 + 槽位池」稀缺模型（豆包时代 ¥128/坑）已过时，且线上 `voice_slot_pool` 已空（`available=0`）、`voice_slot_codes` 全部 used——现有兑换流程实际已不可用。

kongli 决策：**去掉兑换码，改为花 50 点购买音色槽位，单用户上限 5 个。**

## 目标
用户在资产库音色页点「购买音色槽位」→ 扣 50 点 → 直接获得一个个人音色槽位（可用于 CosyVoice 复刻）。不再输入兑换码、不再走槽位池。

## 冲突组
**A（后端 `content_domains/core.py` + `audio.py`）+ C（`site/workbench/assets.html`）**。改前锁这两组。

## 后端改动（`content_domains/`）

### 常量
- `VOICE_SLOT_COST = 50`（点）
- `VOICE_SLOT_MAX_PER_USER = 5`

### 新函数 `audio.purchase_audio_voice_slot(username)`
原子完成，**扣点前先校验、失败必退点**（对齐现有 `_submission_lock`/`deduct_points`/`safe_refund_points` 套路）：
1. 校验用户当前**有效**槽位数 `< VOICE_SLOT_MAX_PER_USER`（超限 → 明确报错「最多 5 个音色槽位」，**不扣点**）。
2. `points_domain.deduct_points(username, VOICE_SLOT_COST, "voice_slot")` 原子预扣（402 点数不足 → 透传，不建槽位）。
3. 生成 `slot_id`（**uuid，如 `slot_<uuid4().hex>`**，不再用池里的豆包 S_xxx 码），`INSERT INTO audio_voice_slots(username,user_id,slot_id,status='active',...)`。
4. 任一步（建行）失败 → `safe_refund_points` 退回 50 点，报错。
5. 返回 `{slot_id, status:"active", cost:50, points_left}`。

### 路由（`core.py`）
- 新增 `POST /api/gen/audio/buy-slot` → 调 `purchase_audio_voice_slot`，走标准鉴权 + 改密拦截。
- **弃用** `POST /api/gen/audio/redeem-slot`：改为返回 400/410「音色槽位已改为点数购买，请使用购买入口」（保留路由做友好提示，避免老前端缓存直接 500）。
- 弃用 `redeem_audio_voice_slot` / `assign_audio_voice_slot`（池/码逻辑）——保留函数体但不再被路由调用，或直接删除；**建表 DDL（`voice_slot_pool`/`voice_slot_codes`）保留**（向下兼容，不删表）。

### 数据迁移（部署时执行，写进 PR 的部署说明）
清脏数据：`voice_slot_pool` 的 3 条 `assigned`（对应已删的 fang 槽位）+ `voice_slot_codes` 的 used 记录 → 清空或标记失效。**不删表结构。**

## 前端改动（`assets.html`）
- 把「输入兑换码 → 确认兑换」弹窗改为「购买音色槽位」：
  - 展示：**本次消耗 50 点**、当前点数余额、已有槽位数 `x/5`。
  - 按钮「确认购买（50 点）」→ POST `/api/gen/audio/buy-slot`。
  - 移除兑换码输入框及相关文案。
- 错误处理：402→「点数不足，去充值」（可跳充值页）；上限→「最多 5 个音色槽位」；401→`HQ.login()`。
- 成功后刷新音色页、更新点数徽标（`HQ.refreshPoints`）。
- 缓存戳：改 `assets.html` 不涉及 `cloud-shell.js`，无需全站 bump。

## 计费口径
- 槽位购买：**50 点/个**（平台侧收费，上游 CosyVoice 坑位免费）。
- 合成/复刻：坑位免费，合成按字符（上游 DashScope），用户点数扣费维持现状（本工单不动合成计费）。

## 测试（`tests/`）
- 购买 happy path：扣 50 点、建 active 槽位、返回 points_left。
- 上限：已有 5 个时第 6 次购买 **拒绝且不扣点**。
- 点数不足：deduct 抛 402 → 不建槽位、透传 402。
- 建槽位失败 → 退点（mock INSERT 抛错，断言 refund 调用）。
- 弃用路由 `redeem-slot` 返回明确提示（非 500）。
- 前端：`buy-slot` 提交路径存在、无残留兑换码输入（grep/node）。

## 验收
- 真实用户走 `/api/gen/audio/buy-slot` 扣 50 点拿到槽位并能进入 CosyVoice 复刻。
- 超 5 个被拦、点数不足被拦、均不误扣。
- 部署：`core.py`/`audio.py` 属共享 content_domains → 重启 content+imggen-api+admin 三 importer；部署前查零在飞任务；`assets.html`→/var/www；数据迁移脚本执行一次。
