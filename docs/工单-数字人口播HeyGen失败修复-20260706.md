# 工单 · 数字人口播总是生成失败 · HeyGen 接口失败（Issue #258）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》+《开发手册》。
> **冲突组：A（`server/content_domains/video.py`、`core.py`）** —— 抢 `lock/A`。**后端为主**，不动前端、不动数据库。
> ⚠️ 部分是**运维排查**（HEYGEN_API_KEY 有效性/额度），非代码能修——见「运维先做」。
> 相关：#250、#252、#263（视频页能力）。

## 现象
工作台「视频」页，数字人口播（text/audio）与动作模仿（motion）生成**总是失败**，前端只笼统提示「heygen 接口失败」，看不出是密钥、额度还是网络。

## 代码链路（issue 已定位）
- 错误源头：`video.py:241` `_heygen_request_json` 抛 `RuntimeError("HeyGen接口失败: HTTP %s %s" % (e.code, detail))`。
- 密钥：`core.py:94` `HEYGEN_API_KEY=os.environ.get("HEYGEN_API_KEY","")`（默认空）；未配时 `video.py:230-231` 抛 `ValueError("视频生成服务未配置")`。
- API base：`core.py:95` `https://api.heygen.com/v3`。
- 入口：`gen_video`(`video.py:781`)→口播 `generate_heygen_video`(440)/动作模仿 `generate_heygen_motion_video`(462)。失败可能在上传素材/建 avatar/轮询任一步。

## 代码问题（本单修）
1. **`URLError` 未捕获（核心 bug）**：`video.py:239` 只 `except urllib.error.HTTPError`，**没捕 `urllib.error.URLError`**。网络层失败（DNS/连接拒绝/超时，**国内服务器访问 api.heygen.com 极可能中招**）抛原始 `URLError`，不转友好提示。
   - 修：补 `except urllib.error.URLError as e: raise RuntimeError("HeyGen接口网络失败: %s" % e.reason)`。
2. **错误详情未透传前端**：`241` 已带 HTTP code + detail，但经 `gen_video` 回传到 `video.html` 时只剩笼统「heygen 接口失败」。
   - 修：把 runner 的 message 原样透传到前端 `error` 字段（`video.html` 已有失败提示位可展示，尽量不改前端；若必须改 video.html 则**另抢 `lock/B`**）。
3. **无密钥自检**：建议生成前/服务启动时自检 `HEYGEN_API_KEY` 是否配置，未配即明确提示（目前 `230` 才在调用时报）。
4. **日志不足**：失败时 `print("[heygen] FAIL %s %s -> %s" % (method, path, detail), flush=True)` 落服务日志，方便运维定位。

## 运维先做（可快速定位，非代码）
1. 看日志：`sudo journalctl -u huangque-content --since "10 min ago" | grep -i heygen`，找 `HeyGen接口失败: HTTP` 后的 code + detail。
2. 确认 `content.env` 里 `HEYGEN_API_KEY` 非空且未过期；HeyGen 后台看额度/配额。
3. 测网络：`curl -I https://api.heygen.com/v3/`（国内服务器重点）。
4. 401/403→换密钥；400/404→核对 API v3 是否变更；超时→网络/代理。

## 验收标准
1. `URLError` 已捕获，网络失败有友好提示（「HeyGen接口网络失败: ...」）。
2. 前端失败提示能看到具体 HTTP code（401/403/404/超时），而非笼统「heygen 接口失败」。
3. 服务日志记录 heygen 失败详情。
4. 密钥未配置时生成前即明确提示「视频生成服务未配置」。
5. 配好有效密钥 + 网络通后，口播与动作模仿均能生成成功。
