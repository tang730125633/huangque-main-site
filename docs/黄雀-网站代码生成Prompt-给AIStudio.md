# 黄雀 AI · 网站代码生成 Prompt（给 AI Studio / Gemini，可直接整段复制）

> **用法**：把【第 0～9 节】整段复制给 AI Studio（Google AI Studio / Gemini），
> 然后在末尾加一句：「**先生成【主页】这一页**」。确认风格后，再换成
> 「生成【AI 作图工作台】」「生成【登录页】」……逐页出。
> 每页都自动套用第 1～7 节的设计系统，保证 16 个页面像同一个产品。

## 1. 设计 Token（CSS 变量 · 照抄进 `:root`）

```css
:root{
  /* —— 背景与表面（暗色深蓝）—— */

  --panel:#0c1220;       /* 主面板/卡片 */
  --panel-2:#111a2b;     /* 次级面板 */
  --surface:#101827;     /* 输入框、选择框、表头 */
  --surface-2:#0d1422;   /* 上传区、分段控件槽 */
  --line:#1d2a3e; --line-soft:#15202f; --line-strong:#27374e;  /* 描边由弱到强 */

  /* —— 文字 —— */
  --txt:#eaf1fa; --txt-dim:#94a4bb; --txt-faint:#586a82;

  /* —— 品牌色 —— */
  --gold:#e7b24c;        /* 主强调：CTA、关键数字、logo、当前项高亮 */
  --gold-soft:#f2c869;   /* 金色高光/渐变浅头 */
  --gold-deep:#caa23e;   /* 金色渐变深头 */
  --cyan:#2dd4bf;        /* 次强调：链接、飞书、聚焦边框 */
  --blue:#46b4ff;        /* 进行中状态 */

  /* —— 语义状态色（低饱和、克制用）—— */
  --green:#2bd576; --copper:#cf8a3e; --warn:#e0a93c; --red:#ff5566;

  /* —— 字体 —— */
  --sans:-apple-system,BlinkMacSystemFont,"PingFang SC","Microsoft YaHei","Segoe UI",sans-serif;
  --mono:ui-monospace,"SF Mono","JetBrains Mono",Menlo,Consolas,monospace;

  /* —— 布局尺度 —— */
  --rail:74px;           /* app 左侧图标导航宽 */
  --inspector:392px;     /* app 右侧检视栏宽 */

```

**圆角**：卡片 13–14px，按钮/输入 8–11px，pill `999px`，大圆角图卡 18–22px（营销页）。
**阴影**：金色 CTA `0 6px 22px rgba(231,178,76,.26)`；卡片 hover 抬升 `translateY(-3px)` + 描边转金。
**选中高亮**：`::selection` 用 `rgba(231,178,76,.3)`。滚动条 9px、thumb `#1c2942`。

## 3. 图标（统一规范）

- **全部用内联 SVG 线性图标**（Lucide / Feather 风格）：`viewBox="0 0 24 24"`、`fill="none"`、
  `stroke="currentColor"`（导航/通用）或 `stroke="var(--gold-soft)"`（能力卡）、`stroke-width:1.7`（rail 21×21）/ `1.8`（营销卡 24×24）。
- **禁止** emoji 当主图标、禁止 FontAwesome 字体图标、禁止彩色填充图标。
- 常用图标参考：
  - 获客=放大镜 `<circle cx=11 cy=11 r=7/><path d="M21 21l-4-4"/>`
  - 作图=图片框 `<rect x=3 y=4 width=18 height=16 rx=2/><circle cx=8.5 cy=9.5 r=1.6/><path d="M5 19l5-5 4 3 3-3 2 2"/>`
  - 视频=播放 `<rect x=3 y=5 width=18 height=14 rx=2/><path d="M10 9l5 3-5 3z"/>`

## 5. 组件库（按这些样式实现）

- **金色主按钮 `.btn-gold` / `.gen-btn`**：`linear-gradient(135deg,var(--gold-soft),var(--gold))`，深色文字 `#0a0e16`，金色阴影；hover 抬升。生成类按钮**右侧带成本 chip**（如 `生成口播` + `13 点`，等宽，半透明深底）。
- **描边按钮 `.btn-ghost`**：透明底 + `--line2` 描边，hover 边框转金、文字转金。
- **分段控件 `.segmented`**：深槽 + 选中项 `linear-gradient(180deg,#16223a,#111a2b)` + 内描边；选中项副标题（如点数）转金。能力点数可挂绿色 `badge`。
- **统计卡 `.stat`**：大号等宽数字（30px）+ 标签 + 角落径向辉光（语义色，`blur(46px) opacity:.14`）。涨跌用绿/红小字。
- **数据表 `.data`**：表头大写字母 + 间距、`sticky`、行 hover 淡蓝、数字列右对齐等宽。
- **状态 pill `.pill`**：g 绿/w 橙/r 红/b 蓝，低饱和半透明底 + 同色描边。
- **上传区 `.upload`**：虚线描边，hover 边框转青；显示接受格式与大小限制。
- **进度条 `.pline`**：细条，金/绿/蓝渐变填充。
- **资产卡 `.acard`**：3:4 缩略图 + 左上类型徽标（青色）+ 标题 + 等宽元信息；hover 边框转金 + 抬升。
- **列表行 `.lrow`**（今日行动/失败任务）：左侧发光状态点 + 主文案 + 右侧金色「重试/处理」按钮。
- **生产线卡 `.prodcard`**：图标 + 名称 + 3 个等宽指标（成/排队/失败）。
- **Toast**：底部居中，绿点 + 文案，淡入上移。

## 6. 动效（克制 · 高级）

- **金色粒子星网背景**（营销页）：固定全屏 `<canvas>`，~70 个金色光点缓慢漂移、近邻连线、跟随鼠标轻微排斥；金色 `rgba(231,178,76,.9)` + 阴影发光；`opacity:.6`。
- **滚动入场**：`.reveal` 元素初始 `opacity:0; translateY(24px)`，进入视口加 `.in` 过渡显现（`IntersectionObserver`，`cubic-bezier(.22,1,.36,1)`，错峰 delay）。
- **微交互**：卡片 hover 抬升、按钮 hover 发光、状态/抽屉切换 160–240ms。
- **必须** `@media (prefers-reduced-motion:reduce)` 时全部关掉动画。
- **不要**：大面积滚动视差、炫技转场、背景视频。
