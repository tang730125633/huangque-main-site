# 渠道模型参数、发布与用户选择

## 操作入口

后台「渠道管理」的托管渠道行点击「参数」。OpenAI / MiniMax / xAI 的内置行提供
「配置模型参数」，用于新增独立托管模型配置；不改写内置线路的密钥和固定调度。
一个托管配置对应一个实际模型，同供应商的多个模型可以分别建配置，并使用不同前台映射名。

1. 保存连接配置，填写真实 API、模型和密钥。
2. 在参数页选择适配协议，勾选允许的值，设置中文字段名称、显示/隐藏与上移顺序。
3. 按勾选项生成合法组合，删除不需要的组合，每行填写一个产物的**总点数**，选择默认组合。
   视频价格为所选时长的总价，不是每秒价格。最多128个组合；不自动猜测成本或加价。
4. 预览用户面板，点击「校验并预览实际请求」检查与运行时共用的请求转换；不会调用供应商。
5. 保存草稿，再确认发布。草稿私有，发布生成新配置版本；可将历史参数回滚为新的版本。
6. 绑定并启用功能映射与渠道。图片请求标识对应前台模型选项；视频当前复用 grok/minimax/omni/micro。

图片与视频工作台增加平台配置模型面板，15秒检查一次发布配置。其他原有模型与工具可以切换访问。
选项按合法组合联动，显示对应总点数；参数更新会保留提示词并要求用户检查变化，参考图需重新选择。
公开接口 `/api/gen/channel-parameters` 不返回密钥、供应商模型名、内部地址、代理、草稿或操作人。

## 已实现能力边界

| 适配器 | 可配置能力 |
| --- | --- |
| OpenAI兼容文生图 | 尺寸、质量；GPT Image协议另支持PNG/JPEG/WebP及透明/不透明背景 |
| MiniMax H3 | 现有适配器允许的比例、4～15秒、2K；参考图范围0～5张 |
| Grok视频 | 现有适配器支持的9:16/16:9/1:1、1～15秒、720p；最多1张参考图，1.5模型至少1张 |

当前三类适配器都只返回**单个产物**；OpenAI托管适配器仍是文生图，不开放图生图、蒙版、批量产物、
任意尺寸、FPS或音轨开关。它们不能因后台勾选就成为已实现能力。中转模型别名必须由管理员按实际协议选择，
配置校验不能证明供应商支持该模型。已选择的单次完整测试通过也不能代表全部参数组合或前台交付通过。

OpenAI保守预设区分GPT Image、DALL-E 3和基础兼容协议，避免给GPT Image发送不支持的response_format。
GPT Image 2 单独提供常用2K、4K横竖尺寸及16:9/9:16组合，不将其能力套用到GPT Image 1系列；
不开放超过其像素限制的3840×3840等尺寸。当前提供审核过的常用尺寸预设，暂不接受任意宽高。
图片尺寸附真实像素比例，拒绝透明背景+JPEG组合；运行时检查实际返回尺寸，不把128px示例冒充1024px成品。
参考资料：[OpenAI Images请求参数](https://developers.openai.com/api/reference/resources/images/methods/generate)、
[xAI视频生成](https://docs.x.ai/developers/model-capabilities/video/generation)。视频允许集以现有代码适配范围为界，不随文档自动扩张。

## 执行、计费与版本

- 私有草稿存现有渠道库 `settings.id=3`；已发布契约存现有 `versions.config.parameters`，没有修改公共表结构。
- 草稿版本与渠道版本同时核对，防止多人覆盖；编辑连接后须重新保存草稿再发布。
- 用户提交 `parameter_selection.revision/combination`，后端从发布契约取得真实参数和总点数，不相信客户端传入的价格。
- 入队前重新检查渠道启用状态、映射、参数版本和价格；过期选择拒绝，禁止静默回退到旧供应商。
- 已接收任务保留原配置快照。旧请求的防重复重放可以用历史参数做预检，新任务入队仍要求当前版本。
- 复用原扣点、任务存储和退款逻辑。特殊已扣款子任务由现有持久补偿流程处理入队失败，不另建收费通道。
- 前端保存防重复编号与原始请求，在网络结果未知时仅允许使用原编号重试；按登录用户隔离会话记录。

## 本地验收

### 参数编辑界面

参数入口改为宽弹窗，分为「可选参数」「组合与定价」「发布记录」，右侧保留用户端预览，底部固定草稿和发布操作。
尺寸显示比例示意与像素值，质量/背景使用中文名称；显示名称和排序在每张卡片的「更多设置」，协议和请求在高级设置中。
切换固定值时只保留一个选项。调整勾选后点击「应用选项」，确认组合增减；原有组合的 ID、价格和仍有效的默认组合保留，新增组合才使用新增点数。
应用前明确显示预览仍是旧组合，禁止保存未应用选项。定价页可按参数筛选并批量修改筛选结果；无效价格标红并阻止保存。
预览和请求校验不调用供应商。发布确认列出选项变化、组合数量、价格范围和关联功能；回滚仍使用原有版本接口。
关闭按钮及 Escape 均检查未保存修改；请求保存期间阻止关闭和编辑。
本轮界面专项：28 项 JS 测试通过；浏览器验证尺寸卡片、定价页、发布记录、草稿保存，以及固定格式单选与待应用保存拦截。静态与资源戳检查通过。本轮未改后端计费或发布协议。

PR 整合时同步主分支的点数结算开关：用户参数面板读取已验证账户的 `points_billing_enabled`；关闭时显示内测免费并隐藏点数确认文案，后台配置价格和任务计价快照保留，余额是否变动仍由 Auth 控制。整合后 271 项 Python 扩展回归、2 项服务器监控回归和 29 项 JS 通过；下述两项已确认基线失败单列。
