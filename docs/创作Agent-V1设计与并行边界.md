# AI 创作助手 V1 设计与并行边界

## 产品目标

主站新增独立标签页「AI 创作助手」，页面标题为「黄雀创作 Agent」。
用户在同一个持续对话中完成 IP12 画像建档、选题与文案创作，以及模板视频制作。

首版只支持：

- IP12 模块 1-4 画像建档、确认与定位画像 PDF；
- 独立入口运行 IP12 模块 5-6，生成选题计划与最终文案；
- 抖音、小红书、视频号的模板视频制作；
- 查看当前进度、内容成果、视频任务及历史版本。

不包含公众号、B 站、自动分发、图片生成、配音、数字人口播或其他生成工具。

## 用户旅程

### 进入页面

- 未登录：跳转登录，成功后返回 AI 创作助手。
- 没有 IP12 画像：自动创建「我的个人画像」，直接从模块 1 开始引导。
- 有未完成画像：自动恢复上次未完成步骤。
- 有完整画像：直接显示「开始制作视频」「生成选题计划」「修改我的画像」。
- 有两个画像项目：顶部画像按钮显示当前项目，点击后选择或切换；每个项目独立保存对话、偏好、成果和任务。
- 每个画像只有一条持续对话，不提供新对话或历史会话列表。

### 画像建档

1. 模块 1-4 由现有 IP12 工作流负责，Agent 每次只问一个自然问题。
2. 小范围问题提供选项；开放问题提供回答模板；所有问题都允许自由输入。
3. 每个模块完成后先展示结构化总结，用户在左侧对话确认或修改后再继续。
4. 模块 4 完成后生成定位画像 PDF，用户预览并确认后画像才算完整。
5. 用户可随时在对话中修改画像；历史作品不变，后续作品使用最新版画像。

IP12 是基础画像正本。定位 PDF 确认后的修改作为版本化「画像补充」保存，后续创作优先读取补充，
不回写同事的 IP12 Agent 内核，也不改变原 PDF 和历史作品。

### 生成选题计划

- 快捷入口「生成选题计划」依次运行模块 5 和模块 6。
- 没有明确选题时生成完整的至少 15 个选题计划，再生成文案。
- 已有明确选题时允许缩短模块 5，直接围绕选题完成模块 6。
- 结果止于最终文案并保存到 IP12 内容成果，不调用视频、不报价、不扣点。
- 用户可继续通过对话修改或重新生成文案。

### 制作模板视频

1. 用户说明选题或核心观点。
2. 首次选择抖音、小红书、视频号，可多选；之后默认最近使用的平台，生成前可调整。
3. 未说明内容目标时，Agent 根据画像与本次内容自动判断，不追加无必要问题。
4. Agent 为每个平台分别生成方案卡：顶部标题、底部行动文案、推荐模板、推荐理由和素材包。
5. 当前模板服务只接受平台素材库，因此 V1 自动选择抖音、小红书或视频号的平台素材库。
   用户自建素材包与未来公共素材库保留为后续合同；在上游支持素材输入前不得伪装成已使用用户素材。
6. 用户可通过对话逐个平台修改或重新生成，全部确认后才统一询价。
7. 展示各平台价格明细和总价，左侧仅提供一个真实确认按钮。
8. 后端按平台创建独立任务；单个任务失败只退该任务点数，不影响其他平台任务。
9. 成功视频可在右侧预览、播放、下载和查看版本。成功后再次生成必须重新报价、确认和扣点。

## 双栏交互

### 左侧：Agent 对话

- 所有提问、选项、自由输入、画像确认、方案修改、报价确认都在左侧完成。
- 快捷入口只负责发起意图，不绕过 Agent 流程。
- 普通聊天不能触发扣点；模型不能代替用户确认付费。

### 右侧：展示窗口

右侧只展示，不放决策按钮，包含三个标签：

- 当前进度：画像模块、当前创作阶段和待处理事项；
- 内容成果：定位画像 PDF、选题计划、文案及其版本；
- 视频任务：分平台状态、失败退款、视频预览、播放和下载。

## 偏好记忆

- 偏好独立写入 `template_video_preferences`，不修改 IP12 模块 1-4 的核心事实。
- 同时保存全局偏好和抖音、小红书、视频号的平台偏好；平台偏好优先。
- 只有「以后」「我喜欢」「不要再」等明显长期表达自动写入；本次指令只影响当前任务。
- 不询问是否保存。用户可在对话中查看、修改或清空偏好。

## 计费与安全

- 画像建档、画像修改、普通对话、选题计划和文案生成免费。
- 只有模板视频正式生成扣点。
- 报价令牌、任务 ID、内部令牌和幂等键不能返回浏览器。
- 报价后参数变化必须作废旧报价并重新询价。
- 网络结果不确定时只能查询原任务，禁止换幂等键重复提交。
- 批次编辑、报价、确认和刷新使用 SQLite `BEGIN IMMEDIATE`、plan revision/hash 与条件更新；
  确认后 Provider 只能读取已冻结的提交快照。
- 浏览器在请求前持久化完整 body、request ID 和 confirmation ID；网络错误或 5xx 后使用原请求恢复，
  明确 4xx 或终态后才清理 pending。
- 第一版不增加 Agent 专用消息频率或每日次数限制，保留网站现有基础安全防护。

## 并行开发边界

- 不修改同事的 `server/hermes_ip12/**` Agent 实现、Master Agent、SDK Canary 或 PR #1264。
- 通过现有 IP12 API/CLI 合同读写用户自己的项目，不直接修改 IP12 运行时文件。
- Creator Agent 使用独立服务 `huangque-creator-agent`、端口 `8114`、SQLite 和环境文件。
- 主站账号、点数、任务、退款与资产库仍是业务正本。
- 功能开关 `creator_agent_v1` 默认开启；关闭时隐藏入口并禁用服务接口。
