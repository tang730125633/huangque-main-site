# 工单 · 作图「转视频」跳转丢图，结果图未带入视频页（Issue #250）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》+ `DESIGN.md`。
> **冲突组：E-banana（`site/workbench/banana.html`）+ B（`site/workbench/video.html`）** —— 两组都要抢锁：`lock/E-banana` + `lock/B`。**纯前端**，不动后端、不动服务器。
> 相关：#252（编导「转作图」同类跨页丢参问题）。

## 现状
作图页 `banana.html` 生成图后，点结果区「转视频」跳到 `video.html`，**刚生成的图不会自动带过去**，用户必须手动重新上传首帧图。

## 根因（issue 已排查，供参考）
- `banana.html:113`：「转视频」是裸跳转 `<a href="video.html">`，不带任何查询参数。
- `banana.html:373-385`：JS 给结果区其余 5 个按钮绑了 onclick，**唯独没给「转视频」绑事件**。
- `banana.html:234/246/363/368`：结果图 url 只存 `localStorage('hq_last_result')`，未传给 video.html。
- `video.html:1255-1272`：`applyAssetPrefill()` 只在 `?prefill=asset` 时触发，只读 `hq_video_prefill`，预填项**不含首帧图片**。
- 结论：作图页→视频页之间**没有首帧图传递通道**，图被丢弃。非"视频转完不上传"，而是"转视频跳转时图没带过去"。

## 已排查正常（勿改）
后端 COS 上传（`video.py:880`/`image.py:45`/`audio.py:765`/tryon `video.py:1039`）与入库（`core.py:442` `record_video_asset`）均正常。本单纯属前端跨页传图缺失。

## 改动建议
- **banana.html**：「转视频」改 JS 跳转——把当前结果图 `lastResultUrl`（可能是 COS 直链）写入约定 localStorage（建议复用 `hq_video_prefill`，新增 `image_url` 字段），再 `location.href='video.html?prefill=image'`。无结果图时仍正常跳空页、不报错。
- **video.html**：扩展预填逻辑识别 `?prefill=image`（或复用 `?prefill=asset` 分支），读取带来的图 url，调用已有的 `setOutputImage()`（`video.html:493`）填首帧，并置 `hasImage`/`imageData` 走「图生视频」路径。
- **实施确认点**：作图结果是 url（COS 直链），而 video.html 提交 `/api/gen/video` 时 `imageData` 走 base64（`video.html:1144/1219`）。二选一：
  - (A) 前端把 COS 图 fetch 成 base64 再填（跨域需 COS 允许 CORS）；
  - (B) 后端 `/api/gen/video` 支持 `image_url` 直传（省一次 base64 往返，**推荐**，但会跨到 A 组后端，需另抢 `lock/A` 或拆二期）。
  - 若只做纯前端（本单范围），走 (A)；(B) 属后端增强可另开工单。

## 验收标准
1. 作图页生成图 → 点「转视频」→ video.html 首帧图自动填入，无需手动重传。
2. 预填的图能正常走口播/动作模仿生成，不报「请上传图片」。
3. 资产页「重生成」原预填流程不受影响（回归 `?prefill=asset`）。
4. 作图页无结果图时点「转视频」，正常跳空页不报错。
