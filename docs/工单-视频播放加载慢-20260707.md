# 工单 · 视频资产点击查看加载慢（Issue #339）

> 冲突组：**C（`site/workbench/assets.html` 弹窗 preload）+ 运维（COS CDN 加速）+ 可能 A（转码，重）**。按实际改的文件抢锁。先读 §0+看板。

## 现象
资产库 → 视频资产，点击视频卡片播放时，视频**长时间黑屏/转圈**，加载慢（期望 2 秒内起播）。

## 现状核实（先读，避免重复劳动）
已经做过、**不要重做**的：
- 视频**已走 COS**：`video_url` 经 `public_url()` 上传腾讯云 COS（core.py:62/78）。
- 网格卡片已优化：`videoCard()` 用 `preload='metadata'` + `poster=缩略图`（assets.html:649-650），网格不拉全片。
- #302 懒加载鉴权弹窗、pause 释放已上线。

## 真实瓶颈（三个，按性价比排序）
1. **COS 源站直链无 CDN 加速**（最大锅）：视频直链是 `xxx.cos.ap-guangzhou.myqcloud.com`（源站域名），走 COS 源站带宽而非 CDN 边缘节点。首字节慢、吞吐低，异地用户尤甚。
2. **弹窗播放器 `preload='auto'`**（assets.html:372）：打开弹窗即预拉全片，大文件时阻塞起播。
3. **HeyGen 原始视频无转码**：出片码率/体积可能偏大，无 web 优化（faststart/moov 前置、合理码率）。

## 待做（分层，可分步上）
- **P0（轻，立竿见影）**：
  - 弹窗 video 改 `preload='metadata'` + 点击/autoplay 时才实际加载（依赖 COS range 请求，COS 直链支持 range，可边下边播）。
  - 确认 COS 对象 `Content-Type: video/mp4` 正确、支持 Range（起播能 seek）。
- **P1（运维，收益最大）**：COS 桶挂**腾讯云 CDN 加速域名**（或开启 COS 全球加速），视频直链改用 CDN 域名。需 kongli 决策（域名/备案/成本）。
- **P2（重，A 组）**：视频产出后加**转码**（ffmpeg：`-movflags +faststart` moov 前置 + 合理码率），显著降体积、提起播。属较大后端改动，评估后再定。

## 验收
1. 点击视频到起播 < 2 秒（同网络下对比修复前）。
2. 网格/弹窗封面正常（配合 #338 修复）。
3. 不影响下载/放大/鉴权（COS 私有 ACL 预签名仍有效）。

- P0 改 assets.html → ship + 公网 vs git 对比。P1 走运维（COS 控制台+nginx/前端直链域名）。P2 单独评估。完成关 #339。
