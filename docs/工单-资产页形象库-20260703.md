# 工单 · 资产页数字人形象库

> 供其他 agent 独立执行。开工前先读《工单-其他agent实施-20260703》§0 公共上下文
> （仓库/分支PR/ship/DESIGN.md/漂移哨兵/**禁止服务器直改**）。本工单只做**前端**。

## 目标
在资产页（`site/workbench/assets.html`）新增**「数字人形象」**分类，让用户在资产模块里也能查看/管理已保存的数字人形象——与视频页「我的形象」用同一套数据。

## 背景（已核实）
- 形象库后端接口**已上线**（F1）；本工单**只改前端 `assets.html`，不动后端**。
- 资产页现有分类 chip：`图片资产`(data-cat=image) / `音频资产`(audio) / `视频资产`(video)，切换时 JS 拉对应接口填充网格；页面另有几张"敬请期待"占位卡。
- 资产页已有"音色"管理（改名等）作为**同类管理 UI 的参照**，风格照它对齐。

## 后端 API 契约（已上线，直接用；均需 `Authorization: Bearer <token>`）
| 方法 · 路径 | 入参 | 返回 |
|---|---|---|
| `GET /api/gen/video/avatars?limit=120` | — | `{"items":[{id,name,image_url,provider_avatar_id,status,created_at,...}]}` |
| `POST /api/gen/video/avatar-name` | JSON `{id,name}` | `{"ok":true,"avatar":{...}}` |
| `POST /api/gen/video/avatar-delete` | JSON `{id}` | `{"ok":true,"avatar":{...}}` |

> 未登录返回 `401 {"detail":"未登录"}`；改名/删除仅能操作本人形象。

## 前端任务（`assets.html`）
1. **新增分类 chip**：在现有 `图片/音频/视频资产` 那排加 **「数字人形象」**（`data-cat="avatar"`），交互（选中高亮/切换）与现有 chip 一致。可用它**顶掉一张"敬请期待"占位卡**。
2. **选中时加载**：`GET /api/gen/video/avatars` → 渲染形象网格（`image_url` 缩略图 + `name` + 保存时间）。
3. **管理操作**：每个形象支持
   - **改名** → `POST avatar-name {id,name}` → 成功后刷新。
   - **删除** → 二次确认 → `POST avatar-delete {id}` → 成功后移除。
4. **空状态**：无形象时提示"还没有数字人形象，去『视频 → 动作模仿』用照片生成一次，形象会自动保存到这里"。
5. **风格**：先读 `DESIGN.md`，复用资产页现有 chip / 卡片 / 音色管理的视觉；复用 `cloud-shell.js?v=15` 外壳。

## 边界与注意
- **只改前端**，不碰后端；其它资产分类（图片/音频/视频）行为不变。
- 与视频页「我的形象」是**同一份数据**（同接口）——此处改名/删除后，视频页刷新应一致（无需特殊同步，读同接口即可）。
- 401 跳登录；改名/删除失败用现有 toast 提示。

## 验收标准
1. 资产页出现「数字人形象」分类，点击显示本人形象网格（缩略图+名字）。
2. 改名、删除生效，且仅作用于本人形象。
3. 与视频页「我的形象」数据一致（同一形象两处都能看到）。
4. 图片/音频/视频资产分类不受影响；资产页无控制台报错。

## 部署与验证
