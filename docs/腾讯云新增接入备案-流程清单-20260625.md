# 腾讯云「新增接入」备案 — 详细流程清单

> 目标：`huangquechuanmei.com` 已在**阿里云**备案成功（备案号 `粤ICP备2025447525号-2`，主体 广州黄雀传媒有限公司），现网站已部署在**腾讯云服务器** 129.204.166.13。
> 需要在腾讯云做「**新增接入**」（= 给已备案的网站，新增腾讯云为接入服务商），否则腾讯云防火墙日后可能拦掉该域名的 80/443 访问。
> 日期：2026-06-25 ｜ 整理：小秋(Claude Code)

---

## 一、这是什么 / 为什么要做

- **不是重新备案**：主体和域名已经备案过（管局已通过），所以是"**新增接入**"，**不审主体、只审接入**，比首次备案快很多。
- **为什么必须做**：大陆规矩——域名解析到哪家云的服务器，就要在哪家云做过接入备案。你域名现在解析到腾讯，但接入挂在阿里云。**现在能访问是侥幸（腾讯还没扫到），扫到后会拦 80/443。** 做完新增接入 = 一劳永逸不怕拦。
- **做的过程中网站照常能访问**，不影响现有上线状态。

## 二、前提条件（先确认，缺一不可）

| 前提 | 说明 | 现状/待确认 |
|---|---|---|
| 已有 ICP 备案号 | `粤ICP备2025447525号-2` | ✅ 有 |
| 腾讯云账号 | 必须**实名认证**（企业实名最好=广州黄雀传媒；个人实名也能做但建议企业）| ⚠️ 确认服务器在哪个腾讯云账号、实名主体是谁 |
| **符合条件的腾讯云服务器** | 用来生成「**备案授权码**」。要求：**CVM 包年包月**（非按量计费）**或 轻量应用服务器**，**购买时长 ≥ 3 个月**，且该机器**还有可用备案名额**（一台机器有固定网站备案数量额度）| ⚠️ **关键待确认**：129.204.166.13 这台是不是包年包月/轻量、买了≥3个月、有名额 |
| 网站负责人本人在场 | 要做**人脸核验 + 短信核验**，必须负责人(张含)本人手机+本人刷脸 | ⚠️ 备案时张含本人要配合 |

> ❗ 如果 129.204.166.13 是**按量计费**或时长不足 3 个月，需要先**续费/转包年包月**，或**单独买一台符合条件的腾讯云轻量**（最便宜的就行，几十块/年）来生成备案授权码——授权码和你网站实际跑哪台机器**可以不是同一台**，授权码只是"接入凭证"。

## 四、详细操作步骤

### 🥇 推荐方式：微信小程序「腾讯云备案」（最省事，刷脸/短信核验一条龙）

1. 微信搜索并打开小程序 **「腾讯云备案」**（或腾讯云 App → 备案）。
2. 用**持有服务器的那个腾讯云账号**登录。
3. 选 **「我要备案」→「新增接入」**（也叫"接入备案 / 已备案的网站新增接入"）。
4. **填写/生成备案授权码**：选你符合条件的腾讯云服务器（CVM/轻量）→ 生成「备案授权码」。
5. **选择备案类型 = 新增接入**，填入已有备案号 `粤ICP备2025447525号-2`。
6. **填主体信息**：主办单位=广州黄雀传媒有限公司、证件=营业执照+信用代码、负责人=张含 + 身份证号（**和原备案一致**）。
7. **填网站信息**：域名 huangquechuanmei.com、负责人张含、服务内容（和原备案一致）。
8. **上传资料**：营业执照、张含身份证正反面，按提示传。
9. **真实性核验**：小程序里**人脸识别（张含本人刷脸）**。
10. 提交 → **腾讯云初审**。
11. 初审通过后，**工信部发短信**到张含手机 → **24 小时内按短信指引回复核验码**（这步漏了备案会失败）。
12. **管局审核** → 通过后收到《备案成功》通知。

### 备选：腾讯云控制台（电脑端）

- 网址：`https://console.cloud.tencent.com/beian`
- 流程一样：备案管理 → 开始备案 → 新增接入 → 生成备案授权码 → 填主体/网站 → 上传 → 核验 → 提交。
- 人脸核验仍需用手机小程序/App 扫脸。

## 六、注意事项 / 常见坑

1. **服务器条件不够 = 做不了**：按量计费 / 不足 3 个月 / 名额已满 → 先续费转包年包月或另买一台便宜轻量生成授权码。
2. **信息必须和原备案一致**：公司名、信用代码、负责人姓名/证件号。负责人若想换人，要先做"备案信息变更"，会更慢。
3. **短信核验别漏**：工信部短信 24 小时内不回复 → 备案被退回重来。
4. **人脸核验要本人**：张含本人刷脸，找别人代刷过不了。
5. **原阿里云接入怎么办**：新增腾讯接入后，域名可以**同时有阿里云+腾讯两个接入**（多线接入，合规），不冲突。原阿里云接入可保留也可后续注销。
6. **谁来做**：持有腾讯云服务器的那个账号登录操作 + 张含本人配合刷脸/收短信。
