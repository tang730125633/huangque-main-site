## 1. 我们是谁（业务背景）

**黄雀 AI（黄雀传媒 / 黄雀 AI 创智）** 是一个面向企业的 **AI 获客 + AI 内容生产 SaaS 平台**。

- 母品牌：**黄雀传媒**（广州黄雀传媒有限公司）。
- 服务对象：**美业、电商、IP 赋能、品牌孵化**等实体/网络生意的老板和团队。
- 商业定位：既对外**售卖软件与服务**，也是公司内部 **AI 板块**的获客与内容中台。
- 一句话价值主张：**「评论区获客，AI 内容成交。」**——先从公开评论区里精准捞到高意向客户，再用 AI 把文案/图片/视频/数字人口播一条龙做出来，完成成交。

**品牌内核**：**黄雀**取自"螳螂捕蝉，黄雀在后"——**精准、敏锐、后发制人的捕手**。气质关键词：锋利、精确、可信赖、有技术感。Logo 是一只**金色麻雀/黄雀**剪影。

## 2. 两条核心产品线

### 产品① 评论区精准获客（Lead-Gen）
关键词 → 抖音 / 小红书 搜视频 → 扒评论区 → AI 意图过滤 → **精准客户名单**。

- 输入：行业关键词（如"美业获客""美容院拓客""皮肤管理"）。
- 输出：一张**精准客户表**，每条含：昵称、抖音号、IP 属地、**需求原话**、来源视频、主页链接。
- 真实战绩（可放进设计稿的数字）：**1,770+ 条评论采集 · 3,168 账号线索池 · 100+ 精准名单 · 80% 回复率**。
- 卖点：自动过滤掉中介噪音/闲聊，只留**正在表达需求**的真人客户，可直接私信。

### 产品② AI 内容工作台（Content Studio）
同一套工作台继续把线索变成成交内容：

- **关键词获客 / 文案编导 / AI 作图 / 数字人口播 / 资产库 / 点数账本** 六大模块。
- 真实能力：AI 生图（gpt-image-2）、数字人口播视频（Seedance）、真人对口型、飞书 Bot 矩阵（34 个 bot 在线）一键回传客户群。
- 计费：**点数制**（如"剩余点数 340"），失败自动退点，成本/毛利可观测。
- 典型场景：美业老板用真人形象生成数字人首帧 + 活动海报 + 小红书封面文案，推送到客户飞书群。

## 3. 受众与调性

- **看这个网站的人**：行业同行、潜在客户老板、想加入的人才、合作方。
- 要传达：**专业、靠谱、有真实成果、技术领先**，不是花架子。
- 既要**对外销售感**（首页要能让陌生老板秒懂价值、想预约演示），也要有**工具产品的硬核感**（功能页要像真能干活的后台）。

## 4. 设计语言（统一规范 · 所有页面通用）

| 维度 | 规范 |
|---|---|
| **整体气质** | 深色"作战台 / operating desk"，暗色仪表盘 + 暖金高光，数据密集但优雅、留白克制 |
| **背景** | 深海军蓝 / 近黑 `#050811` ~ `#0b1018`，可带极淡的径向辉光 |
| **主强调色（金）** | 黄雀金 `#e7b24c`（CTA 按钮、关键数字、高亮、Logo） |
| **次强调色（青）** | 科技青 `#35d6c6`（链接、状态、次级高亮） |
| **状态色** | 成功绿、警示橙、失败红，低饱和、克制使用 |
| **字体** | 正文用干净无衬线（思源黑体 / Inter 风）；**数字、点数、ID 用等宽 mono 字体** |
| **布局** | 卡片化、模块化、栅格整齐；圆角中等（12–18px）；卡片有微妙描边 + 轻微内发光/阴影做层次 |
| **组件** | 分段控件(segmented)、标签 chip、状态 pill、数据表格、缩略图网格、底部操作条 |
| **参考基调** | Linear / Vercel / Raycast 的暗色界面，但**更暖、有金色**，更像"专业作战中台" |

## 5. 要生成的页面（逐页要素）

> 每张图都默认套用第 4 节的设计语言。下面只补充每页**特有的结构和内容**。

### 5.1 主页 / Landing（先出这张）
营销落地页 + 产品首页一体。
- **顶部导航**：左侧黄雀金色 Logo + "黄雀 AI"；中间菜单（产品 / 解决方案 / 价格 / 关于）；右侧"登录"+ 金色实心按钮"预约演示"。
- **Hero 主视觉**：超大粗体标题 **「评论区获客，AI 内容成交。」**，一行副文案；两个 CTA（金色实心"进入工作台" + 描边"看演示"）。
- **数据条**：4 个等宽金色数字计数器——采集评论 `1,770+` / 账号线索池 `3,168` / 精准名单 `100+` / 回复率 `80%`。
- **产品预览卡**：Hero 右侧悬浮一张产品截图卡，展示一张美业数字人海报样片（真实作品感）。
- **能力区**：三张能力卡片（关键词获客 / AI 作图 / 数字人口播），各带图标 + 一句话。
- **底部**：客户/场景背书 + 页脚（公司名 + 备案号 `粤ICP备2025447525号-2`）。
- 整体深色 + 金色辉光，专业、有锋芒。

### 5.2 登录页 / Login
- 深海军蓝背景，**中央一张玻璃质感登录卡**，卡片后方有柔和的金色径向辉光。
- 卡片内：黄雀 Logo + "黄雀 AI 工作台"标题；输入框（手机号、验证码 / 密码）；金色整宽"登录"按钮；下方小字链接"团队口令登录"。
- 可选：左半屏是品牌展示区（slogan + 抽象的黄雀/数据流意象），右半屏是登录卡。
- 极简、聚焦、高级感。

### 5.3 充值页 / 点数充值（在 App 内）
- 左侧有窄图标导航栏（说明这是登录后的后台页）。
- 顶部：一张余额卡，大号金色等宽数字 **「剩余点数 340」** + "本月已消耗 / 毛利"小指标。
- 中部：**点数套餐卡片网格**（4 档），例如：`100 点 / ¥xx`、`500 点 / ¥xx 送 50`、`2000 点 / ¥xx 送 400`（标"推荐"，金色描边高亮）、`企业版 / 联系销售`；每张含 点数 · 价格 · 赠送 · "购买"按钮。
- 支付方式行：微信支付 / 支付宝 图标。
- 下方：**消费明细表格**（时间 / 项目 / 类型 / 消耗点数 / 余额）。
- 干净、可信、收银台级别的清晰，金色只点缀在"推荐档"和数字上。

### 5.4 功能页 · AI 工作台（以"AI 作图"为例）
经典**三栏作战台布局**：
- **左**：窄竖排图标导航（今日 / 获客 / 作图 / 视频 / 资产 / 成本），当前项金色高亮。
- **中**：创作面板——提示词输入框 + 分段控件（模型 / 比例 / 清晰度 / 张数）+ "灵感案例 · 做同款"模板缩略图行 + 底部金色按钮"立即生成（340 点）"。
- **右**：结果检视区——展示一张生成的美业海报 + 一排操作（再生成 / 继续改 / 转视频 / 发飞书 / 下载 / 入库）+ "最近作品"缩略图网格。
- **顶栏**：当前客户（如"仙颜美容 · 示例"）+ 在线状态"34 个 Bot 在线"。
- 信息密集但优雅，金 + 青点缀。

### 5.5（可选）今日 Dashboard
登录后首屏总览：
- "今日行动"卡片列表（如 N 个任务失败可重试、N 个作品待推送客户群）。
- "今日关键指标"数字卡片行（客户群消息 / 今日任务 / 今日成本 / 失败率 / 平均响应）。
- "三条生产线状态"（抓取·文案 / 图片·海报 / 数字人·视频）的进度卡。

### 5.6（可选）获客结果页
- 关键词搜索框 + 行业关键词 chip 推荐（美业 / 电商 / IP 打造…）。
- 一张**精准客户名单表**：# / 昵称（带主页链接）/ 抖音号 / 属地 / 需求原话 / 来源视频。
- 顶部统计：🔥 精准客户 / 🗑️ 中介噪音 / 💬 闲聊 / 评论总数。

## 6. 出图规格 & 注意事项

- **桌面端浏览器视角**，**16:9**（约 1456×816）；如要移动端单独说明。
- **一次出一页**，同一 Brief 下保持风格统一；可以先给我各出 **2 版风格探索**，我选定方向后再细化。
- 文字（尤其中文）可能渲染不准——**正常，忽略即可**，我看的是版式/配色/组件/层级/气质。
- 不要：卡通风、廉价 SaaS 模板、浅色默认 Bootstrap 风、堆砌渐变。
- 要：深色高级、金色锋芒、数据感、真实可落地的组件。
