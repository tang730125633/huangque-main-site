# 工单 · 影视级模仿(motion)模式加画面比例选项（Issue #345）

> 冲突组：**B（`site/workbench/video.html`）**。抢 `lock/B`。先读 §0+看板。

## 现象
视频生成页「影视级模仿(动作模仿/motion)」模式**没有画面比例(ratio)选择控件**（9:16/16:9/1:1 等），用户无法控制输出比例。数字人口播/文本模式有比例控件（video.html:286-287），motion 没有。

## 根因（已核实）
- **后端已支持**：`generate_heygen_motion_video(image_file, reference_video_file, resolution, ratio, duration, ...)`（video.py:675）已接收 `ratio` 参数。
- **前端硬编码**：motion 提交处 `ratio:'9:16'` 写死（video.html:~1321），motion tab 无比例控件；只有数字人/文本模式用用户选的 `selectedRatio`（由 286-287 的 `data-ratio` 按钮设，line 1155）。

## 待做（前端为主）
1. motion 模式 UI 增加画面比例控件（复用数字人模式的 `.seg` + `data-ratio` 样式：9:16/16:9/1:1/4:5/5:4）。建议独立变量 `selectedMotionRatio`（默认 9:16），别和数字人的 `selectedRatio` 串了。
2. motion 提交 body 的 `ratio` 从写死 `'9:16'` 改为 `selectedMotionRatio`（video.html:~1321 及 currentVideoDraft:~1313）。
3. 默认值 9:16，与其它模式一致。

## ⚠️ 必须先验证（决定要不要做/怎么做）
**HeyGen motion(视频转视频/act-two) 的输出比例是否真受 ratio 控制**——很多"动作模仿"类接口输出**跟随参考视频的原始比例**，ratio 可能被忽略。做之前先用不同 ratio 各跑一条 motion，确认线上真能改比例：
- 若**生效** → 按上面加控件。
- 若**被忽略**（输出恒等于参考视频比例）→ 不加控件，改为在 motion 区显示一行说明「输出比例跟随参考视频」，并在 issue 回复说明，避免给用户假控件（违反四态/假控件收口原则，见 FAKE-UI 系列）。

## 验收
1. （若生效）motion 选不同比例，输出视频比例正确；默认 9:16。
2. 不影响数字人/文本/换装模式的比例（各自独立，不串值）。
3. 不回退 video.html 近期改动（#294 __cookie__/#302 vidBox/#276 fetchImagePrefill/#333 prefillMode）。
