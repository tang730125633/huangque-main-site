# 工单 · 资产收藏 + 标签

> 供其他 agent 独立执行。开工前先读《工单-其他agent实施-20260703》§0 公共上下文 + 《任务看板》领取流程。
> **冲突组：A（后端核心 content_api/content_domains）+ C（assets.html）** —— 认领需同时抢到 `lock/A` 和 `lock/C`。

## 目标与价值
资产越来越多，找不到常用的。加**收藏**（星标常用作品）+ **标签**（自定义分类），配合 F7 已有的搜索，让资产可管理、可快速定位。

## 现状（已核实）
- 前端 `site/workbench/assets.html`：图片/音频/视频/数字人形象分类，已有搜索/批量下载/重生成（F7）。资产经 `/api/gen/history`、`/api/gen/audio/assets`、`/api/gen/video/assets` 加载，每条有可标识字段（job_id/url 等）。
- 后端 T8 后：HTTP 层与建表在 `content_domains/core.py`（`init_db`/`init_audio_db` 里 `CREATE TABLE IF NOT EXISTS ...` + `_ensure_column` 迁移）。点数收敛在 auth（本工单不涉及点数）。

## 技术设计
### 后端（`content_domains/core.py`，新表 + 接口，单写者、按用户隔离）
1. **新表** `asset_marks`（放 AUDIO_DB 或 JOB_DB，与被标资产同库更好；建表用 `CREATE TABLE IF NOT EXISTS`）：
   ```
   asset_marks(
     id INTEGER PK AUTOINCREMENT,
     username TEXT NOT NULL,
     asset_kind TEXT NOT NULL,      -- image/audio/video/avatar
     asset_key  TEXT NOT NULL,      -- 资产唯一标识(job_id 或 url 或 avatar id，前后端约定一致)
     favorite   INTEGER NOT NULL DEFAULT 0,
     tags       TEXT,               -- 逗号分隔 或 JSON 数组
     updated_at INTEGER,
     UNIQUE(username, asset_kind, asset_key)
   )
   ```
2. **接口**（均 `verify(token)` 鉴权、按 username 隔离）：
   - `POST /api/gen/asset/favorite`  body `{kind, key, favorite:bool}` → upsert 收藏态
   - `POST /api/gen/asset/tags`      body `{kind, key, tags:[...]}` → upsert 标签
   - `GET  /api/gen/asset/marks?kind=` → 返回本人该类资产的收藏/标签映射（前端合并到资产卡）
3. 不改现有资产加载/生成逻辑，只加"标注"这层。

### 前端（`assets.html`）
- 进分类后拉 `GET /api/gen/asset/marks?kind=` 合并到卡片。
- 每张卡加**⭐收藏**切换（调 favorite 接口）+ **标签**编辑（调 tags 接口）。
- 顶部工具条加**筛选**：只看收藏、按标签筛（与 F7 搜索叠加）。
- 复用 `cloud-shell.js?v=<hash>` 外壳、`data-active="assets"`；401 跳登录。

## 边界与注意
- **asset_key 前后端要约定一致**（用哪个字段做唯一标识，建议 job_id 优先、无则 url）。定不下时先用 url，务必前后端统一。
- 按 username 隔离，防越权读写他人标注。
- 只加"标注"层，不动资产生成/加载/点数。
- 数字人形象（avatar）也可收藏/标签（kind=avatar），前端在形象分类同样接上。

## 验收标准
1. 资产可收藏（⭐切换持久化）、可打标签，刷新后保留。
2. 可"只看收藏"、"按标签筛"，与搜索叠加正确。
3. 仅本人可见/可改自己的收藏标签；其它功能不受影响；`py_compile` 通过、health 200、无控制台报错。

## 部署与验证
- `./ship "资产收藏+标签" server/content_domains/core.py site/workbench/assets.html`
- 上线后实测：收藏/取消、加/删标签、筛选；新表 `CREATE IF NOT EXISTS` 对存量无破坏；确认漂移哨兵无新增告警。
