# 工单 · 视频播放 9:16 居中弹窗（Issue #292）

> 供其他 agent 独立执行。开工前先读《工单-其他agent实施-20260703.md》公共上下文、《任务看板》和 `DESIGN.md`。
> **冲突组：B（`site/workbench/video.html`）**。只改视频页，不碰后端、不改 `cloud-shell.js`。

## 背景

Issue #292 反馈：视频生成结果和历史记录里的播放按钮，目前是在 312px 高的预览框内原地播放。画面太小，用户需要再点浏览器 controls 的全屏按钮才能看清，体验割裂。

期望点击播放后弹出页面内全屏蒙层，中央以 9:16 竖屏比例播放视频；关闭后暂停并释放播放器。

## 目标

把 `site/workbench/video.html` 的视频播放体验改成统一弹窗：

- 输出区播放按钮：打开 9:16 居中弹窗播放。
- 历史记录播放按钮：同样打开 9:16 居中弹窗播放。
- 弹窗支持点击背景关闭、关闭按钮关闭、关闭时暂停视频并清理资源。
- 原页面卡片/预览区保留封面或占位，不再把小框作为主要播放容器。

## 现状入口

### 输出区

`renderOutputVideo(result)` 当前会把视频直接写进 `#outputPreview`：

```javascript
box.innerHTML='<video data-src="'+esc(fresh(result.video_url))+'" controls playsinline preload="none"></video>';
```

### 历史记录

`renderVideoHistory()` 里 `.history-play` 点击后调用 `hydrateVideo()`，再对小卡片里的 `videoEl.play()`。

## 实施范围

**In**

- 在 `site/workbench/video.html` 新增页面内播放弹窗样式，例如：
  - `.vidOv`：fixed 全屏半透明黑色蒙层，居中布局。
  - `.vidBox`：9:16 容器，`max-width:90vw`、`max-height:90vh`，黑底。
  - `.vidClose`：右上角关闭按钮。
- 新增 `openVideoPlayer(videoUrl, title)` 或同等函数：
  - 先移除已有弹窗，避免重复。
  - 创建蒙层和 `<video>`，设置 `controls`、`playsinline`、`autoplay`、`preload="auto"`。
  - 点击蒙层背景或关闭按钮时，暂停视频、清空 `src`、移除 DOM。
  - 尽量复用现有 `fresh()`、`esc()`、私有文件 blob 播放逻辑，避免把鉴权视频直链裸塞到不可访问的 `src`。
- 修改输出区和历史记录播放按钮点击逻辑，统一调用弹窗函数。

**Out**

- 不改后端接口。
- 不改 `assets.html` 的视频卡片播放。
- 不新增全站共享弹窗组件，不改 `cloud-shell.js`。
- 不改变视频生成、轮询、扣点、历史记录数据结构。

## 交互要求

1. 点击输出区或历史卡片的播放按钮，打开全屏蒙层。
2. 弹窗中间显示 9:16 竖屏播放器，自动开始播放。
3. 播放器在桌面和移动端都不能超出视口。
4. 点击背景或关闭按钮，关闭弹窗并停止播放。
5. 关闭后再次点击任意视频，能正常重新打开和播放。

## 边界与注意

- 如果视频 URL 是 `/api/gen/file/...` 等需鉴权资源，沿用当前页面已有的 `playableUrl()` / blob URL 思路，不能因为弹窗改造导致私有视频 401。
- 历史卡片里原本的小视频如果还保留 `video` 标签，点击播放按钮不应在小框里直接播放。
- `autoplay` 可能被浏览器策略拦截，要保留 controls，让用户可以手动点播；拦截不应报错打断页面。
- 弹窗 `z-index` 要高于页面内容和普通 toast，但不要影响登录弹窗层级。
- CSS 风格对齐视频页现有深色工作台，不要引入新的大面积配色。

## 验收标准

1. 输出区生成结果点击播放，弹出居中 9:16 播放器，视频可播放。
2. 历史记录点击播放，弹出同一套 9:16 播放器，视频可播放。
3. 关闭按钮和点击背景都能关闭，关闭后视频停止播放。
4. 未登录/鉴权失效时，仍走现有登录提示或 401 处理，不出现空白弹窗。
5. 桌面宽屏、普通 1280px 视口、移动窄屏下播放器不溢出、不遮挡关闭按钮。
6. 控制台无新增错误；`node --check` 或等价 JS 语法检查通过。
