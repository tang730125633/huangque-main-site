# 短剧口型 Provider 选型记录（阶段 0-B）

## 当前状态

代码侧已经具备 Sync Labs 与 fal.ai LatentSync 的统一适配、恢复、静音输出、脱敏报告和评测汇总能力。当前尚未使用真实 API Key 和真实样本执行收费评测，因此不能宣称任何 Provider 已通过质量验收，也不能确定默认或备用 Provider。

## 选型原则

1. 先看资金与恢复安全，再看画面质量；
2. 必须使用同一批输入与相同输出规格；
3. 自动指标只检查合同，不替代人工口型、身份和画质评分；
4. 单次成功不能代表可生产化，必须覆盖失败、超时、中断、取消和结果重拉；
5. 供应商公布价格与实际账单都要记录，差异需要解释；
6. 输出媒体必须无音轨，主音轨只由项目装配阶段掌控。

## 待执行证据

- 每家 5 条冒烟任务及账单核对；
- 每家 20～30 条完整样本结果；
- 全量人工双盲评分；
- P50/P95 耗时、成功率和失败类型；
- 进程中断后的原 Job ID 恢复；
- 成功任务结果重拉；
- fal.ai 取消任务后的最终状态与费用；
- Sync Labs 不支持运行中取消时的运营处置记录；
- 创建响应丢失后的供应商后台对账演练。
