# 短剧第 4 阶段：字幕强制对齐运行手册

## 功能边界

- 输入是已锁定的配音、字幕文本和逐句音频时间；不会修改主音轨。
- 本阶段不扣用户点数。
- 默认 Provider 使用 `faster-whisper` 读取已锁定的真实配音文件，并请求
  `word_timestamps` 与 VAD 时间戳。
- ASR 未匹配或 Provider 不可用时允许生成明确标记为 `estimated` 的降级时间，
  但置信度必须为 `null`，且不得作为自动质量门禁结果。
- 真实或估算结果都必须经过人工校对，生成不可变子版本并通过质量门禁后才能锁定。
- 人工校对支持“调整后确认”和“原样确认”；原样确认用于边界估算本身正确的情况，不要求为了过门禁而修改正确数据。
- 后续视频和合成阶段只消费当前、锁定且输入哈希未失效的版本。

## 状态和恢复

- 任务状态：`queued / running / succeeded / failed / canceled`。
- 版本状态：`needs_review / ready / locked / stale`。
- `provider_job_id` 与本地任务在同一事务中持久化，避免进程退出后失去恢复凭据。
- 同一用户、项目和 `Idempotency-Key` 的相同请求会重放；不同请求返回 `409 idempotency_conflict`。
- 相同输入使用新的 `Idempotency-Key` 再次生成时复用已有对齐版本和产物，不创建重复版本。
- 输入音频、字幕或项目修订发生变化时，旧版本按 `input_hash` 判定为失效，不能锁定或被下游消费。
- 从未启动字幕对齐的历史项目保持原阶段推进能力；一旦生成过对齐版本，必须锁定当前有效版本后才能推进。

## 质量门禁

- 项目覆盖率阈值：98%。
- 单句覆盖率阈值：95%。
- 平均置信度阈值：0.80。
- 字幕区间必须位于对应音频只读边界内，且相邻字幕不能重叠。
- 所有初始结果均带 `manual_review_required`，人工保存完整时间线后才清除。
- 只要存在估算 token，就附加 `estimated_timing_present`；真实 Provider 不可用时
  同时附加 `forced_alignment_unavailable`。
- 估算 token 的 `confidence` 必须为 `null`，不得使用固定置信度伪装真实识别结果。
- `save_adjustments` 必须至少修改一条字幕边界；`confirm_unchanged` 必须保持全部边界不变。
- 审核子版本记录审核方式、审核人、审核时间、来源版本和来源修订；审计信息不完整时禁止锁定或被下游消费。

## 故障排查

1. `transcript_not_locked`：回到配音字幕页面，逐镜头保存并锁定。
2. `missing_master_audio`：确认当前配音版本为 `done`、输入哈希一致且已解析时长。
3. `active_alignment_job`：等待任务结束，或通过取消接口终止仍在运行的任务。
4. `stale_alignment`：音频或字幕已经变化，重新生成并校对，禁止复用旧版本。
5. `timeline_boundary_invalid`：字幕时间超出对应音频边界，只调整字幕时间，不改音频时间。
6. `subtitle_overlap`：按绝对开始时间检查相邻字幕，修正重叠后重新保存。
7. `review_action_mismatch`：提交的审核方式与时间线是否变化不一致；刷新后选择“原样确认”或“保存调整并确认”。

## 发布前检查

### 真实音频对齐生产契约

生产环境必须安装 `faster-whisper`，并在部署前缓存中文识别模型。默认配置：

```text
SHORT_DRAMA_ALIGNMENT_MODEL=small
SHORT_DRAMA_ALIGNMENT_CONCURRENCY=1
```

模型加载、音频读取或 ASR 执行失败时，接口会返回带
`forced_alignment_unavailable` 的估算时间轴，必须逐句试听并人工确认，不能自动锁定。
上线前验收音频至少包含句中停顿、快慢语速变化和 ASR 漏字三种样本，并确认：

1. 停顿前后的 token 时间戳保留真实空隙。
2. 快慢语速 token 时长存在真实差异，不是按字符等分。
3. 漏字仅对应 token 标记为 `estimated`，置信度为 `null`。

### 视觉语义门禁生产契约

视觉门禁默认完全关闭，不抽帧、不加载 Whisper，也不请求视觉模型：

```text
SHORT_DRAMA_VISUAL_GATE_MODE=off
SHORT_DRAMA_VISUAL_GATE_ASR=0
SHORT_DRAMA_VISUAL_GATE_VISION=0
```

只有完成 CPU/内存、并发、超时、GPT token 成本和 SLA 评审后，才允许显式启用
`shadow` 或 `enforce`；非法或缺失的 mode 一律按 `off` 处理。

### 中文字体生产契约

正式预览和导出只允许使用 `Noto Sans CJK SC`，不得回退到 DejaVu Sans
或 libass 默认字体。生产镜像/主机必须安装：

```bash
apt-get update
apt-get install -y fontconfig fonts-noto-cjk
fc-cache -f
```

服务环境必须配置：

```text
SHORT_DRAMA_SUBTITLE_FONT=/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
```

上线前必须执行以下预检，并确认 family、文件路径和中文字符覆盖均正确：

```bash
test -f /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
fc-match --format='%{family}\n%{file}\n' 'Noto Sans CJK SC'
fc-query --format='%{charset}\n' \
  /usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc
```

应用启动后的 `_toolchain()` 会再次进行同等校验；字体缺失、family 回退、
匹配到其他文件或缺少必要中文字符时，任务以
`subtitle_font_unavailable` 终止，不进入渲染。

### 检查清单

1. 两份 OpenAPI 文件完全一致且不存在重复 JSON 键。
2. Python 对齐、主音轨、字幕合成及短剧联合回归通过。
3. 生产环境通过上述 Noto CJK 字体预检。
4. 画布配音字幕前端测试通过。
5. `scripts/stamp_assets.py --check` 通过。
6. 浏览器验证生成、人工确认、锁定按钮门禁，以及锁定后进入下一阶段。
