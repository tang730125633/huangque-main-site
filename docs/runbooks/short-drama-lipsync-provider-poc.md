# 短剧口型 Provider PoC 运行手册

## 1. 目的

在不接入生产画布、扣点和用户数据的前提下，用真实短剧样本比较候选口型
Provider，形成默认 Provider、备用 Provider和 Go/No-Go 结论。

PR 0-A 只交付统一契约、样本清单、媒体探测、指标模板、脱敏报告和 Mock
合同测试。真实 Provider及真实评测属于 PR 0-B。

## 2. PR 0-A 退出条件

- Provider统一接口覆盖能力、校验、创建、查询、取消、下载和错误归一化。
- 样本清单拒绝绝对路径、目录穿越、重复 ID 和未知字段。
- 输入哈希同时绑定视频、音频、台词、人物、比例和输出规格。
- FFprobe 使用参数数组执行，不经过 shell。
- 报告原子写入，失败不留下半文件。
- Token、密钥、Cookie和 URL查询参数不会进入报告。
- Mock Provider不访问网络、不收费，并通过合同测试。
- 真实媒体、报告和供应商响应不会被 Git提交。
- Provider Job ID在创建后立即原子持久化，失败和超时也会生成报告。
- 两个Provider的状态、媒体、报告和人工评分目录互相隔离。
- 超时任务按能力声明执行取消，支持原 Job ID恢复查询和结果重拉。

## 3. 私有样本集

建议准备20–30条5–15秒镜头，覆盖：

- 正脸、半侧脸、侧脸、嘴部短暂遮挡；
- 正常、快速、慢速语音和句中停顿；
- 平静、激动、低声表达；
- 9:16、16:9；
- 单可见说话人、旁白、无人像；
- 画面中有多人但仅指定一名说话人。

样本放在仓库外的受控目录。清单使用脱敏 `sample_id`，不得出现用户姓名、
手机号、账号或公开下载链接。

## 4. PR 0-B 接入规则

真实 Adapter必须只实现
`tools.lipsync_poc.adapters.base.LipsyncProvider`，不得修改生产 API：

1. 从环境变量读取密钥；
2. `capabilities()` 声明真实限制；
3. `create_job()` 保存并返回真实 Provider Job ID；
4. `get_job()` 支持进程重启后查询；
5. `fetch_result()` 支持已完成结果重新下载；
6. `normalize_error()` 输出统一 code/message/retryable；
7. 供应商响应进入报告前必须执行统一脱敏；
8. 不得在 PoC 阶段调用项目扣点服务。
9. 使用请求的 `input_hash` 作为供应商幂等键或派生稳定幂等键；
10. Provider名称必须是安全的小写标识，不能包含路径分隔符。

运行产物固定使用以下布局：

```text
<output-dir>/<provider>/
  state/<sample-id>.json
  media/<sample-id>.mp4
  reports/<sample-id>.json
```

新运行检测到已有状态时必须停止。进程中断或轮询失败使用 `--resume`，已完成
结果重新下载使用 `--refetch`；禁止通过删除本地状态绕过费用核对。

恢复准入必须根据最后确认的 Provider 状态计算并同时约束报告和 CLI：

- `queued/running/unknown`：允许恢复查询，禁止结果重拉；
- `succeeded`：禁止恢复查询，按 Provider 能力决定是否允许结果重拉；
- `failed/canceled/cancelled`：默认禁止恢复查询和结果重拉；
- 超时取消失败且最后状态仍在运行：保留恢复查询能力；
- 超时取消成功：以取消返回的 Provider 状态为准。

脱敏是失败处理的安全兜底。非法端口、破损 IPv6、异常 Unicode netloc 等
畸形 URL 必须整体替换为安全占位符，任何 Provider 异常字符串都不能阻止
状态文件和失败报告落盘。

## 5. 评测流程

1. 运行 `--validate-only` 冻结样本和输入哈希。
2. 用5条样本做每个Provider的冒烟验证。
3. 确认异步查询、超时、取消和结果重拉。
4. 对全部样本运行两个候选Provider。
5. 汇总成功率、P50/P95耗时、成本、输出规格和错误类型。
6. 完成双盲人工评分：口型、身份、画质、整句偏移。
7. 执行进程中断、重复查询、结果重拉等恢复验证。
8. 形成默认Provider、备用Provider和Go/No-Go结论。

## 6. 建议准入门槛

- 有效样本成功率不低于95%；
- 人工可用率不低于85%；
- 明显整句错位率低于5%；
- AV偏移P95不超过120ms；
- 身份保持平均分不低于4/5；
- Provider Job ID可恢复查询和结果重拉；
- 费用归属明确，没有无法确认的收费终态；
- 输出音轨可被安全识别和移除。

未通过资金恢复、任务恢复或数据安全要求时，即使画面质量合格，也只能给出
Conditional Go，禁止进入正式扣点流程。
