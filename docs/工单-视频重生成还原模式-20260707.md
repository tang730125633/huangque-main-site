# 工单 · 视频资产「重新生成」还原原始模式（Issue #325）

> 冲突组：**C（`site/workbench/assets.html`）+ 可能 A（视频资产存 mode 字段）**。抢 `lock/C`（+A若改后端）。先读 §0+看板。

## 现象
资产库视频「重新生成」**一律跳数字人口播**，不管原视频是动作模仿/换装/图生视频/文本生视频哪种模式，参数也不回填。

## 待做
1. **视频资产记录生成模式**：video 资产数据加 `mode/function` 字段（digital_human/motion_copy/outfit_change/img2video/txt2video）。若后端没存→需 A 组补（建视频任务时把 mode 写进资产）。
2. **「重新生成」按 mode 跳对应页 + 回填参数**（提示词/模特/音色/参考视频等），改 assets.html 的 regenerate 逻辑（现在写死跳口播）。
3. **向下兼容**：历史数据无 mode → 默认按数字人口播（现状），不报错。

## 验收
1. 各模式生成的视频，重新生成跳**对应**功能页并回填原参数。
2. 无 mode 的历史视频默认口播，不崩。
3. 不影响资产页其它功能（#300提示词/#311视频放大/收藏/删除/下载）。
