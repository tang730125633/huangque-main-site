# 工单 · F6 视频模板库（前端版：预设一键预填）

> 供其他 agent 独立执行。开工前先读《工单-其他agent实施-20260703》§0 公共上下文
> （仓库/分支PR/ship/DESIGN.md/漂移哨兵/**禁止服务器直改**）。**本工单纯前端，只改 `site/workbench/video.html`（+ 一个模板清单文件），不碰后端**（这样可与后端工单/其它前端页面工单并行、不撞车）。

## 目标与价值
非技术用户不懂分辨率/比例/音色/字幕怎么配。给一批**预设模板**（一个模板 = 一套参数组合），点一下就把视频页的各项设置**预填**好，用户只需上传照片/填文案即可出片。

## 现状（已核实）
- `video.html` 视频页有这些可选参数（点选即改对应 JS 变量）：
  - 功能 `data-function`（talking 口播 / motion 动作模仿）
  - 音色 `selectedVoice`、分辨率 `selectedResolution`（720p/1080p/4k）、比例 `selectedRatio`（9:16/16:9/1:1/4:5/5:4）
  - 动作幅度 `selectedMotion`（low/medium/high）
  - 字幕 `selectedSubtitle`（on/off）+ 样式 `selectedSubtitleStyle`（white/variety/bar）
- 这些就是模板要预填的字段。

## 范围
- **In（纯前端）**：内置若干预设模板，点选自动预填上述设置；模板从清单文件读（便于以后加）。
- **Out（不做，需后端）**：用户"保存自定义模板"（要持久化 → 后端，留待后端工单后）。

## 方案（清单驱动，零后端）
1. **模板清单**：新增 `site/workbench/assets/video-templates.json`，形如：
   ```json
   [
     { "name": "美业口播·竖屏带字幕", "function": "talking", "resolution": "1080p",
       "ratio": "9:16", "motion": "medium", "subtitle": "on", "subtitle_style": "white" },
     { "name": "综艺大字·短视频", "function": "talking", "resolution": "1080p",
       "ratio": "9:16", "motion": "high", "subtitle": "on", "subtitle_style": "variety" }
   ]
   ```
   本期放 3–6 个常用模板。以后加模板只改这个 json、不改代码。
2. **前端模板选择器**：视频页加一个"模板"入口（一排卡片/芯片），进页 `fetch` 该 json 渲染。
   - 点某模板 → 依次设置对应选择器（触发现有的点选逻辑 / 直接置 `selectedXxx` 并高亮对应按钮），把功能/音色/分辨率/比例/动作/字幕都预填好。
   - 预填后用户可再手动微调；清单缺失/加载失败优雅降级（不显示模板区、不报错）。
   - 只"预填设置"，**不自动提交生成**（避免误扣点）。
3. **风格**：先读 `DESIGN.md`，复用 `cloud-shell.js?v=<hash>` 外壳与视频页现有控件样式。

## 边界与注意
- **只改前端** `video.html` + 新增 `video-templates.json`；不碰后端、不改生成逻辑。
- 模板只改**已有选择器的选中态**，不新增参数。
- 音色字段：若模板指定的音色 key 用户没有，优雅跳过该项（不报错），其它照填。
- 点模板只预填、不生成。

## 验收标准
1. 视频页出现模板选择器（从 json 读，本期几个模板的名字/卡片）。
2. 点一个模板 → 功能/分辨率/比例/动作/字幕开关+样式都被正确预填、对应按钮高亮。
3. 往 json 加一条 → 模板区自动多一项（无需改 JS）。
4. 预填后能正常生成；不点模板时行为与现状一致；口播/动作模仿均不受影响；无控制台报错。
