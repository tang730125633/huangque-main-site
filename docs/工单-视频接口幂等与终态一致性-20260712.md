# 视频接口幂等与终态一致性

## 背景

Issue #60 最新压力测试反馈指出，`POST /api/gen/video`、`POST /api/gen/video/batch`、`POST /api/gen/tryon`、`POST /api/gen/xiaole_video` 在客户端超时或重复点击时缺少请求幂等保护，可能重复创建任务并重复扣点；任务查询中的 `status`、`phase` 与退点状态也需要统一。

## 范围

- 冲突组：A。
- 文件：`server/content_domains/core.py`、对应自动化测试。
- 不改前端，不直改服务器，不包含素材转 COS、队列 ETA、监控指标等后续独立事项。

## 验收

1. 四个视频提交接口接受 `Idempotency-Key`；同用户、同接口、同请求体重放时返回首次成功响应，不再次扣点或建任务。
2. 同一个 key 携带不同请求体时返回 HTTP 409 和稳定错误码。
3. 未提供 key 时保持现有行为；非法或过长 key 在扣点前返回 HTTP 400。
4. `GET /api/gen/job/{id}` 对成功、失败任务返回一致的终态 `phase`，并返回布尔字段 `refunded`。
5. 单元/HTTP 回归测试、`py_compile` 与 CI 门禁通过。
