# 渠道管理与本地验收

入口：运营后台 → 系统管理 → 渠道管理。

## 本次实现

- 新增渠道、API地址、加密密钥替换、实际模型、直连/HTTP代理、请求超时、并发、等待队列和每分钟调用限制。
- 独立 SQLite 数据库存储配置版本、映射、测试/任务记录和审计，不修改公共 jobs 表结构。
- 新任务入库前解析映射并保存渠道编号与版本；执行读取该版本的地址、模型与密钥。已有任务不随后台配置变更。
- 保存配置使用版本冲突检测；回滚生成新版本。停用渠道阻止映射到该渠道的新任务。停用映射恢复原调用方式。
- 主/备用渠道配置和手动切换；不自动重发生成 POST，提交不确定或工单查询中断显示结果未知，保留供应商编号。同一业务任务不重复提交。
- 连接、鉴权和完整生成测试分开显示。完整测试使用预备提示词和参考图；图片必须实际解码，视频必须经过 ffprobe 检查视频流。未取得用户接收证明，不能当成交付成功。
- 按配置周期执行连接检测；每天北京时间指定小时执行生成测试。原子预留每日测试次数和预算，失败/未知同样计入预留。
- 渠道故障、恢复和巡检受阻进入持久通知队列，通过已配置的通用 Webhook 发送；沿用退避重试和失败记录。重复同状态错误不反复通知。
- 渠道调用记录显示任务号、供应商单号、配置版本、耗时与故障阶段；实时任务详情补充渠道配置版本。
- 后台每15秒更新列表；编辑表单期间不覆盖输入。

## 当前协议支持范围

| 协议 | 能力 | 基础地址要求 |
|---|---|---|
| OpenAI 兼容图片 | 单张文生图，返回 data[].b64_json 或 URL | 含 `/v1` 等版本前缀，调用 `/images/generations` |
| MiniMax H3 | 文生视频、最多5张参考图，MiniMax-H3/2K | MetaSo H3 协议前缀，例如 `/api/minimax`，调用 `/v2/video_generation` |
| Grok 视频 | 文生视频、单参考图，最长15秒，720p | 含 `/v1`，调用 `/videos/generations` |

兼容中转必须真正实现对应请求/响应协议。不能把任意 API 地址当成兼容协议。
图片编辑、多产物、视频编辑、多图 Grok、短剧绑定任务不通过此通用映射处理；使用现有专用适配器。图片接口返回尺寸由对应模型协议决定，启用正式映射前需要核对前台尺寸约定。
MiniMax 没有在本适配器中可可靠判定的独立鉴权接口，鉴权检测显示“条件未满足”，需用完整生成测试验证；不会把找不到工单误判成鉴权通过。

映射沿用现有前台请求标识：视频 `grok/minimax/omni/micro`，图片为请求中的 `model`。后台说明可以写“黄雀1”；本改动不改前台显示文案。新增前台请求标识还需要接入前台、价格与功能权限。

## 生产启用所需配置（本次未部署）

后台、内容服务和独立 imggen 图片服务必须共享以下配置，且服务账号应有读写权限：

- `HQ_CHANNEL_DB`：渠道管理数据库的同一绝对路径。
- `HQ_OBSERVABILITY_DB`：执行证据与通知数据库的同一绝对路径。
- `HQ_PROVIDER_KEYS_MASTER_KEY`：现有保险箱使用的32字节 Base64 主密钥，两服务必须一致。不得提交到 Git。旧配置版本依赖此主密钥解密，不可直接轮换丢弃。
- `CONTENT_OUT`：可供内容服务读取的产物目录，后台完整测试也写入这里。
- 系统需安装 Pillow、cryptography、ffprobe；视频测试没有 ffprobe 会失败，不会给出假通过。

先创建停用的渠道，填写真实配置和测试素材，完成连接/生成核验，再启用对应映射；正式启用前还需通过原“功能状态”中的前端用户旅程 E2E。
渠道生成测试验证的是配置→供应商→成品；没有自动操作前台，也不验证用户实收。

通知设置接受通用 JSON Webhook 接收器，载荷含 event/service/occurred_at，不包含用户数据、密钥和产物。不是飞书、企微机器人原生消息适配器；需要接收器转换。HTTP 2xx 只证明接收端接受，发送记录不证明人已阅读。沿用单通知发送实例的部署约束。

预算是管理员按供应商价格填写的预留额度，不是供应商实扣金额；不支持余额查询或账单对账。每分钟限制约束任务/检测的启动，供应商异步结果查询另按5秒间隔执行。队列等待最多120秒，生成轮询最多1800秒。
数据库版本、审计、执行记录和测试产物暂不自动删除，正式部署需要配套存储保留策略。中断的已提交任务保留未知状态，不自动再次付费生成；未提交的测试可由下一轮监控重新认领。

## 本地验收

本地预览在 `http://127.0.0.1:8766/admin-console/`，使用仓库外独立数据库与模拟供应商。只允许本机模拟地址，不向外部发送通知。生成测试确实返回一张模拟图片并核验文件，不能据此声称真实供应商健康。

测试覆盖配置加密/脱敏、旧版本快照、并发预算、健康过期、回滚、调度认领、未知不重试、本机HTTP图片生成与核验、两种视频协议工单契约、本机Webhook接收和既有任务扣点/后台日志回归。
生产密钥、真实视频产物、真实代理出口、正式通知接收端和前台用户旅程仍需在正式配置后验收。
