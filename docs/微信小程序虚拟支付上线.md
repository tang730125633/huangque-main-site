# 微信小程序虚拟支付上线

本实现只接入微信官方“小程序虚拟支付”，不再使用普通 `wx.requestPayment` 购买点数。

## 服务器配置

真实值只写入 `/home/ubuntu/auth-service/auth.env`，权限保持 `0600`，不要提交到 Git：

```text
WX_MP_APPID=小程序AppID
WX_MP_APPSECRET=小程序AppSecret
WX_VIRTUAL_PAY_ENV=0
WX_VIRTUAL_PAY_OFFER_ID=虚拟支付后台的offerId
WX_VIRTUAL_PAY_APP_KEY_PROD=虚拟支付后台的现网AppKey
WX_MESSAGE_PUSH_TOKEN=消息推送自定义Token
WX_MESSAGE_PUSH_AES_KEY=消息推送的43位EncodingAESKey
```

沙箱测试时将 `WX_VIRTUAL_PAY_ENV` 改为 `1`，并配置 `WX_VIRTUAL_PAY_APP_KEY_SANDBOX`。现网版本必须使用 `env=0`。

默认商品必须先在“小程序后台 → 虚拟支付”上传并发布，ID 和价格要与服务端完全一致：

| 商品 ID | 点数 | 价格（分） |
|---|---:|---:|
| `hq_points_1000` | 1000 | 9900 |
| `hq_points_2000` | 2000 | 19900 |
| `hq_points_5000` | 5000 | 49900 |

如需改变档位，用 `WX_VIRTUAL_PAY_PRODUCTS_JSON` 覆盖默认商品；不要仅修改小程序显示价格。

会员折扣订单的 `goodsPrice` 仍须传上述已发布原价，折后单价通过
`activitySellingPrice` 传给微信。修改原价后必须重新运行商品同步脚本并等待现网发布生效。

配置完成后可在认证服务目录运行 `python3 sync_virtual_pay_goods.py`，脚本会按当前环境逐个上传、等待处理完成并逐个发布这些商品（微信接口每次最多提交 1 个道具）。
商品图片默认使用 `site/assets/cloud/virtual-pay-item-200.png`，微信要求该图片必须严格为 `200×200` 像素且能通过公网 HTTPS 访问。

## 到账安全

- 小程序每次付款前调用 `wx.login`，服务端用 `code2Session` 获取当前 `openid` 与 `session_key`。
- `session_key` 只在内存中参与用户态签名，不写数据库、不返回明文。
- 小程序调用 `wx.requestVirtualPayment`，不存在普通微信支付兜底入口。
- 前端 success 不直接加点；服务端调用 `/xpay/query_order` 核对订单状态和金额。
- 用户加点、订单置为已到账、点数审计在同一个 SQLite 事务中完成。
- `order_id` 是主键，重复确认不会重复加点；未完成订单会在再次进入充值页时自动补查。
- 到账后调用 `/xpay/notify_provide_goods` 标记发货，失败会保留错误并在再次确认时重试。

## iOS 消息推送

在「小程序后台 → 开发与服务 → 开发管理 → 消息推送」配置：

- URL：`https://huangquechuanmei.com/api/auth/wechat/message-push`
- Token：与服务器 `WX_MESSAGE_PUSH_TOKEN` 一致
- EncodingAESKey：与服务器 `WX_MESSAGE_PUSH_AES_KEY` 一致
- 加解密方式：安全模式
- 数据格式：JSON
- 推送事件：`xpay_goods_deliver_notify`、`xpay_refund_notify`、`xpay_complaint_notify`、`xpay_subscribe_ios_refund_query_notify`

服务端会验签、解密并校验 AppID。iOS 退款问询会根据本地发放状态返回决策与凭据；Apple 最终退款成功后，`xpay_refund_notify` 会幂等撤回该订单发放的点数。

## 上线前验证

1. 先在沙箱发布同 ID 商品，真机支付一笔并确认只到账一次。
2. 重复调用确认接口，点数不能再次增加。
3. 将价格不一致的模拟查单响应注入测试，必须拒绝到账。
4. 切换 `WX_VIRTUAL_PAY_ENV=0` 和现网 AppKey，确认商品已在现网发布。
5. 重启 `huangque-auth` 后检查 `/api/auth/health`，再上传小程序体验版真机测试。
