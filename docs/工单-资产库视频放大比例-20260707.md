## 现象（#306）
资产库视频资产点击放大预览，播放窗口比例不对（被拉伸/裁剪/黑边），不是正确比例。

## 根因（已定位，2026-07-07）
`assets.html` 的 `videoCard(x)`（约 line 525-545）：
- `media` 容器固定 `aspect-ratio:4/3`（line 535）
- `<video>` 用 `object-fit:cover`（line 540）→ **把视频裁剪填满 4:3 框**。口播视频是 9:16 竖屏，塞进 4:3 框被 cover 裁掉上下 → 画面变形/被切。
- **且当前没有"点击放大"弹窗**，是在卡片 4:3 小框里内联播放（`hydrateVideo` 挂 src）。

## 待做（纯前端，改 `assets.html` videoCard）
1. **不裁剪变形**：视频播放/放大统一 `object-fit:contain`（letterbox/pillarbox 居中，保持原始比例不拉伸不裁），替换现在的 `object-fit:cover`。
2. **点击放大弹窗**（issue 要的"放大"）：给视频卡片加**点击→居中蒙层弹窗**播放大图，容器用 16:9（或自适应视频真实比例），视频 `object-fit:contain`。
   - 可**复用 video.html #302 已实现的 vidBox 弹窗模式**（居中蒙层 + 点外关闭 + ESC + pause/revokeObjectURL 释放），但**容器比例改为不裁剪**：要么 16:9 外框 + 视频 contain 居中（9:16 视频会有左右黑边，正常 letterbox），要么外框自适应视频真实宽高。
   - 视频要走 `assetUrl()`（现有函数）带鉴权取 blob 再放（私有视频，跟 #302 一致）。
3. **关闭释放**：关弹窗时 `video.pause()` + 若 blob 则 `URL.revokeObjectURL`（防内存泄漏，#302 已有范式可抄）。
4. **XSS**：标题/prompt 进 DOM 用 `textContent`/`esc()`，别 innerHTML 拼。

## 验收标准
1. 视频资产点击能放大到居中大窗，**画面不拉伸、不裁剪**（原始比例，letterbox 居中，无变形）。
2. 9:16 口播视频和 16:9 横屏视频都正确显示（各自真实比例）。
3. 关闭弹窗视频暂停、资源释放；点外/ESC 可关。
4. 不影响资产页其它功能（图片提示词查看#300、收藏/标签/重生成/删除/下载、音频卡片）。
5. rebase 到最新 main，无回退 #300 等近期改动。
