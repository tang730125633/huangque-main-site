# 工单 · 编导「转作图 / 全部转作图」跳转丢分镜，未把画面描述带入作图页（Issue #252）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》+ `DESIGN.md`。
> **冲突组：E-script（`site/workbench/script.html`）** —— 抢 `lock/E-script`。**纯前端**，作图页已支持 `?prompt=` 预填，后端无需改。
> 相关：#250（作图「转视频」同类跨页丢参问题）。

## 现状
编导页 `script.html` 生成 3 分镜脚本后，每个分镜下及底部的「转作图」「全部转作图」点击后只跳到 `banana.html`，**分镜画面描述没带过去**，作图页提示词为空，用户得手动复制粘贴。

## 根因（issue 已排查，供参考）
- `script.html:143/163/183/194`：静态 HTML 里「转作图」「全部转作图」都是裸跳转 `<a href="banana.html">`，不带参数。
- `script.html:230`：JS 动态渲染的分镜卡里「转作图」同样裸跳转；旁边「转口播」`<a href="audio.html">` 也裸跳转（未带 `s.line`）。
- `script.html:235-266`：JS 只给「复制全部」绑了 onclick，**没给任何「转作图」绑事件**。
- 数据已具备：`script.html:228` 的 `s.scene`（画面描述）就是天然作图 prompt，跳转时没带上。
- 作图页本可接收：`banana.html:191-194` 已支持 `?prompt=`/`?engine=` 预填（灵感页「做同款」在用），编导页只是没用上。

## 改动建议
- **单分镜「转作图」**：改 JS 跳转，带该分镜 `s.scene` 作 prompt：
  `location.href='banana.html?prompt='+encodeURIComponent(s.scene)`，可选 `&engine=nb2`。
- **「全部转作图」**：banana.html 当前一次只接受单 prompt。**先走方案 (A)**：带入第一个分镜并 toast「已带入第 1 个分镜，其余请逐条转」；批量多 prompt 队列留二期（改动大，另单）。
- **静态 HTML 占位分镜**（`script.html:129-189`）的「转作图」也要改成同样 JS 跳转，或初始禁用直至生成出分镜。
- **顺带（可选）**：「转口播」（audio.html）同理裸跳转，应带 `s.line` 预填——需先确认 audio.html 是否支持预填；不支持则本单不动、另开工单。

## 验收标准
1. 编导生成分镜 → 点某分镜「转作图」→ banana.html 提示词框自动填入该分镜画面描述，可直接生成。
2. 「全部转作图」有明确行为（带入首个分镜并提示），不出现跳空页。
3. 作图页预填后引擎/比例等其余选项可正常修改并生成。
4. 「转口播」若一并修则口播文案自动带入；否则不回归。
5. 灵感页「做同款」→ banana.html 的预填回归不受影响。
