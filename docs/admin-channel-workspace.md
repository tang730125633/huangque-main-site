# 分类渠道管理

后台左侧统一为“渠道管理”，原“渠道与密钥”入口自动转到这里。原号池与服务器线路
不会自动迁移成托管渠道，现有任务路由保持不变。

## 操作入口

- **渠道列表**：按图片、视频、数字人、音频、文本、采集、视频处理分类；支持名称、
  供应商、接入方式、状态搜索筛选。历史和停用渠道默认隐藏。多用途供应商可以出现在
  多个分类中，仍使用同一份配置。未登记用途归入“其他服务”。
- **详情**：现有供应商显示可管理号池及关联用户旅程，可继续使用鉴权检测、密钥更换、
  短时审计查看及 HeyGen 授权。服务器环境变量仍需原维护方式，不假装支持在线编辑。
- **连接配置 / 测试素材 / 巡检与预算**：托管渠道在右侧抽屉编辑。供应商与官方/中转
  标记为管理员填写的目录信息，不改变真实网络路径；代理地址才控制运行时代理。
- **功能映射**：只显示兼容协议的主/备用渠道；保存前展示前台请求标识、原渠道、新渠道
  与新任务影响范围。现有任务使用旧配置快照。展示说明不修改客户页面名称。
- **测试与健康**：连接、鉴权和完整生成分别显示最新结果；24 小时后标记过期。
  现有供应商的综合线路证据单独保留，不转换为未做过的生成验证。完整功能 E2E 从
  详情进入关联旅程准备素材并发起，尚未支持的旅程仍明确阻塞。
- **操作记录**：合并托管渠道操作与既有号池、密钥查看、HeyGen 授权审计，不返回敏感详情。

托管连接巡检、每日完整测试、费用预算、通知 Webhook 沿用既有运行时。
完整测试可能产生供应商费用；定时生成需要明确配置次数与预算。未知结果也占预算，
不会自动重发付费请求。HTTP 接收通知不等于开发者已阅读。

## 实现边界

托管协议仍是 OpenAI 兼容文生图、MiniMax H3、Grok 视频；分类不代表新增协议适配能力。
未标注接入方式显示“未标注”，不根据供应商名称猜测直连或中转。
原有供应商鉴权探针保留自己的有效期，完整客户交付状态以功能旅程的实际证据为准。

目录分类完全在前端执行；供应商、接入方式写入既有版本 JSON，没有修改公共表结构。
检查列表按 connection/auth/full 各取当前版本最新一条，避免连接轮询挤掉生成证据。
编辑中不自动重建表单；退出抽屉清除密钥输入。

本地 8766 使用合成渠道与独立模拟 API。页面和隔离测试通过不代表真实供应商、代理、
告警收件端或全部客户旅程已完成生产验收。

## 渠道操作与回收站

- 托管渠道列表提供详情、编辑、启用/停用，以及“更多 → 移入回收站”。状态筛选中的
  “回收站”单独显示已删除渠道，可以恢复；恢复后默认停用，不自动恢复映射或接单。
- 启停、删除、恢复填写原因并确认影响范围，服务端核对版本。并发修改使用 SQLite
  写事务及版本比较，过期页面必须刷新后重新确认。操作人、原因、版本写入审计记录。
- 停用使后续接单和新测试被拒绝；既有任务使用原版本执行，停用不等于终止任务。
  普通付费入队入口在扣点前检查；已进入持久扣费流程的特殊子任务若入队被拒绝，
  沿用各自的补偿流程。探针通过与允许接单是不同状态，启用不会显示健康通过。
- 删除是逻辑删除，保留加密密钥、配置版本、调用证据。必须已停用，无任何主/备用
  映射引用（含未启用映射），无 pending/running 任务，以及无 queued/running/unknown
  渠道调用。任务库不可读取时拒绝删除，不把未知状态当作任务已结束。
- 删除映射单独确认：后续请求恢复原有默认调用方式，不等于停用前台功能。
  回收站渠道禁止直接保存、回滚、配置映射或测试，必须先恢复。

内置供应商的固定功能依赖保留，因此不支持删除。目前统一接单控制覆盖：

| 供应商 | 控制范围 |
| --- | --- |
| OpenAI | image 的 OpenAI 分支、sora_video |
| Google Gemini | image 的 banana 分支、xiaole_video 的 omni 分支 |
| 火山方舟 | image 的 seedream 分支、xiaole_video 的 micro 分支 |
| xAI | xiaole_video 的 grok 分支 |
| MiniMax | xiaole_video 的 minimax 分支 |

这些开关只控制上述任务入口，不阻断同步接口、鉴权探针或已落库任务的供应商请求。
其余内置服务显示“启停未接入”；密钥编辑沿用现有号池能力，服务器环境字段仍只读。
任务服务与管理服务必须共享 `HQ_CHANNEL_DB`，`CONTENT_JOB_DB` 必须指向实际共享任务库。
没有修改公共表结构：托管生命周期写入现有版本 JSON，内置状态写入 settings 的 id=2。
