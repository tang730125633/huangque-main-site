# 工单 · COS 成片存储（换装/换背景成片上传腾讯云 COS）

> 来自 tang 需求：服务器买了 COS，把生成成片放上去、前端用 COS 直链播放/下载。
> 冲突组：**A（server/content_domains）**。前端无需改动——成片的 `video_url` 换成 COS 链接后，`video.html` 照原样播放。

## 目标
把换装/换背景（`kind=tryon`）生成的成片上传到腾讯云 COS，`video_url` 返回 COS/CDN 直链；省服务器磁盘、更持久、播放更快。**配置不全时自动回退本地链接，对现有流程零影响。**

## 改动
- 新增 `server/content_domains/cos.py`：COS 上传助手。`qcloud_cos` **懒加载**，全部配置走**环境变量**（密钥绝不进 git）；`enabled()` 判断配置齐全才启用；支持公有读直链 / 自定义 CDN 域名 / 私有读签名链接；失败抛异常由调用方回退。
- `server/content_domains/video.py`：`generate_tryon_video` 收尾处，成片入库后——若 `cos.enabled()` 则上传 COS 并把 `video_url` 换成 COS 链接（失败则保留本地 `/api/gen/file/` 链接，不影响交付）；可选删本地成片省磁盘（`COS_DELETE_LOCAL`）。

## 部署前置（审核方/ops 在服务器准备，非本 PR，密钥不进 git）
1. content-api 服务机安装 SDK：`pip install cos-python-sdk-v5`。
2. 在 `/home/ubuntu/content-api/content.env`（EnvironmentFile，不进 git）加：
   ```
   COS_SECRET_ID=<腾讯云 SecretId>
   COS_SECRET_KEY=<腾讯云 SecretKey>
   COS_REGION=<地域，如 ap-guangzhou>
   COS_BUCKET=<完整桶名，带 APPID 后缀，如 xxx-1435693839>
   # 可选：COS_PREFIX=huangque/  COS_DOMAIN=https://你的CDN域名  COS_PUBLIC=1  COS_DELETE_LOCAL=0
   ```
3. **桶需公有读或挂 CDN**（前端直链播放）；私有读会走签名链接、会过期，不推荐存历史。
4. 前置就绪后再部署本 PR，`sudo systemctl restart huangque-content`。

## 验收
1. 配好 COS 后，新生成的换装/换背景成片 `video_url` 是 COS/CDN 链接，前端能播放能下载。
2. 未配 COS（或上传失败）时，成片仍走本地链接、功能不受影响。
3. `py_compile` / `ci_validate` / `unittest` 全过；不影响口播/动作模仿。
4. 密钥不在 git（`os.environ.get` 读取）。

> 本工单只做规划与后端实现，不改前端、不动服务器。
