## 目标与价值
口播视频生成后是"裸视频"，发社媒还要二次加字幕/配乐。本工单让视频生成后**自动烧录字幕**、可选**背景音乐**，产出即社媒可发。

## 现状（已核实，含服务器能力）
- 后端 `server/content_api.py`：`gen_video`（mode = text / audio / motion）→ `generate_heygen_video`（口播）/ `generate_heygen_motion_video`（动作模仿）→ 视频下载到 `video_file`；任务在 `run_job` 线程里跑，有 `phase` 阶段跟踪。
- **服务器已装 `ffmpeg`/`ffprobe`（带 `ass`/libass 滤镜）**；有中文字体 **`Noto Sans SC`**（字幕不会乱码）；**`faster-whisper` 可用**（python3 里 `import faster_whisper` OK）。
- 豆包 TTS **不返回时间戳** → 字幕时间轴用 **whisper ASR**。

## 范围
- **In**：口播模式（text / audio）自动字幕 + 可选 BGM。
- **Out（本工单不做）**：动作模仿(motion)字幕（多无语音，价值低）；实时字幕编辑器。

## 技术设计

### 后端（`content_api.py`）— 在 HeyGen 视频下载之后加"后处理"
1. **触发**：`gen_video` 接受可选参数 `subtitle`(bool)、`subtitle_style`(str)、`bgm`(str, 预设 key)。仅 text/audio 模式生效。
2. **字幕流水线**（新函数，如 `burn_subtitle(video_file, known_text=None)`）：
   - `ffmpeg -i <video> -vn -ar 16000 -ac 1 audio.wav` 抽音频；
   - `faster-whisper`（模型 **base 或 small**，language="zh"）转写 → `[(start,end,text)]`；
   - **text 模式优先用已知文案**：若有输入文案，用它替换 whisper 识别文本（时间轴仍用 whisper），减少错字；audio 模式直接用 whisper 结果；
   - 生成 `.ass`（字体 `Noto Sans SC`，底部居中，描边，按 `subtitle_style` 给 2–3 个预设样式：白字黑边 / 综艺大字 / 底部半透条）；长句要断行；
   - `ffmpeg -i <video> -vf "ass=subs.ass" -c:a copy <out>` 烧录 → 产出带字幕视频。
   - 加 phase `burning_subtitle`（与 F3 进度联动）。
3. **BGM**（可选）：预设无版权音乐放服务器（如 `content-api/assets/bgm/`，或 webroot 静态目录），`ffmpeg` 混音（人声/BGM 音量比，如 BGM -18dB）。
4. **产出策略**：默认**另存**带字幕/BGM 版本为最终视频资产（可保留原片）；`video_file` 指向成品。
5. **并发保护**：whisper 吃 CPU（4 核无 GPU），**加一个信号量/锁限制同时最多 1–2 个 whisper 任务**，避免多视频并发把 CPU 打满。
6. **不改**生成核心、不改点数模型（如需字幕加价另议）。

### 前端（`video.html`）
- 口播区加 **「自动字幕」开关** + 样式预设选择（下拉/芯片）；可选 **BGM 选择**（无 / 预设几首）。
- 提交时带 `subtitle` / `subtitle_style` / `bgm`。
- 不勾选时行为与现在完全一致。
- 先读 `DESIGN.md`，复用 `cloud-shell.js?v=15` 外壳。

## 依赖与注意（开工前确认）
- **whisper 模型预下载**：首次用会联网下模型，**先在服务器手动预热一次**（如 `python3 -c "from faster_whisper import WhisperModel; WhisperModel('base')"`），避免线上首个任务卡在下载。
- **BGM 素材**：预设 BGM 需无版权音乐，**由用户提供**；没有就先只做字幕、BGM 留空。
- 中文字体 `Noto Sans SC` 已在服务器（libass 可用），无需额外装。
- 字幕耗时：whisper base + ffmpeg 烧录，短片约 +10~40s，可接受；reaper 视频超时已有 30 分钟余量。

## 验收标准
1. 口播（text）勾选"自动字幕"→ 成品视频带**正确中文字幕、无方块乱码、时间轴基本对齐**。
2. 上传音频（audio）模式字幕也能出（用 whisper 识别）。
3. 不勾选字幕/BGM 时，生成流程与现状**完全一致**。
4. （若做 BGM）选 BGM → 成品有背景音乐且人声清晰、音量合理。
5. 并发跑 2 个带字幕视频不会把服务器 CPU 打满导致整体卡死。
6. `python -m py_compile server/content_api.py` 通过；health 200；视频页无控制台报错。
