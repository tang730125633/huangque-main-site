# 工单 · F7 资产页增强（前端版：搜索 / 批量下载 / 一键重生成）

> 供其他 agent 独立执行。开工前先读《工单-其他agent实施-20260703》§0 公共上下文
> （仓库/分支PR/ship/DESIGN.md/漂移哨兵/**禁止服务器直改**）。**本工单纯前端，只改 `site/workbench/assets.html`，不碰后端**（这样可与后端工单并行、不撞车）。

## 目标与价值
资产页目前只能一个个看/下载。加三个高频能力，让"内容工厂"产出更好用：**搜索筛选、批量下载、一键用相同参数重生成**。

## 现状（已核实）
- `assets.html` 分类：图片 / 音频 / 视频 / 数字人形象（F1 已加）。资产经 `/api/gen/history`、`/api/gen/audio/assets`、`/api/gen/video/assets` 加载。
- 每张资产卡已有单个"下载"链接；数据里有 `mode/prompt/text/url/video_url/voice/ratio/status` 等字段（可用于搜索与重生成）。
- **页面顶部已有一个搜索输入框**（`name="hq_asset_search"`，placeholder"搜索作品、素材或标签…"），但**目前没接筛选逻辑**——本工单把它接上。

## 范围
- **In（纯前端）**：① 搜索/筛选 ② 批量下载 ③ 一键重生成。
- **Out（本工单不做，需后端、留待 T6 之后）**：收藏、标签持久化（要新表/接口，会和后端工单冲突）。

## 前端任务（`assets.html`，先读 `DESIGN.md`）
1. **搜索/筛选**：把已有搜索框接上——按输入关键词**客户端过滤**当前分类下已加载的资产（匹配 `prompt`/`text`/文件名等）。清空恢复全部；与现有分类 chip 叠加生效。
2. **批量下载**：加"多选"模式——每张卡可勾选，底部出现"下载所选(N)"按钮，点了逐个触发各资产的下载（用其 `url`/`video_url`）。要有"全选/取消"。注意逐个下载间稍加间隔，避免浏览器拦截连续下载。
3. **一键重生成**：每张卡加"重生成"入口——带上该资产的原参数跳到对应生成页（或直接调对应 `/api/gen/*` 提交）。例如：
   - 图片 → 用 `prompt`/`ratio`/`quality` 重新调 `/api/gen/image`；
   - 音频 → 用 `text`/`voice` 调 `/api/gen/audio`；
   - 视频 → 带参数跳视频页预填（视频成本高，建议跳转预填让用户确认，不直接扣点生成）。
   - 具体用现有各生成接口的既有字段，**不新增后端**。
- 复用 `cloud-shell.js?v=<hash>` 外壳、`data-active="assets"`；401 跳登录。

## 边界与注意
- **只改前端**，不碰后端、不新增接口/表；其它分类与现有下载行为不变。
- 搜索/筛选是**客户端过滤已加载数据**，不改加载接口。
- 重生成走**现有**生成接口；视频类建议"跳转预填"而非直接生成（避免误扣点）。
- 批量下载注意浏览器对连续下载的限制（加间隔/提示）。

## 验收标准
1. 搜索框输入关键词能实时过滤当前分类资产；清空恢复；与分类 chip 叠加正确。
2. 多选 + 批量下载能把所选资产逐个下载下来。
3. 一键重生成能带原参数进入生成流程（图片/音频可直接生成或预填，视频预填确认）。
4. 现有单个下载、各分类展示、数字人形象库均不受影响；无控制台报错。
