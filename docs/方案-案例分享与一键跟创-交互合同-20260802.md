# 黄雀案例分享与一键跟创交互合同

> 状态：Tang 已确认，PR 1 开发中
> 日期：2026-08-02
> 范围：主站网页第一版，仅图片案例与图片作品

## 1. 一句话目标

让一个没有黄雀账号的人，从微信、飞书或收藏夹打开分享链接后，先看懂一张作品为什么值得跟创，再用一次明确操作完成注册、邀请关系绑定和作图页预填。

## 2. 本期边界

### 本期必须完成

- 黄雀官方案例拥有独立、可复制、可直接打开的公开链接。
- 客户图片作品可以主动创建分享链接、预览公开效果和撤销分享。
- 新用户从客户作品点击“一键跟创”后，注册成功时绑定作品主人。
- 已有用户只跟创，不新增或修改邀请关系。
- 注册或登录后返回原来的跟创任务，提示词和模型不丢失。
- 跟创只完成预填，绝不自动提交生成或扣点。

### 本期不做

- 视频、音频、画布、短剧和数字人作品分享。
- 评论、关注、排行榜、公开作品社区。
- 自建短链服务、二维码系统、A/B 平台。
- 飞书自建应用链接卡片和微信专属分享 SDK；第一版使用标准 HTTPS 页面和通用分享元信息。
- 现金分佣、二级关系或新的奖励规则。

## 3. 统一术语

| 术语 | 本项目含义 |
|---|---|
| 分享落地页 | 收件人点击链接后看到的公开案例页，不是登录后的工作台 |
| 一键跟创 | 把分享来源带入作图页并预填，用户检查后自行点击生成 |
| 邀请归因 | 点击客户作品后，临时记住“这个新用户来自谁” |
| 邀请绑定 | 新账号注册成功时，把邀请人与被邀请人写入现有 `user_invites` |
| 回跳 | 注册或登录成功后回到原本要去的作图页 |
| 撤销分享 | 作品主人关闭公开链接；旧链接不再展示作品或产生新归因 |

## 4. 两类分享链接

### 4.1 黄雀官方案例

建议地址：

```text
https://huangquechuanmei.com/case/{case_id}
```

- 数据来源复用现有 `inspirations.json` 和后台已发布案例接口。
- 官方案例链接默认不绑定任何个人邀请关系。
- 分享入口放在灵感案例详情弹窗中，按钮名为“复制分享链接”。
- 后台案例列表可复用同一链接，不再生成第二种后台专用链接。

### 4.2 客户图片作品

建议地址：

```text
https://huangquechuanmei.com/work/{share_token}
```

- `share_token` 是不可猜测的随机标识，不在 URL 中放账号、邀请码、任务 ID 或提示词。
- 分享记录由服务端绑定作品主人和原图片资产。
- 同一作品重复点击分享时复用仍有效的链接，避免生成大量重复记录。
- 作品主人撤销后，旧链接显示“分享已结束”，不能继续归因。

## 5. 分享落地页结构

官方案例和客户作品共用一套页面骨架，只替换数据和身份说明。

### 首屏

1. 黄雀 Logo 与“AI 图片跟创”身份。
2. 作品大图，优先完整展示，不做自动轮播。
3. 案例标题、用途和一句风格说明。
4. 主按钮“一键跟创这个风格”。
5. 次按钮“查看更多黄雀案例”。

### 首屏下方

1. 跟创后可以修改的内容，例如人物、产品、场景和文字。
2. 三步说明：打开案例 → 上传自己的图片或调整描述 → 确认后生成。
3. 客户作品只显示“由黄雀用户创作”；作品主人主动开启后才显示昵称。
4. 不展示账号、手机号、会员等级、奖励、原始任务号或完整后台数据。

### 移动端优先级

- 首屏必须看到主体图片、标题和完整主按钮。
- 主按钮最小高度 48px，底部安全区不能遮挡。
- 不使用横向卡片墙、自动播放视频或需要悬停才能发现的操作。
- 加载中保留图片区域尺寸，避免内容跳动。

## 6. 访客状态与按钮行为

| 访客状态 | 点击“一键跟创”后的行为 | 邀请关系 |
|---|---|---|
| 新用户打开官方案例 | 进入注册，成功后回到作图页 | 不绑定个人 |
| 新用户打开客户作品 | 记录临时归因，进入注册，成功后回到作图页 | 绑定作品主人 |
| 已有账号但未登录 | 选择“已有账号登录”，成功后回到作图页 | 不新建、不修改 |
| 已登录用户 | 直接进入作图页 | 不新建、不修改 |
| 已经绑定过邀请人 | 正常跟创 | 保留原关系 |
| 作品主人打开自己的链接 | 正常预览，可进入作图页 | 禁止自邀 |
| 分享被撤销或作品被删除 | 显示失效页，可前往灵感案例 | 不产生归因 |
| 案例不存在或未发布 | 显示不存在页，可前往灵感案例 | 不产生归因 |

## 7. 新用户核心流程

```text
打开分享页
  → 点击“一键跟创”
  → 服务端校验分享状态并签发短期邀请归因
  → 进入注册页，同时保留安全回跳目标
  → 用户提交注册
  → 同一事务创建账号、校验归因、绑定一级邀请关系、建立登录态
  → 回到作图页
  → 作图页按案例 ID 或分享 token 重新读取跟创内容
  → 预填提示词与模型，等待用户检查并手动生成
```

邀请关系不能在点击时建立，因为点击时还没有被邀请人的账号。点击只产生临时归因；永久关系只能在注册成功时建立。

## 8. 登录与注册页合同

### 进入参数

- `mode=register`：新用户默认看到注册表单，同时保留“已有账号登录”。
- `next`：只允许黄雀站内白名单工作台地址。
- 客户作品的邀请归因使用服务端签名值，不直接相信 URL 中的邀请码。

### 注册成功

- 官方案例：回到 `/workbench/banana?inspiration={case_id}`。
- 客户作品：回到 `/workbench/banana?share={share_token}`。
- 注册响应明确返回是否成功绑定；前端只显示“已通过作品作者邀请加入”，不展示奖励金额。

### 登录成功

- 始终执行 `next` 回跳。
- 即使链接含有客户归因，登录已有账号也不调用绑定逻辑。

### 失败恢复

- 邀请归因过期、被撤销或不匹配：不创建半成品账号，保留表单内容并提示重新打开分享链接。
- 账号已存在：切换到登录，不尝试把现有账号绑定给主人。
- 回跳参数不安全：忽略该参数并进入灵感案例页。

## 9. 作图页跟创合同

- 只接受案例 ID 或分享 token，不把完整提示词放进地址栏。
- 页面自行读取仍然有效的公开跟创数据。
- 预填提示词、目标图片引擎和来源标识。
- 提示用户“已带入分享作品的风格，可修改后生成”。
- 不自动选择本地图片、不自动上传、不自动生成、不自动扣点。
- 客户撤销分享后，尚未进入作图页的新请求不能再读取提示词。
- 已经进入作图页的用户可以继续编辑本次已加载草稿，但不能借此重新建立邀请归因。

## 10. 客户创建分享的交互

入口：`我的资产 → 图片作品 → 分享作品`

弹层只保留必要选项：

1. 公开效果预览。
2. “允许收到链接的人使用这个风格跟创”确认项，必须主动勾选。
3. “显示我的昵称”开关，默认关闭。
4. “创建分享链接”主按钮。

创建成功后显示：

- 复制链接；
- 打开预览；
- 撤销分享。

不增加有效期选择、自定义域名、访问密码或多套权限模板；有真实客户提出后再扩展。

## 11. 公开素材与隐私合同

- 分享前必须由作品主人主动确认，不默认公开历史资产。
- 客户提示词默认不在落地页全文展示，但经主人授权后可用于跟创预填。
- 公开页不能直接返回永久 COS 原地址；使用可撤销的分享媒体端点或短期签名地址。
- 撤销分享、删除资产、封禁账号任一发生时，公开页立即失效。
- 生成结果含真人、品牌、客户素材时，界面提示分享者确认拥有展示和跟创授权。
- 页面和日志不得暴露邀请风控使用的 IP、设备哈希或签名密钥。

## 12. 页面状态

每个分享落地页必须覆盖：

- 正常：图片、标题和主按钮可用。
- 加载：固定媒体骨架和“正在读取案例”。
- 不存在：说明链接不正确，提供“查看灵感案例”。
- 已下架/已撤销：说明分享已经结束，不暴露原因。
- 素材暂时不可用：保留标题和重试按钮。
- 离线：提示检查网络并重试。
- 按钮处理中：防止连续点击产生多个归因请求。

## 13. 分享到外部应用

第一版保证标准 HTTPS 链接可复制、可打开，并提供通用页面元信息：

- 页面标题；
- 简短描述；
- 黄雀通用分享封面；
- canonical URL；
- 不含敏感参数的地址。

第一版不接飞书自建应用链接预览回调。微信和飞书最终显示样式由客户端决定，必须在安卓和 iPhone 真机验收，不能把桌面浏览器截图当成通过。

## 14. 最小事件口径

只记录完成漏斗所需事件：

1. 分享页有效打开。
2. 点击一键跟创。
3. 注册成功。
4. 邀请绑定成功。
5. 跟创草稿成功加载。
6. 用户主动提交生成。
7. 生成成功。

刷新页面不重复计算一次注册或绑定；同一生成任务只记一次成功。第一版复用现有案例点击、任务来源和邀请关系记录，不引入新的分析平台。

## 15. 第一阶段验收清单

### 官方案例分享

- 任一现有静态案例和后台已发布案例都能生成唯一链接。
- 链接在未登录浏览器直接打开，不被工作台登录态拦截。
- 分享页移动端首屏看到图片、标题和主按钮，无横向溢出。
- 新用户注册后返回正确作图页，提示词和模型正确。
- 已有用户登录后返回正确作图页，不产生邀请关系。
- 下架后台案例后，原链接不再展示内容。
- 全流程不自动生成或扣点。

### 客户作品分享

- 只有作品主人能创建或撤销链接。
- 默认不显示客户昵称和完整提示词。
- 新用户注册成功后只产生一条直接邀请关系。
- 已有用户、已绑定用户和作品主人不会被重新绑定。
- 撤销、删除资产和封禁账号后旧链接立即失效。
- 永久 COS 地址、账号信息和邀请签名不出现在公开响应中。

## 16. 分阶段交付

### PR 1：官方案例分享闭环

- 独立分享落地页；
- 灵感详情复制链接；
- 登录/注册安全回跳；
- 作图页按案例 ID 预填；
- 桌面与移动端最小回归。

不改数据库，不接邀请绑定，不做客户资产分享。

### PR 2：客户图片分享与邀请归因

- 图片资产分享、预览和撤销；
- 最小分享记录；
- 可撤销媒体访问；
- 复用现有一级邀请注册事务；
- 客户分享来源的最小统计。

不扩展其他资产类型，不新增奖励规则。

## 17. 已锁定决策

- 官方案例不绑定个人邀请关系。
- 客户作品分享才绑定作品主人。
- 绑定发生在新账号注册成功时。
- 第一版只支持图片。
- 跟创只预填，不自动生成。
- 先上泽龙测试环境，再决定是否进入正式站。
- 分享落地页首版沿用现有黄雀深色金色风格。
- 主按钮文案采用“一键跟创这个风格”。
