# 工单 · 后台用户调用日志「功能」列细化（ADMIN-6）

> 供其他 agent 独立执行。先读《工单-其他agent实施》§0 +《任务看板》+ `DESIGN.md`。
> **冲突组：admin（`server/admin_api.py`、`site/admin/index.html`）** —— 抢 `lock/admin`。
> 来自 kongli：后台「用户调用日志」的功能列写得更具体（现在只按 kind 显示，太笼统）。

## 现状
ADMIN-5 的调用日志「功能」列只按 `kind` 映射中文（如 video→"视频口播"）。但同一个 kind 下有多个子功能，光看 kind 分不清：
- `kind=video` 覆盖 **文案口播 / 音频口播 / 动作模仿**（区别在 payload `mode`：text/audio/motion）——都显示"视频口播"是错的。
- `kind=image` 覆盖 **Nano Banana 2 / Nano Banana Pro / GPT Image / 泽龙**（区别在 payload `model`=nb2/pro 或 `provider`=openai/zelong）。
- `kind=collect` 覆盖 **贴链接采集 / 关键词搜索**（payload 有 `url` vs `keyword`）。
- 注：实际**没有 `banana`/`motion` 这两个 kind**（banana→image+model，motion→video+mode），现有前端 kindName 里的 banana/motion 映射用不上。

## 改动：读 payload、给出具体功能名
### 后端（`server/admin_api.py` 的 `call_logs`）
- SELECT 里**加上 `payload`**；对每条解析 payload，提取 `mode`/`provider`/`model`/是否有 `keyword`——据此在后端算出**具体功能名**（返回如 `func` 字段），或把这几个字段一并返回给前端映射（二选一，建议后端直接给 `func` 字符串，前端简单）。
- 解析失败/字段缺失要兜底到该 kind 的通用名，别报错。

### 功能名映射（具体到子功能）
| 条件 | 显示 |
|---|---|
| image + model=nb2 | 作图 · Nano Banana 2 |
| image + model=pro | 作图 · Nano Banana Pro |
| image + provider=openai | 作图 · GPT Image |
| image + provider=zelong | 作图 · 泽龙 |
| image（其它/缺失）| 作图 |
| video + mode=text | 视频 · 文案口播 |
| video + mode=audio | 视频 · 音频口播 |
| video + mode=motion | 视频 · 动作模仿 |
| video（缺 mode）| 视频生成 |
| tryon | 换装换背景 |
| audio | 配音生成 |
| collect + 有 keyword | 内容采集 · 关键词搜索 |
| collect + 有 url（贴链接）| 内容采集 · 贴链接 |
| collect（其它）| 内容采集 |
| leads / leadgen | 获客分析 |
| copy | 文案生成 |
| dl | 无水印下载 |

### 前端（`site/admin/index.html`）
- 调用日志的「功能」列改用后端 `func`（或按上表在前端映射 mode/provider/model）。
- 其它列（时间/用户/耗时/状态/点数）不变。

## 边界
- 只细化「功能」列的显示逻辑；不改调用统计、不改生成主流程。
- payload 只读、不外泄敏感内容（只取 mode/provider/model/keyword 存在性，别把整个 prompt/图片 base64 返回前端）。
- `role=admin` 门控不变。

## 验收标准
1. 调用日志「功能」列能区分：文案口播/音频口播/动作模仿、Nano Banana 2/Pro、GPT Image/泽龙、贴链接采集/关键词搜索、换装换背景、配音、获客、文案、下载。
2. payload 缺字段时兜底到通用名、不报错、不泄露 prompt/base64。
3. 其它列不变；`py_compile` 通过、admin health 正常。

## 部署与验证
- `admin_api.py`→huangque-admin、`site/admin/index.html`→webroot。
- 实测：日志里视频三种口播、作图各引擎、采集两种能分别显示。
