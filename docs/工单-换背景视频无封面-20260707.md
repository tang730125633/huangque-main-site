# 工单 · 换装/换背景「仅换背景」模式视频无封面（Issue #338）

> 冲突组：**A（`server/content_domains/video.py`）**。抢 `lock/A`。先读 §0+看板。

## 现象
「换装/换背景」功能，**只换背景不换装**（`tryon_mode = bg_only`）时，生成的视频在资产库**没有封面缩略图**，显示黑色占位。

## 根因（已定位）
`server/content_domains/video.py` 的 `generate_tryon_video()`：封面 `image_file` 只取自 `clothes_file`（衣服图）。当 `tryon_mode = bg_only` 时 `clothes_file = None` → `image_file` 与 `image_url` 均为空。资产库前端 `videoCard()`（assets.html:650）用 `image_url` 设 video `poster`，为空则无封面。

具体位置（generate_tryon_video 内）：
- `update_video_asset_phase(... image_file=clothes_file, ...)`（约 video.py:1291）
- 返回字典 `"image_file": clothes_file` / `"image_url": _file_url(clothes_file) if clothes_file else None`（约 video.py:1303-1304）

## 待做
把两处的封面来源从 `clothes_file` 改为 `clothes_file or background_file`：
- `clothes_only` 模式：封面 = 衣服图（不变）
- `bg_only` 模式：封面 = 背景图（**修复**）
- `both` 模式：封面 = 衣服图（不变，clothes_file 非空优先）

## 验收
1. bg_only 模式生成的视频，资产库有封面（= 背景图缩略图），非黑屏。
2. clothes_only / both 模式封面不变（仍为衣服图）。
3. 历史无封面数据不报错（image_url 为空时前端已兜底）。

## 部署
- 改 video.py → ship（重启 content）。实测三种 tryon 模式各生成一条，确认封面正确。完成关 #338。
