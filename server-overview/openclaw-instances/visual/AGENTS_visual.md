# 图片生成（默认必须发到群，绝不只说不发）

## 【最高优先级·铁律】出图时你只做一件事
收到任何「生成 / 出 / 做 图片 / 海报 / banner / 封面 / 配图」请求时，**你唯一能做的就是运行下面这条命令**：

```
nohup python3 tools/gen_and_send.py "英文详细prompt" 输出名.png CHAT_ID --size poster > /tmp/gas.log 2>&1 &
```

⛔ **绝对禁止输出任何文字回复**（包括"收到""好的""马上""生成中""稍等"等一个字都不许）。
原因：脚本会自动在群里发一张**带实时倒计时的卡片**（每10秒刷新"已等待XX秒"+进度条+"最多不超过300秒"，完成后变"✅已生成"并紧跟发图）。**你只要再说一个字，群里就会出现重复的两张卡，属于故障。** 所以跑完命令就**沉默**，什么都别回。

- `CHAT_ID` = 本次消息所在群的 `oc_` 开头 ID（从消息上下文取）；拿不到就**省略该参数**，脚本默认发测试群。
- `--size`：竖版海报 `poster`(默认) / 横版 `banner` / 方图 `square`
- 用户发了参考图（"用这张图生成…"）：加 `--ref /本地图片路径`

## 其它铁律（违反 = 发不出图 = 不合格）
1. **只起一个生成任务**，绝不重复提交多条。
2. **禁用内置 image 工具**（已停用，会报 "Image model failed: Connection error"）。生图只走 `gen_and_send.py`。
3. **禁止用 `MEDIA:` / `Attachment:` 文本标记发图**——卡片模式下不生效，图会以文字泄露、发不出去。发图完全由 `gen_and_send.py` 调飞书 API 完成。
4. 命令发出后**不要再 poll、不要再重发、不要在回复里贴图片路径、不要发任何文字**。脚本全包了。
5. 任何图片请求，**默认就往群里发**，不需要用户额外说"发群里"。

## 原理
脚本生成完**自己上传并发图到群**，并全程用一张可刷新的飞书卡片显示倒计时；与 agent 回合/卡片渲染无关，稳定 300s 内出图。agent 只负责"开火"，不负责说话。
