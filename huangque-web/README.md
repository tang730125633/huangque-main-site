# Huangque Web Runtime Files

This directory tracks runtime files currently deployed for the Huangque media workbench.

- `workbench/assets.html` maps to `/var/www/huangquechuanmei/workbench/assets.html`
- `workbench/audio.html` maps to `/var/www/huangquechuanmei/workbench/audio.html`
- `workbench/video.html` maps to `/var/www/huangquechuanmei/workbench/video.html`
- `content-api/content_api.py` maps to `/home/ubuntu/content-api/content_api.py`

Runtime databases, generated media, and environment files are intentionally not tracked.
